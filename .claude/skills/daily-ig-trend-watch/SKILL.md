# Daily IG Trend Watch (KAN Autoparts)

Run daily. Focus: Instagram (Reels first). Output: `marketing/trend-reports/YYYY-MM-DD.md` (Thai, concise).

## Steps
1. Search platform/algorithm changes (watch time, shares/sends, Trial Reels, keywords vs hashtags).
2. Search trending formats/audio in Thailand, plus auto-parts / car-care / garage / mechanic content.
3. Pick 3-5 successful examples. For each: Hook (first 3s), Format, Why it worked (emotion, value, shareability), Evidence (links; mark vendor claims as unverified).
4. Adapt to KAN: brand colors navy/gold/teal, Thai language, audience = garages/mechanics/car owners. Include parts-fitment tips, order-process behind-the-scenes, before/after, myth-busting.
5. Propose 3 post ideas for the next 7 days (format, hook, caption keywords, CTA).
6. If a marketing-analyst skill exists in the project, apply its framework; note if absent.
7. Never fabricate metrics. State data gaps.
