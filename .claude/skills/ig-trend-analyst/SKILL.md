# KAN Autoparts — IG Trend Analyst (daily)

แบรนด์: KAN Autoparts (อะไหล่รถยนต์) — โทนสี navy #082B55 / gold #C99632 / cream, ภาษาไทย, ลูกค้าหลัก: ช่าง/อู่/ร้านอะไหล่ และเจ้าของรถ
ช่องทางหลัก: Instagram (Reels > Carousel > Stories)

## Daily steps
1. **Scan** (WebSearch, ภาษาไทย+อังกฤษ): trending Reels formats/audio ของวัน, คอนเทนต์รถยนต์/อะไหล่/อู่/ช่างที่ไวรัลในไทย, เทรนด์ของ IG algorithm ล่าสุด
2. **Pick 3–5 pieces** ที่ตอบโจทย์ KAN และระบุที่มา (ลิงก์). ถ้าหาข้อมูลเฉพาะไม่ได้ ให้ระบุชัดว่าเป็น "ข้อสันนิษฐาน" ห้ามแต่งตัวเลขหรือตัวอย่าง
3. **Analyze WHY it worked** ต่อแต่ละชิ้น: Hook (3 วิแรก) · Format/ความยาว · Emotion/คุณค่า (ให้ความรู้/ขำ/ความเชื่อใจ) · สัญญาณอัลกอริทึม (saves, shares, watch time, DM sends) · CTA
4. **Adapt for KAN**: แปลงเป็นไอเดียคอนเทนต์ 3 ชิ้น (Reel / Carousel / Story) พร้อม hook, ฉาก/สไลด์, caption ร่าง, hashtag, CTA (เช่น คอมเมนต์ keyword รับราคา / ทัก DM เช็คสต็อก)
5. **Plan**: ใส่ลงปฏิทินคอนเทนต์ 7 วัน; ติดตามผลของโพสต์ที่แล้วเทียบกับสมมติฐาน (ถ้ามีข้อมูล)
6. **Save** รายงานที่ `marketing/trend-reports/YYYY-MM-DD.md` แล้ว commit/push บน branch ที่กำหนด

## Content pillars ของ KAN
- ความรู้ช่าง: เช็กอาการ/เลือกอะไหล่ถูกรุ่น (บันทึกง่าย → saves สูง)
- Fitment: ยี่ห้อ/รุ่น/ปี/เลขอะไหล่ ชัดเจน
- Behind-the-scenes: แพ็คของ ส่งของ สต็อกเข้า (สร้างความเชื่อถือ)
- Before/After, ของแท้ vs เทียบ, ราคา/โปร
- ลูกค้ารีวิว/ช่างใช้จริง

## Report template
# IG Trend Report — YYYY-MM-DD
1. สรุปเทรนด์วันนี้ (พร้อมลิงก์ + ระดับความมั่นใจ)
2. วิเคราะห์ว่าทำไมถึงได้ผล (ตารางต่อชิ้น)
3. ไอเดียคอนเทนต์สำหรับ KAN (3 ชิ้น)
4. แผน 7 วัน
5. ข้อจำกัดของข้อมูล / สิ่งที่ต้องตรวจสอบ
