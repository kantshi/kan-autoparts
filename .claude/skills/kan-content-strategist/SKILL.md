# KAN Content Strategist

Daily routine for a marketing analyst working on **KAN Autoparts** (ร้านอะไหล่รถยนต์), a Thai auto-parts business that sells through a mobile web storefront (`index.html`) with checkout handed off to LINE OA.

## Brand facts (don't re-derive these — read them here)

- **Product**: auto parts (อะไหล่รถยนต์), sold by SKU, with a bulk-price break at 5+ units ("ราคาส่ง 5+ ตัว").
- **Ordering flow**: browse → add to cart → checkout form → redirected to LINE OA (`@617ytnjm`) to confirm payment. No online payment on-site.
- **Brand palette**: navy `#082B55`, gold/champagne `#C99632` / `#D4A447`, teal `#1C6668` / `#0C4144`, cream `#F6F4ED`. Font: Sarabun. Tone: trustworthy, straightforward, value-for-money — not flashy.
- **Audience**: Thai car owners and mechanics/garages buying parts in bulk, price-sensitive, likely to search by SKU or car model/part name.
- **Primary channel for this routine**: Instagram (IG feed + Reels first; other platforms are secondary).

## Workflow

1. **Scan trends** — run 2–3 web searches covering:
   - General Instagram/Reels trend reports for the current month (hooks, formats, audio, algorithm signals).
   - Automotive/auto-parts-specific social media trends (UGC, before/after, fitment content, social commerce).
   - Keep only trends still fresh (reported within the last ~30 days) — Reels trends move in days, not months.
2. **Analyze why each trend works** — name the mechanic, not just the format: e.g. "raw/unpolished beats polished" works because it reads as trustworthy and lowers the viewer's guard; "first 2–3 second hook" works because retention is the dominant ranking signal; UGC works because it's proof a paid ad can't fake.
3. **Translate to a KAN content idea** — for each trend that's a plausible fit, produce one concrete idea with:
   - Format (Reel / carousel / single image)
   - Hook (first line, in Thai, ready to say/write)
   - Content pillar it belongs to (see below)
   - Call-to-action tying back to LINE OA ordering or bulk pricing
   - Skip trends that don't fit an auto-parts retailer (e.g. pure entertainment/lip-sync formats) rather than forcing them.
4. **Output** — a short digest (today's trends + why) followed by a ready-to-shoot content list (3–5 ideas), in Thai. Publish it somewhere the marketer will actually see it (an Artifact is a good default) rather than leaving it only in chat.
5. **If this is running as an unattended scheduled routine**, send a push notification with the single highest-value idea and a link to the full plan — don't rely on someone reading the transcript.

## KAN content pillars (rotate across these, don't repeat the same pillar two days running)

1. **Fitment/compatibility education** — "รุ่นนี้ใช้อะไหล่ตัวไหน", how to check the right part before buying.
2. **Bulk savings hook** — the 5+ unit price break, framed for garages/resellers buying in quantity.
3. **Behind-the-scenes / stock authenticity** — warehouse shelves, SKU picking, packing orders — raw, unpolished, builds trust (matches the 2026 "raw beats polished" trend).
4. **UGC / customer installs** — real customers' cars with KAN parts installed; ask buyers to tag KAN.
5. **Myth vs. fact** — common misconceptions about auto parts (แท้/เทียบ, อายุการใช้งาน, ของแท้ vs ของเทียบ).
6. **Quick maintenance tips** — short, useful, not a sales pitch — builds authority.
7. **How to order via LINE OA** — friction-reduction content; new followers often don't know the checkout flow.

## Notes for future runs

- No dedicated design system or existing content calendar file exists in this repo yet — if one gets created (e.g. `content-calendar.md`), read it first before proposing new ideas so pillars stay in rotation instead of repeating.
- This repo is the storefront's source code, not a content archive — write daily plans to an Artifact or hand them to the marketer directly, don't accumulate them as repo files unless asked.
