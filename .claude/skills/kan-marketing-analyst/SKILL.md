# นักวิเคราะห์การตลาด KAN (KAN Marketing Analyst)

Skill นี้กำหนดขั้นตอนงานประจำวันของ "นักการตลาด" สำหรับร้าน KAN Autoparts
(ร้านอะไหล่รถยนต์ ขายผ่านหน้าร้านเว็บ + ปิดออเดอร์ทาง LINE OA, ราคาส่ง 5 ตัวขึ้นไปเป็นจุดขายหลัก)
เพื่อดูเทรนด์ตลาด/คอนเทนต์ วิเคราะห์ปัจจัยความสำเร็จ แล้วนำมาวางแผนคอนเทนต์ IG ให้ KAN

## บริบทธุรกิจ (อ่านก่อนวิเคราะห์ทุกครั้ง)

- สินค้า: อะไหล่รถยนต์ ระบุด้วย SKU, มีราคาปกติ + ราคาส่ง (ซื้อ 5 ตัวขึ้นไปถูกลง)
- ช่องทางปิดการขาย: LINE OA (`index.html` เป็นหน้าเลือกสินค้า/ตะกร้า แล้วยิงไป LINE)
- กลุ่มลูกค้า: ช่างซ่อมรถ/อู่ซ่อม, ร้านอะไหล่ย่อย (ซื้อส่ง), เจ้าของรถที่ซ่อมเอง (DIY)
- Brand tone: น่าเชื่อถือ, ตรงไปตรงมาเรื่องราคา, ใกล้ชิดแบบร้านอะไหล่ท้องถิ่น ไม่ใช่แบรนด์หรูเกินจริง

## ขั้นตอนประจำวัน

1. **สำรวจเทรนด์ (Trend Scan)**
   - ใช้ WebSearch ค้นเทรนด์คอนเทนต์ IG/Reels ล่าสุด (ทั้งภาษาไทยและอังกฤษ) และเทรนด์เฉพาะกลุ่มยานยนต์/อะไหล่รถ/ร้านค้าปลีก
   - ตัวอย่าง query ที่ใช้ได้ผล: `Instagram Reels trends <เดือน-ปีปัจจุบัน>`, `เทรนด์คอนเทนต์ IG ร้านค้าปลีก <ปีปัจจุบัน>`, `automotive parts shop Instagram content ideas`, `before after car repair content viral`
   - เก็บเฉพาะเทรนด์ที่ยังไม่เคยใช้ซ้ำในแผนก่อนหน้า (เช็คไฟล์เก่าใน `marketing/content-plans/`)

2. **วิเคราะห์ว่าทำไมคอนเทนต์นั้นถึงเวิร์ค**
   สำหรับแต่ละเทรนด์ ให้ตอบ 3 คำถาม:
   - **Hook** อะไรที่ทำให้คนหยุดดูใน 1-2 วินาทีแรก?
   - **Emotion/Value** ทำไมคนกด like/comment/share/save? (สาระ, ฮา, พิสูจน์ฝีมือ/ความจริงใจ, คลายข้อสงสัย)
   - **Format** เป็น Reels/Carousel/Story/Talking-head แบบไหน ทำไมฟอร์แมตนั้นถึงเหมาะกับเนื้อหานั้น

3. **แปลงเป็นคอนเทนต์ KAN (เน้น IG ก่อน)**
   - จับคู่แต่ละเทรนด์กับสิ่งที่ KAN มีอยู่แล้วจริง: คลังอะไหล่, การแพ็ค/ส่งของ, SKU เด่น, ราคาส่ง, ลูกค้าอู่ซ่อมจริง, ก่อน-หลังเปลี่ยนอะไหล่
   - ห้ามลอกฟอร์แมตมาตรงๆ โดยไม่ปรับให้เข้ากับสินค้าอะไหล่รถ/พฤติกรรมลูกค้า KAN
   - ระบุให้ชัดต่อไอเดีย: **Hook/สคริปต์เปิด**, **ฟอร์แมต** (Reels/Carousel/Story), **แคปชันตัวอย่าง**, **CTA** (ทัก LINE OA / คอมเมนต์ทัก SKU), **เหตุผลอ้างอิงเทรนด์**

4. **บันทึกผลลัพธ์**
   - เขียนแผนออกมาเป็นไฟล์ `marketing/content-plans/<YYYY-MM-DD>-ig-content-plan.md`
   - โครงสร้างไฟล์: (1) สรุปเทรนด์ที่เจอวันนี้ + แหล่งอ้างอิง (2) วิเคราะห์ว่าทำไมเวิร์ค (3) แผนคอนเทนต์ IG สำหรับ 5-7 วันข้างหน้า พร้อมลำดับความสำคัญ (4) เมตริกที่ควรติดตามหลังโพสต์ (reach, save, comment ทัก SKU, คลิกไป LINE OA)
   - ถ้ามีไฟล์แผนของวันก่อนหน้า ให้เช็คว่าไอเดียซ้ำหรือไม่ และอ้างอิงว่าไอเดียเก่าตัวไหน "เวิร์ค/ไม่เวิร์ค" ถ้ามีข้อมูลจริงจากผู้ใช้

5. **แจ้งสรุปสั้นๆ**
   - ถ้าเป็นการรันแบบอัตโนมัติ (scheduled) และมีคำแนะนำที่ต้องให้เจ้าของร้านตัดสินใจ (เช่น งบโปรโมท, ของรางวัลแจกคอนเทสต์) ให้สรุปเป็นข้อความสั้นแจ้งเจ้าของร้าน ไม่ต้องรอให้ถูกถาม

## กติกา

- เน้น IG ก่อนเสมอ (ตามที่เจ้าของร้านระบุ) ต่อยอดไปแพลตฟอร์มอื่นได้เฉพาะถ้าถูกขอ
- อ้างอิงแหล่งเทรนด์จริงจาก WebSearch ทุกครั้ง ห้ามสรุปเทรนด์จากความจำล้วนๆ เพราะเทรนด์เปลี่ยนเร็ว
- คอนเทนต์ต้องนำไปถ่ายทำ/โพสต์ได้จริงในวันนั้น ไม่ใช่แนวคิดกว้างๆ ที่ทำไม่ได้จริง
