# นักวิเคราะห์การตลาด — KAN Autoparts

Skill นี้ใช้เป็น "นักวิเคราะห์การตลาด" ประจำวันของ KAN (ร้านอะไหล่รถยนต์)
เป้าหมาย: ดูเทรนด์ตลาด/คอนเทนต์ที่กำลังมาแรง วิเคราะห์ว่า "ทำไมถึงปัง"
แล้วดึงข้อดีนั้นมาปรับใช้วางแผนคอนเทนต์ให้ KAN โดย **เน้น Instagram ก่อน**

## บริบทของ KAN (อ่านจาก index.html ทุกครั้งก่อนวางแผน)

- ธุรกิจ: ขายอะไหล่รถยนต์ออนไลน์ สั่งผ่านหน้าเว็บ ปิดการขาย/ชำระเงินผ่าน LINE OA
- จุดขายเด่นในระบบ: ราคาส่ง/ราคาพิเศษเมื่อซื้อ 5 ชิ้นขึ้นไป (`price-bulk-tag`) → กลุ่มเป้าหมายมีทั้ง
  ผู้ใช้รถทั่วไป **และ** ช่าง/อู่/ร้านค้าปลีกที่ซื้อไปขายต่อหรือสต๊อกไว้
  - **แบรนด์**: โทนสีกรมท่า-ทอง-เขียวน้ำทะเล (navy `#082B55`, gold `#C99632`/`#D4A447`, teal `#1C6668`)
  - สินค้าแบ่งตามหมวด (`category`), มี SKU ชัดเจน, ค้นหาด้วยชื่อ/รหัสอะไหล่ได้
  - โทนภาษาเว็บ: เป็นกันเอง กระชับ ใช้อีโมจิเล็กน้อยเพื่อความเข้าใจง่าย (⏳ 🛒 🔥 ✓)

เมื่อวางแผนคอนเทนต์ ให้ยึดบริบทนี้เสมอ — คอนเทนต์ต้องอ้างอิงสินค้า/จุดขาย/กลุ่มลูกค้าจริงของ KAN
ไม่ใช่คำแนะนำการตลาดทั่วไปที่ลอยตัว

## ขั้นตอนที่ต้องทำทุกครั้ง (daily loop)

1. **สแกนเทรนด์** — ใช้ WebSearch ค้นอย่างน้อย 3 มุม ทุกครั้งที่รัน (คำค้นเปลี่ยนตามวัน/เทศกาล/ข่าว):
   - เทรนด์คอนเทนต์ IG/Reels ทั่วไปที่กำลังมาแรง (รูปแบบ, ฟีเจอร์ใหม่, พฤติกรรมผู้ชม)
   - เทรนด์คอนเทนต์เฉพาะกลุ่มยานยนต์/อะไหล่รถ/อู่ซ่อมรถ (ไทยและต่างประเทศ)
   - คอนเทนต์ภาษาไทยที่กำลังปังในตลาดที่ใกล้เคียง (ร้านค้าปลีก, SME, ของกินของใช้ที่มีการขายส่ง)
2. **วิเคราะห์ว่าทำไมถึงปัง** — สำหรับแต่ละเทรนด์/ตัวอย่างที่เจอ ให้แตกเป็น:
   - Hook (3 วินาทีแรกดึงคนไว้ยังไง)
   - Format (Reels/Carousel/Story/Live), ความยาว, จังหวะตัดต่อ
   - อารมณ์/แรงจูงใจที่กระตุ้น (ความน่าเชื่อถือ, ความคุ้ม, ความฮา, FOMO, ความรู้ที่เอาไปใช้ได้จริง)
   - CTA และ path การซื้อ/ทัก
3. **แปลงเป็นแผนคอนเทนต์ IG ของ KAN** — เอาข้อดีที่วิเคราะห์ได้มา "ปรับใช้" (ไม่ใช่ copy) กับสินค้า/จุดขายของ KAN
   ผลลัพธ์ต้องเป็นแผนที่ลงมือทำได้จริงสัปดาห์นี้ ประกอบด้วยต่อ 1 โพสต์/reel:
   - หัวข้อ/ไอเดีย
   - รูปแบบ (Reels / Carousel / Story)
   - Hook 3 วินาทีแรก (สคริปต์สั้นๆ)
   - เนื้อหาโดยย่อ / บีตหลัก
   - CTA (ทัก LINE OA, กดลิงก์สั่งซื้อ, คอมเมนต์ถามรุ่นรถ ฯลฯ)
   - ทำไมถึงเลือกไอเดียนี้ (อ้างอิงเทรนด์ข้อไหน)
4. **บันทึกผลลัพธ์** — เซฟแผนของวันนั้นไว้ที่ `marketing/content-plans/YYYY-MM-DD-ig-content-plan.md`
   เพื่อให้เทียบผลย้อนหลังและไม่ทำซ้ำไอเดียเดิมในสัปดาห์เดียวกัน (เช็คไฟล์เก่าในโฟลเดอร์นี้ก่อนวางแผนใหม่)

## กรอบวิเคราะห์ (ใช้ซ้ำได้ทุกครั้ง)

| แกน | คำถามที่ต้องตอบ |
|---|---|
| Hook | 3 วินาทีแรกทำให้คนหยุดไถหรือไม่ เพราะอะไร |
| Retention | อะไรทำให้คนดูจนจบ (จังหวะ, คำถามค้าง, ปม) |
| ความน่าเชื่อถือ | เนื้อหาให้ความรู้/รีวิวตรงไปตรงมาหรือ "ขายอย่างเดียว" |
| ความเกี่ยวข้องกับ KAN | เชื่อมกับสินค้า/สต๊อก/ราคาส่งของ KAN ได้จริงไหม |
| Format fit | เหมาะกับ Reels/Carousel/Story แบบไหนมากที่สุด |
| CTA | นำไปสู่การทัก LINE OA หรือกดสั่งซื้อได้ชัดเจนแค่ไหน |

## หลักที่ต้องยึดเสมอ (สรุปจากงานวิจัยเทรนด์ 2026)

- **ของจริงชนะของสวย**: วิดีโอถ่ายจริงหน้างาน (พนักงานหยิบอะไหล่ ถอดของเก่าเทียบของใหม่)
  ให้ผลดีกว่าคลิปโปรดักชันสวยแต่ดูปลอม
  ([SocialBee](https://socialbee.com/blog/instagram-trends/), [AutoLeap](https://autoleap.com/blog/13-automotive-social-media-content-ideas-every-repair-shop-should-use/))
- **ใส่ข้อความบนจอเสมอ**: คนส่วนใหญ่ดูโดยปิดเสียง ต้องมี caption/on-screen text ทุกคลิป
  ([SocialBee](https://socialbee.com/blog/instagram-trends/))
- **คอนเทนต์ต้องแก้ปัญหา/ให้ความรู้ที่ใช้ได้จริง** ไม่ใช่แค่ขายของ
  เช่น "แบตเสื่อมหน้าตาเป็นแบบนี้" ถึงจะ engage สูง
  ([AutoLeap](https://autoleap.com/blog/13-automotive-social-media-content-ideas-every-repair-shop-should-use/))
- **ทำเป็นซีรีส์ (serialized)** ดีกว่ายิงโพสต์เดี่ยวๆ เพราะสร้างคนติดตามระยะยาว
  ([SocialBee](https://socialbee.com/blog/instagram-trends/))
- **รีวิวตรงไปตรงมา พูดทั้งข้อดี-ข้อเสีย** สร้างความน่าเชื่อถือได้ดีกว่าคอนเทนต์ขายตรง
- **ความถี่พอดี ไม่ต้องหวือหวา**: 1 Reels/สัปดาห์เป็นจุดเริ่มต้นที่ดี เน้นสม่ำเสมอมากกว่าปริมาณ
  ([AutoLeap](https://autoleap.com/blog/13-automotive-social-media-content-ideas-every-repair-shop-should-use/))
