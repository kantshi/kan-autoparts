# KAN Marketing Analyst

Daily routine for KAN Autoparts' marketing team (or an agent standing in for
them) to scan trends, understand *why* winning content works, and turn that
into a concrete content plan for KAN's own channels — IG first.

## When to run this

Once per day (or whenever asked to "ดูเทรนด์" / "วิเคราะห์คอนเทน"). Each run
should produce one dated report under `marketing/content-plans/`.

## Steps

1. **Scan trends.** Search for current content/market trends relevant to
   KAN's business (auto parts — replacement parts, accessories, car care,
   B2B/B2C ordering), with emphasis on Instagram (Reels, Carousels, Stories)
   since that's KAN's priority channel. Also check general content-marketing
   trend sources (algorithm changes, format shifts, what metrics the
   platform rewards) — these directly affect what "success" looks like.

2. **Find concrete examples.** Look for specific posts, campaigns, or
   creators (auto parts / automotive / adjacent retail categories) that
   performed well. Prefer real examples with visible engagement signals
   (shares, saves, comments) over generic advice.

3. **Analyze *why* it worked.** For each example, name the mechanism, not
   just the format — e.g. "before/after install reveals give an instant
   payoff in the first 2 seconds" is useful; "it was a good reel" is not.
   Common lenses: hook speed, authenticity vs. polish, UGC/social proof,
   demonstrated payoff (before/after, unboxing, fitment), trust signals
   (SKU accuracy, warranty, price transparency), save/share-worthiness.

4. **Map to KAN.** For each success factor, write one concrete way to apply
   it to KAN's own catalog and brand (see `product-catalog.md` in this
   skill's folder for what KAN sells and its visual identity). Be specific:
   which product category, what the shot list looks like, what the caption
   hook is — not "make more videos."

5. **Produce a content plan.** Output a short IG content plan: a handful of
   post ideas (format, hook, caption angle, CTA), ranked by expected
   effort-to-impact. Focus on IG; note anything worth adapting to other
   channels (TikTok, Facebook, LINE OA) separately, don't dilute the IG
   plan.

6. **Save the report.** Write it to
   `marketing/content-plans/YYYY-MM-DD-ig-trend-analysis.md` (Bangkok date).
   Keep each day's file self-contained: trends found → why they worked →
   KAN-specific ideas. Don't rewrite prior days' files.

## Notes

- KAN's brand identity (from `index.html`): navy (`#082B55`), gold/champagne
  (`#C99632`/`#D4A447`), teal (`#1C6668`/`#0C4144`), cream background,
  Sarabun typeface, Thai-first copy. Keep content ideas visually consistent
  with this palette where it's relevant (thumbnails, overlays, graphics).
- KAN's product catalog is data-driven (categories/SKUs loaded at runtime,
  not hardcoded) — treat "which category to feature" as a live question,
  not a fixed list. Ask the team or check the live catalog before assuming
  what's in stock/season.
- Keep recommendations concrete and testable (a specific reel to shoot this
  week), not generic social-media advice.
