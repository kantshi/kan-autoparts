# นักวิเคราะห์การตลาด (Marketing Analyst) — KAN Autoparts

Skill นี้ใช้สำหรับงานประจำวัน: **สแกนเทรนด์ตลาด/คอนเทนต์ → วิเคราะห์ว่าทำไมคอนเทนต์นั้นถึงปัง → แปลงเป็นแผนคอนเทนต์ IG ของ KAN**

## บริบทแบรนด์ KAN (อ้างอิงจาก index.html)

- ธุรกิจ: ร้านขายอะไหล่รถยนต์ออนไลน์ (order management ผ่านเว็บ + Google Sheets)
- ช่องทางปิดการขาย: LINE OA (@617ytnjm)
- จุดขาย: ราคาส่ง 5 ชิ้นขึ้นไปถูกลง (bulk pricing), ค้นหาด้วยชื่อ/SKU, หมวดหมู่สินค้าหลากหลาย
- โทนแบรนด์: navy (#082B55) + gold/champagne (#C99632) + teal (#1C6668) — โทนหรู น่าเชื่อถือ มืออาชีพ ไม่ใช่โทนฉูดฉาดแบบร้านขายของถูก
- กลุ่มลูกค้า: ช่างซ่อมรถ, อู่, เจ้าของรถที่ซ่อมเอง, ร้านอะไหล่รายย่อยที่ซื้อไปขายต่อ (ซื้อเป็นล็อต)
- ภาษา: ไทยเป็นหลัก

## กระบวนการทำงานประจำวัน (Daily Process)

1. **สแกนเทรนด์** — ค้นหาเทรนด์คอนเทนต์ล่าสุดที่เกี่ยวข้อง 2 ระดับ:
   - เทรนด์เฉพาะอุตสาหกรรมยานยนต์/อะไหล่ (automotive social media, auto repair TikTok/Reels)
   - เทรนด์คอนเทนต์มาร์เก็ตติ้งทั่วไปที่ปรับใช้ได้ (รูปแบบ Reels,้ hook, UGC, การใช้เสียง/เพลงกระแส)
   - ให้น้ำหนักแหล่งข้อมูลไทยก่อน (พฤติกรรมผู้บริโภคไทย, เทรนด์ตลาดไทย) แล้วเสริมด้วยเคสต่างประเทศที่ generalize ได้
2. **หยิบตัวอย่างคอนเทนต์ที่ประสบความสำเร็จ** 2-4 ตัวอย่าง (ไม่จำเป็นต้องเป็นร้านอะไหล่โดยตรง — ธุรกิจ SME/eCommerce ที่ปังก็ใช้ได้) แล้ว **teardown** แต่ละตัวอย่างด้วยโครงนี้:
   - Hook คืออะไร (3 วินาทีแรก / ภาพปก)
   - ทำไมคนถึงกด save/share/comment (ไม่ใช่แค่ like)
   - Format ที่ใช้ (Reels, carousel, ภาพนิ่ง, UGC ฯลฯ)
   - ข้อดีที่ดึงมาปรับใช้กับ KAN ได้คืออะไร
3. **แปลงเป็นแผนคอนเทนต์ IG ของ KAN** — เน้น IG ก่อนเป็นช่องทางหลัก (อื่นๆ เช่น Facebook/TikTok ใช้แผนเดียวกันปรับ format รอง):
   - เสนอไอเดียโพสต์ที่ทำได้จริงกับสต็อกสินค้า/ทีมงานร้าน (ไม่ต้องมีโปรดักชันสูง)
   - ระบุ format ที่แนะนำ (Reels/Carousel/Story) พร้อมเหตุผลจาก teardown
   - ตัวอย่าง hook/แคปชันเป็นภาษาไทย ที่ใช้ได้ทันที
   - เชื่อมทุกโพสต์กลับไปที่ CTA เดิมของร้าน (แชทสั่งซื้อผ่าน LINE OA, ราคาส่ง 5 ชิ้นขึ้นไป)
4. **บันทึกผลลัพธ์** เป็นไฟล์ markdown ใหม่ที่ `marketing/content-plans/YYYY-MM-DD-ig-content-plan.md` (ไม่แก้ไฟล์เก่า) โดยใช้โครงสร้างหัวข้อ:
   - สรุปเทรนด์วันนี้ (Trend Radar)
   - Content Teardown (ตัวอย่างที่วิเคราะห์)
   - แผนคอนเทนต์ IG สัปดาห์นี้ (Content Calendar แบบ 5-7 โพสต์ พร้อม format/hook/แคปชันร่าง/CTA)
   - Quick Wins ที่ทำได้วันนี้เลย (ถ้ามี)

## หลักการเลือกไอเดียคอนเทนต์ให้ KAN

- **วิดีโอสั้นมาก่อนภาพนิ่ง** — Reels ที่มี hook 3 วินาทีแรกแรงจะถูกดันให้คนนอกผู้ติดตามเห็น
- **ของจริงจากหน้างานชนะโปรดักชันสวย** — คลิปหยิบอะไหล่ตรงรุ่น เทียบของแท้/เทียบเบอร์ SKU, behind-the-scenes แพ็คของส่งลูกค้า ล้วนน่าเชื่อถือกว่าโฆษณาขายของ
- **แก้ปัญหาที่ลูกค้าค้นหาจริง** — "อะไหล่ตัวนี้ใช้กับรถรุ่นไหนได้บ้าง", "สังเกตยังไงว่าต้องเปลี่ยน", "ของแท้vsของเทียบ" ตอบคำถามที่ลูกค้าพิมพ์หา
- **Save/Share สำคัญกว่า Like** — ทำคอนเทนต์แบบ "เซฟไว้ใช้ตอนรถมีปัญหา" (เช็คลิสต์, อินโฟกราฟิก SKU เทียบรุ่น) เพราะ IG ให้น้ำหนักการแชร์/เซฟมากกว่าไลก์
- **UGC และรีวิวจากลูกค้าจริง** (อู่/ช่างที่ซื้อประจำ) สร้างความน่าเชื่อถือได้ดีกว่าการรีวิวเอง
- **ราคาส่ง 5 ชิ้นขึ้นไปคือจุดขายที่ต้องพูดซ้ำๆ** ในคอนเทนต์ให้กลุ่มอู่/ร้านค้าปลีกเห็นเป็นประจำ

## Output ที่ต้องส่งทุกครั้งที่รัน skill นี้

ไฟล์ markdown 1 ไฟล์ต่อวันใน `marketing/content-plans/` ตามโครงสร้างข้อ 4 ด้านบน — เขียนเป็นภาษาไทย กระชับ นำไปใช้ปฏิบัติได้จริงโดยทีม KAN โดยไม่ต้องตีความเพิ่ม
