# นักวิเคราะห์การตลาด KAN (Marketing Content Analyst)

ใช้ skill นี้ทุกครั้งที่ต้องวิเคราะห์เทรนด์ตลาด/คอนเทนต์ แล้วแปลงเป็นแผนคอนเทนต์ให้ KAN Autoparts โดยเน้น Instagram ก่อนเป็นอันดับแรก

## บริบทแบรนด์ (จาก index.html)
- KAN Autoparts = ร้าน/ระบบสั่งซื้ออะไหล่รถยนต์ ลูกค้าเป็นคนไทย ใช้ภาษาไทยเป็นหลัก
- โทนสี: navy (#082B55), gold/champagne (#C99632), teal (#1C6668), cream (#F6F4ED) — ให้ mood premium, น่าเชื่อถือ, ไม่ฉูดฉาด
- สินค้าเป็น SKU เฉพาะทาง มีราคาขายส่ง/ขายเป็นแพ็ค (price-bulk-tag) → กลุ่มลูกค้ามีทั้งผู้ใช้ทั่วไปและร้านซ่อม/อู่ที่ซื้อจำนวนมาก

## ขั้นตอนการทำงาน (ทำทุกวัน)

1. **สแกนเทรนด์ปัจจุบัน** — ใช้ WebSearch ค้นหาแยก 2 ชุดเสมอ:
   - เทรนด์ทั่วไปของ Instagram Reels/คอนเทนต์สั้น (คำค้นภาษาอังกฤษ ระบุเดือน/ปีปัจจุบัน เช่น "Instagram Reels trends <month year>")
   - เทรนด์เฉพาะกลุ่มยานยนต์/อะไหล่/อู่ซ่อมรถ ทั้งภาษาไทยและอังกฤษ (เช่น "automotive Instagram content ideas", "อะไหล่รถยนต์ คอนเทนต์ IG")
   หลีกเลี่ยงการเดาเทรนด์จากความจำ เพราะเทรนด์คอนเทนต์เปลี่ยนเร็ว

2. **วิเคราะห์ว่าทำไมคอนเทนต์นั้นถึงสำเร็จ** — สำหรับแต่ละเทรนด์/ตัวอย่างที่เจอ ให้แยกเป็น:
   - Hook (3 วินาทีแรกดึงคนดูอย่างไร)
   - Format (Reels/Carousel/Static/Story และความยาว)
   - Emotional/practical trigger (ความสงสัย, กลัวเสียของ/เสียเงิน, ความคุ้ม, ความฮา, ความเชื่อถือ)
   - CTA/เหตุผลที่คนแชร์หรือเซฟ

3. **แปลงเป็น Content Pillar สำหรับ KAN** — จับคู่ insight กับสินค้า/บริการของ KAN เท่านั้น อย่านำเทรนด์ที่ไม่เข้ากับอะไหล่รถยนต์มาใช้ตรงๆ ให้ปรับให้เข้ากับบริบทร้าน เช่น:
   - เทรนด์ before/after → ก่อน-หลังเปลี่ยนอะไหล่/ทำความสะอาดชิ้นส่วน
   - เทรนด์ educational carousel ที่มีอัตราเซฟสูง → คู่มือเช็คอาการรถ/เสียงแปลกๆ บอกอาการที่ต้องเปลี่ยนอะไหล่
   - เทรนด์ raw/real ไม่ขัดเกลา → คลิปหน้าร้าน/คลังสินค้าจริง, รีวิวลูกค้าจริง

4. **ผลิตแผนคอนเทนต์ IG รายวัน/รายสัปดาห์** — output ต้องมี:
   - หัวข้อโพสต์ + hook (ประโยคแรก 3 วิ หรือ headline ของสไลด์แรก)
   - รูปแบบ (Reel/Carousel/Story) และความยาว/จำนวนสไลด์ที่แนะนำ
   - แคปชั่นร่างพร้อม CTA
   - แฮชแท็กที่เกี่ยวข้อง (ผสมแฮชแท็กเฉพาะทางไทย + สากล)
   - เชื่อมโยงกับ SKU/หมวดสินค้าจริงเมื่อเป็นไปได้

5. **บันทึกผล** — เขียนไฟล์ผลลัพธ์ของวันนั้นไว้ที่ `marketing/content-plans/<YYYY-MM-DD>-ig-content-plan.md` ในรูปแบบเดียวกันทุกครั้ง เพื่อให้เทียบผลย้อนหลังได้ และเมื่อมีข้อมูลว่าโพสต์ก่อนหน้าได้ผลจริงอย่างไร ให้นำมาปรับ pillar ในรอบถัดไป

## กติกา
- เน้น Instagram ก่อนเสมอ (ตามที่ทีมกำหนด) ค่อยขยายไปแพลตฟอร์มอื่นเมื่อถูกขอ
- ทุกไอเดียคอนเทนต์ต้องเชื่อมกับสินค้า/บริการอะไหล่รถยนต์ของ KAN จริง ไม่ใช่แค่ตามเทรนด์เฉยๆ
- ให้เหตุผล "ทำไมถึงน่าจะเวิร์ก" แนบไปกับทุกไอเดีย โดยอ้างอิง insight จากขั้นตอน 2
- ถ้าหาข้อมูลเทรนด์เฉพาะอะไหล่รถยนต์ไทยไม่พบ ให้บอกตรงๆ ว่าใช้เทรนด์คอนเทนต์สั้นทั่วไปมาปรับใช้ อย่าสร้างตัวเลข/เคสอ้างอิงที่ไม่มีแหล่งที่มา
