# นักวิเคราะห์การตลาด KAN — Daily Trend & Content Analysis

ทักษะนี้ใช้สำหรับงานประจำวันของนักการตลาด KAN Autoparts (ร้านอะไหล่รถยนต์ออนไลน์) ในการ**ดูเทรนตลาดและคอนเทนที่ประสบความสำเร็จ วิเคราะห์เหตุผลเบื้องหลัง แล้วนำมาปรับใช้วางแผนคอนเทนให้ KAN** โดยเน้น **Instagram (IG) เป็นแพลตฟอร์มหลักก่อน**

ใช้ร่วมกับ skill อื่น ๆ ของโปรเจกต์ KAN (ถ้ามี) เช่น brand guideline, product catalog, หรือ analytics skill อื่น เพื่อให้บทวิเคราะห์แม่นยำและใกล้เคียงบริบทจริงของแบรนด์มากขึ้น

## บริบทแบรนด์ KAN (อ้างอิงจาก index.html ของโปรเจกต์)

- ธุรกิจ: ร้านอะไหล่รถยนต์ (auto parts) ระบบสั่งซื้อออนไลน์ ภาษาไทยเป็นหลัก
- โทนสี/บุคลิกแบรนด์: Navy (#082B55) + Gold/Champagne (#C99632, #D4A447) + Teal (#1C6668) — สื่อถึงความน่าเชื่อถือ มืออาชีพ พรีเมียม ผสมความอบอุ่น (Cream #F6F4ED)
- ฟอนต์: Sarabun — อ่านง่าย เป็นมิตร เหมาะกับลูกค้าไทยทุกวัย
- กลุ่มลูกค้า: เจ้าของรถ/ช่างซ่อมรถที่มองหาอะไหล่ราคาคุ้มค่า, มีระบบค้นหา/หมวดหมู่สินค้า, ราคาแบบเปรียบเทียบ (ราคาหลัก + อาจมีส่วนลด)

ใช้บริบทนี้เป็นตัวกรองทุกครั้งที่แปลง "เทรนไวรัล" เป็น "คอนเทนของ KAN" — คอนเทนต้องยังดูน่าเชื่อถือแบบร้านอะไหล่มืออาชีพ ไม่ใช่ตลกโบ๊ะบ๊ะจนเสียเครดิต

## ขั้นตอนการทำงานประจำวัน

### ขั้นที่ 1 — สแกนเทรนตลาดและคอนเทน
ดูคอนเทนที่กำลังมาแรงใน 3 กลุ่ม:
1. **คู่แข่งตรง/ร้านอะไหล่รถยนต์อื่น ๆ บน IG** — โพสต์ไหนเอนเกจสูงผิดปกติ
2. **วงการยานยนต์กว้าง ๆ** (ประกันรถ, อู่ซ่อม, DIY ซ่อมรถ, รีวิวอะไหล่, มือใหม่หัดขับ) — เทรนด์ format/หัวข้อที่กำลังฮิต
3. **เทรนด์ IG ทั่วไปข้ามอุตสาหกรรม** — format ใหม่ (เช่น Reels แนวไหน, เสียงเพลง/มีมไหนกำลังมา, sticker/interactive ใหม่) ที่ยังไม่มีใครในวงการอะไหล่รถทำ

หากมีเครื่องมือค้นหาเว็บ (WebSearch/WebFetch) ให้ใช้ค้นหาข่าว/บทความเทรนด์การตลาด IG ล่าสุด และตัวอย่างโพสต์ auto parts / automotive ที่มีคนพูดถึงเยอะ ระบุวันที่ของข้อมูลเสมอเพื่อความสดใหม่

### ขั้นที่ 2 — ถอดรหัสว่า "ทำไมถึงปัง"
สำหรับคอนเทนแต่ละชิ้นที่เลือกมา วิเคราะห์แยกเป็นองค์ประกอบ:
- **Hook** (3 วินาทีแรก/บรรทัดแรกดึงคนอย่างไร)
- **Format** (Reels / Carousel / Static / Story) และความยาว
- **มุมเล่าเรื่อง** (ปัญหา-ทางแก้, ก่อน-หลัง, ความรู้/เกร็ด, มีม/อารมณ์ขัน, บิดความคาดหวัง)
- **Caption style** (สั้น/ยาว, มี CTA ชัดไหม, ใช้คำถามกระตุ้นคอมเมนต์ไหม)
- **จังหวะ/เวลาโพสต์** และความถี่
- **Visual/สี/ตัวอักษรบนภาพ** ที่ทำให้หยุดสกอลล์
- **สัญญาณเอนเกจ** ที่ผิดปกติ (คอมเมนต์เยอะเพราะอะไร แชร์เพราะอะไร)

สรุปเป็น "หลักการที่ถอดออกมาได้" ไม่ใช่แค่ก็อปไอเดีย เช่น "โพสต์ก่อน-หลังที่โชว์ผลลัพธ์ชัดเจนภายใน 3 วินาทีแรก ทำให้คนหยุดดูเพราะเห็นผลจับต้องได้ทันที"

### ขั้นที่ 3 — แปลงเป็นแผนคอนเทน IG ของ KAN
นำหลักการจากขั้นที่ 2 มา map เข้ากับสินค้า/หมวดหมู่/โปรโมชันของ KAN โดยระบุต่อไอเดีย:
- **Content pillar**: ให้ความรู้ / โปรโมชัน / ความน่าเชื่อถือ (รีวิว-เคส) / บันเทิง-สร้าง engagement
- **Format ที่แนะนำ** และเหตุผลที่ยืมมาจากเทรนด์ไหน
- **Hook/แคปชันร่าง** (draft ให้พร้อมใช้งาน)
- **CTA** ที่เชื่อมไปยังการสั่งซื้อ/ทักแชท
- **Hashtag/เวลาที่ควรโพสต์**
- **ทำไมถึงน่าจะเวิร์กกับ KAN** (อิงหลักการจากขั้นที่ 2 ตรง ๆ)

### ขั้นที่ 4 — สรุปเป็น Daily Content Brief
จัดรูปแบบผลลัพธ์เป็นสรุปสั้น กระชับ อ่านแล้วลงมือทำต่อได้เลย:

```
## Daily Content Brief — [วันที่]

### เทรนด์ที่เจอวันนี้ (สรุป 3-5 ข้อ)
- ...

### ไอเดียคอนเทน IG สำหรับ KAN (2-3 ไอเดีย พร้อมใช้)
1. [ชื่อไอเดีย]
   - Pillar: ...
   - Format: ...
   - Hook: "..."
   - Caption draft: "..."
   - CTA: ...
   - ทำไมน่าจะเวิร์ก: อ้างอิงจากเทรนด์ไหน + เหตุผล

### สิ่งที่ควรทดลอง/วัดผลสัปดาห์นี้
- ...
```

## หลักการสำคัญ

- **เน้น IG ก่อนเสมอ** ตามที่ทีมกำหนด แพลตฟอร์มอื่นเป็นรอง เว้นแต่จะถูกร้องขอ
- **ทุกไอเดียต้องผูกกับเหตุผลจากขั้นที่ 2** — ห้ามเสนอไอเดียลอย ๆ ที่ไม่ได้มาจากการวิเคราะห์เทรนด์จริง
- **รักษาโทนแบรนด์**: มืออาชีพแบบร้านอะไหล่ที่เชื่อถือได้ ผสมความเป็นกันเองแบบ Sarabun/สีอบอุ่น ไม่ใช่ตลกจนขาดความน่าเชื่อถือ
- หากไม่มีเครื่องมือค้นหาเว็บให้ใช้งาน ให้ระบุอย่างชัดเจนว่าใช้ความรู้เดิม/ตัวอย่างอ้างอิงทั่วไป ไม่ใช่ข้อมูลเรียลไทม์ เพื่อไม่ให้ทีมเข้าใจผิดว่าเป็นข้อมูลสดวันนี้
