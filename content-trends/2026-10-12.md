# KAN Daily IG Trend Brief — 2026-10-12

> หมายเหตุ: ใน repo ยังไม่มีไฟล์ skill.md (นักวิเคราะห์การตลาด/skill อื่นของ KAN) และเข้าถึงข้อมูล IG จริงไม่ได้ (ไม่มีโพสต์/Insights ของคู่แข่งหรือของ KAN) จึงสรุปจากการค้นเว็บทั่วไปเท่านั้น ข้อมูลระดับโพสต์ไวรัลของวงการอะไหล่ในไทย **ยังไม่พบ** — ไม่ได้สร้างตัวอย่างขึ้นเอง

## เทรนด์ที่ยืนยันได้ (Meta Thailand / แหล่งข่าว)
- Reels ที่แชร์ผ่านแชทในไทยคิดเป็น ~85% ของคอนเทนต์ที่ถูกแชร์; การแชร์ผ่าน DM คือ interaction หลัก
- IG เป็นแอปอันดับ 1 สำหรับค้นพบแบรนด์/สินค้าในไทย; ผู้บริโภคไทยถึง ~70% ใช้ DM ประกอบการตัดสินใจซื้อ
- สัญญาณอัลกอริทึม (จากบล็อกการตลาด ยังไม่ใช่เอกสารทางการ): watch time/ดูซ้ำ, saves, sends (แชร์ส่วนตัว) มาก่อนไลก์; ฮุกต้องมาในไม่กี่วินาทีแรก; คอนเทนต์ต้นฉบับได้เปรียบ

## ทำไมคอนเทนต์แนวนี้ถึงสำเร็จ → นำมาปรับใช้กับ KAN
| หลักการ | ไอเดียคอนเทนต์ KAN (IG) |
|---|---|
| Save-worthy: สอน/เช็กลิสต์ | "5 อาการที่ต้องเปลี่ยนผ้าเบรก", ตารางเช็กระยะเปลี่ยนอะไหล่ (Carousel) |
| Send-worthy: คนอยากส่งให้เพื่อน/ช่าง | "อะไหล่ตัวนี้ใช้กับรุ่นไหนได้บ้าง" ให้ส่งต่อใน DM |
| ฮุกเร็ว + ภาพจริง | คลิปเทียบของแท้ vs ของเทียบ ใกล้ๆ ใน 3 วิแรก, แกะกล่อง/แพ็กออเดอร์จริง |
| ความน่าเชื่อถือ | ถ่ายหน้างานจริงของร้าน ไม่ใช้คลิปสำเร็จรูป |
| DM = ช่องทางปิดการขาย | CTA "ส่งรุ่นรถ/ปีมาใน DM เราเช็กอะไหล่ให้" |
| Reels ดึงคนใหม่, Carousel สร้างความเชื่อใจ | สัปดาห์ละ 3 Reels + 1–2 Carousel |

## แผนคอนเทนต์เสนอ 3 วันข้างหน้า
1. Reel 15–20 วิ: "ของแท้ vs ของเทียบ" ชิ้นเดียวที่ขายดีที่สุด — ฮุก: ภาพชิ้นส่วนใกล้ๆ
2. Carousel: เช็กลิสต์อาการ → อะไหล่ที่ต้องเปลี่ยน (ท้ายสไลด์ CTA DM)
3. Reel 45 วิ: ขั้นตอนเช็กเลขชิ้นส่วนให้ตรงรุ่นก่อนสั่ง
