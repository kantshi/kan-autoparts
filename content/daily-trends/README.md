# Daily IG Trend Brief (KAN Autoparts)

รูทีนรายวัน: ดูเทรนตลาด/คอนเทนต์ IG → วิเคราะห์ว่าทำไมคอนเทนต์ถึงเวิร์ก → ปรับเป็นไอเดียคอนเทนต์ KAN
ไฟล์ผลลัพธ์: `content/daily-trends/YYYY-MM-DD.md`

## Framework วิเคราะห์ (ใช้ทุกวัน)
1. **Trend scan** – แพลตฟอร์ม/อัลกอริทึม, ฟอร์แมตที่กำลังขึ้น, เทรนตลาดรถ/อะไหล่ในไทย
2. **Why it worked** – Hook 3 วินาทีแรก, คุณค่า (ให้ความรู้/ขำ/แก้ปัญหา), เหตุผลที่คนเซฟ/ส่ง DM, ความสัมพันธ์กับ search intent
3. **Adapt for KAN** – แปลงเป็น 3 ไอเดีย (Reel / Carousel / Story) พร้อม hook, CTA ไป LINE/DM
4. **Measure** – KPI: views, saves, shares (DM), DM inquiries
- Brand: ราคา/สต็อก/ความน่าเชื่อถือของอะไหล่, โทนสี navy-gold (ดู index.html)
