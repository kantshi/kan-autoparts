# KAN Autoparts — คู่มือนักวิเคราะห์การตลาด (Marketing Analyst Skill)

> ใช้เป็น "สคิล" ประจำตัวของนักการตลาด KAN สำหรับงานวิเคราะห์เทรนด์ + วางแผนคอนเทนต์รายวัน
> โฟกัสหลักตอนนี้: **คอนเทนต์ Instagram (Reels + Feed)**
> อัปเดตไฟล์นี้เมื่อเจอข้อค้นพบใหม่ที่ควรจำไว้ใช้ซ้ำ

---

## 1. KAN คือใคร (บริบทที่ต้องจำ)

- ธุรกิจ: **ร้านอะไหล่รถยนต์** ขายทั้งปลีกและส่ง (มีราคาส่งเมื่อซื้อ ≥ 5 ชิ้น)
- ช่องทางปิดการขาย: **LINE OA** (`@617ytnjm`) + เว็บสั่งซื้อ (index.html)
- กลุ่มลูกค้า 3 ขา:
  1. **เจ้าของรถทั่วไป (ปลีก)** — อยากประหยัด, ซ่อมเอง, กลัวโดนโก่งราคา
  2. **อู่/ช่าง (ส่ง)** — ซื้อซ้ำ, สนใจราคาส่ง + ของมีสต็อก + ส่งไว
  3. **ร้านขายต่อ (reseller)** — กำไรต่อชิ้น + ของไม่ขาด
- โทนแบรนด์: น้ำเงินกรมท่า + ทอง + ครีม = ดูน่าเชื่อถือ พรีเมียมแต่เข้าถึงง่าย
- บทบาท IG: **สร้างการรับรู้ + ความน่าเชื่อถือ แล้วส่งคนไป LINE** (IG ไม่ใช่หน้าปิดการขาย แต่เป็นหน้าสร้างความไว้ใจ)

---

## 2. งานประจำวัน (ทำซ้ำทุกวัน)

1. **อ่านเทรนด์** — ดู format/เสียง/หัวข้อที่กำลังมาบน Reels + คอนเทนต์สายรถ (CarTok/car detailing/DIY)
2. **เลือกคอนเทนต์ที่ "ปัง" 2–3 ชิ้น** แล้ว **วิเคราะห์ว่าทำไมถึงปัง** (ใช้เฟรมเวิร์กข้อ 3)
3. **ถอดจุดแข็ง → ปรับใช้กับ KAN** (ใช้ Content Pillars ข้อ 4)
4. **ส่งมอบ**: รายงานสั้น + ปฏิทินคอนเทนต์ IG ที่พร้อมถ่าย/โพสต์ (hook + แคปชัน + แฮชแท็ก)
5. **บันทึก** ลง `marketing/daily/YYYY-MM-DD.md` เพื่อให้วันถัดไปต่อยอดได้ (ไม่เริ่มใหม่ทุกวัน)

---

## 3. เฟรมเวิร์ก "ทำไมคอนเทนต์นี้ถึงปัง" (วิเคราะห์ทุกชิ้น)

ตอบ 6 ข้อนี้กับคอนเทนต์ตัวอย่างทุกชิ้น:

| # | คำถาม | มองหาอะไร |
|---|-------|-----------|
| 1 | **Hook (3 วิแรก)** | หยุดนิ้วคนได้ยังไง — คำถามค้างคา / เคลมแรง / ปัญหาที่ตรงใจ |
| 2 | **อารมณ์หลัก** | สงสัย / สะใจ (satisfying) / กลัวพลาด / ได้ความรู้ / ตลก |
| 3 | **คุณค่าที่ได้** | เซฟไว้ใช้ได้ (how-to) / ส่งต่อให้เพื่อน (relatable) / อยากคอมเมนต์ |
| 4 | **โปรดักชัน** | ดิบ/จริง (มือถือ) มักชนะเนี้ยบเกินจริง — ของสายรถเน้น "เห็นของจริง" |
| 5 | **ความยาว + จังหวะ** | สั้น 8–30 วิ รีวอตช์ได้ = ไปไกลกว่าผู้ติดตาม |
| 6 | **ทำไมคนแชร์/เซฟ** | สัญญาณแรงสุดคือ **DM share + save** → คอนเทนต์ "ต้องส่งให้เพื่อนที่มีรถ" |

> หลัก: ถ้าถอดได้ว่า "จุดแข็ง" คืออะไร (เช่น curiosity gap, before/after, สอนทำเอง) ให้ **ก๊อปโครงสร้าง ไม่ใช่ก๊อปหัวข้อ** แล้วใส่สินค้า/บริบทของ KAN ลงไป

---

## 4. Content Pillars ของ KAN (หมุน 6 เสานี้)

1. **สอนให้รู้ (Educational)** — "อะไหล่ตัวนี้คืออะไร เสียเมื่อไหร่ เปลี่ยนเองได้ไหม" → คนเซฟเยอะ
2. **อาการ → สาเหตุ (Symptom→Part)** — "เสียงแบบนี้ = อะไหล่ตัวไหนใกล้พัง" → สงสัย + ใช้ได้จริง
3. **ก่อน/หลัง + ติดตั้ง (Before/After)** — โชว์ของจริงตอนเปลี่ยน = สะใจ รีวอตช์ได้
4. **ของแท้ vs เทียบ / กันโดนหลอก (Trust)** — "ดูยังไงว่าอะไหล่แท้" → สร้างความน่าเชื่อถือ
5. **ราคาส่ง/คุ้ม (Value, สำหรับอู่/ช่าง)** — ไม่ขายโต้ง ๆ ใช้มุม "ช่างซื้อแบบนี้ประหยัดกว่า"
6. **หลังร้าน/คลัง (BTS)** — โชว์สต็อก ความพร้อมส่ง ทีมงาน = ความไว้ใจ

**กติกา 80/20:** 80% ให้คุณค่า/ความรู้/ความบันเทิง, 20% ขายตรง — ห้ามโพสต์แต่โปรโมชัน

---

## 5. เช็กลิสต์โพสต์ IG ที่ดี (ก่อนปล่อยทุกชิ้น)

- [ ] Hook ชัดใน 1–2 วิแรก (ข้อความบนจอ + ปากพูด)
- [ ] Reels สั้น < 30 วิ (เริ่มต้น) / ไม่เกิน 3 นาที เพื่อให้ถูกดันออกนอกผู้ติดตาม
- [ ] เสียงเทรนด์ที่ใช้ได้เชิงพาณิชย์ (เลี่ยงปัญหาลิขสิทธิ์สำหรับบัญชีธุรกิจ)
- [ ] มี CTA เบา ๆ ชี้ไป LINE OA (`@617ytnjm`) — "ทักไลน์เช็กของ/เช็กราคา"
- [ ] แฮชแท็กเฉพาะเจาะจง ~5–10 แท็ก (เลี่ยงแท็กกว้างล้วน ๆ)
- [ ] โพสต์สม่ำเสมอ 3–4 Reels/สัปดาห์ (สม่ำเสมอ > ถี่แล้วหมดแรง)
- [ ] ตอบคอมเมนต์เร็วใน 1–2 ชม.แรก (ช่วยการกระจาย)

---

## 6. Metric ที่ดู (เรียงความสำคัญ)

1. **Shares / Sends (DM)** — สัญญาณกระจายแรงสุด
2. **Saves** — คอนเทนต์ "มีประโยชน์" (สายสอน/how-to)
3. **Watch time / rewatch** — hook + ความยาวดี
4. Reach จากคนที่ไม่ได้ติดตาม — คอนเทนต์หลุดออกนอกวงหรือยัง
5. Comments — มีส่วนร่วม + ได้ไอเดียคอนเทนต์ต่อ
6. ทักเข้า LINE / คลิก — ปลายทางที่เป็นเงิน

> ไลก์/ยอดผู้ติดตาม = vanity metric อย่าตัดสินด้วยตัวเดียว
