# KAN Marketing – Daily IG Trend Routine

ทุกวัน: ดูเทรนด์ตลาด + คอนเทนต์ IG → วิเคราะห์ว่าทำไมถึงสำเร็จ → ปรับเป็นแผนคอนเทนต์ KAN
รายงานเก็บที่ `marketing/daily-trends/YYYY-MM-DD.md`

หมายเหตุ: ใน repo ยังไม่มีไฟล์ SKILL.md ของ "นักวิเคราะห์การตลาด" หรือ skill อื่นของ project KAN
หากเพิ่มไฟล์ไว้ที่ `marketing/skills/*.md` รอบถัดไปจะนำมาใช้เป็นกรอบวิเคราะห์อัตโนมัติ

## กรอบวิเคราะห์ (ใช้จนกว่าจะมี skill จริง)
1. Hook (3 วินาทีแรก) 2. Format 3. Value (ให้ความรู้/แก้ปัญหา/ความน่าเชื่อถือ) 4. CTA 5. เหตุผลที่สำเร็จ 6. วิธีปรับใช้กับ KAN
