# 📣 KAN Marketing — ระบบวิเคราะห์เทรนด์ & คอนเทนต์รายวัน

งานนักการตลาดอัตโนมัติประจำวันของ KAN Autoparts — ดูเทรนด์ตลาด + คอนเทนต์ วิเคราะห์ว่า
"ทำไมคอนเทนต์นั้นถึงสำเร็จ" แล้วนำบทเรียนมาวางแผนคอนเทนต์ให้ KAN **โฟกัส Instagram ก่อน**

## โครงสร้าง
- **`playbook-marketing-analyst.md`** — คู่มือ/skill ของนักวิเคราะห์การตลาด (วิธีทำงานทุกวัน, หลักการคอนเทนต์, KPI) ← เริ่มอ่านที่นี่
- **`daily/YYYY-MM-DD.md`** — รายงานรายวัน: สรุปเทรนด์ + ถอดรหัสเคสเด่น + แผนคอนเทนต์ IG + ปฏิทิน + KPI

## รันรอบถัดไปควรทำ
1. อ่าน `playbook-marketing-analyst.md`
2. ทำตาม Step A–D แล้วบันทึกไฟล์ใหม่ใน `daily/`
3. เทียบกับไฟล์ของเมื่อวาน — อย่าเสนอไอเดียซ้ำ, ต่อยอดสิ่งที่ได้ผล
