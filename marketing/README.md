# marketing/ — ระบบนักวิเคราะห์การตลาดประจำวันของ KAN

รูทีนอัตโนมัติรายวัน: สแกนเทรนด์ตลาด+คอนเทนต์ → ถอดรหัสว่าทำไมคอนเทนต์นั้นปัง → แปลงเป็นแผนคอนเทนต์ **Instagram** ของ KAN

- `analyst-playbook.md` — คู่มือ/วิธีคิดของนักวิเคราะห์ (แก้เพิ่มได้) + คลังไอเดียที่ใช้ไปแล้ว
- `daily/YYYY-MM-DD-ig-content-analysis.md` — ผลวิเคราะห์ + แผนคอนเทนต์รายวัน

**อยากให้แม่นขึ้น:** เปิด IG Insights จริงของเพจ KAN (โพสต์ไหนเซฟ/แชร์เยอะ) มาป้อนให้นักวิเคราะห์ แล้วแผนจะอิงของจริงแทนเทรนด์ทั่วไป
