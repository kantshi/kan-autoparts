# KAN Marketing — Content Plans

Daily trend analysis and Instagram content plans for KAN Autoparts,
produced by the `marketing-analyst` skill (`.claude/skills/marketing-analyst/SKILL.md`).

Each file in `content-plans/` is one day's trend scan plus ready-to-shoot
IG content ideas, named `YYYY-MM-DD.md`. `content-plans/TEMPLATE.md` is
the structure new entries follow.
