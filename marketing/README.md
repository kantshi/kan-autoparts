# KAN Autoparts — คอนเทนต์การตลาด (Marketing)

โฟลเดอร์นี้คือ "โต๊ะทำงานของนักวิเคราะห์การตลาด" ของ KAN รันอัตโนมัติทุกวัน
เพื่อ **ดูเทรนด์ตลาด + คอนเทนต์ที่ปัง → วิเคราะห์ว่าทำไมมันถึงสำเร็จ → แปลงเป็นแผนคอนเทนต์ IG ให้ KAN**

## โครงสร้าง
- `playbook.md` — คู่มือหลัก (living document) เทรนด์ที่ยืนยันแล้ว, สูตรคอนเทนต์ที่ได้ผล,
  เสาหลักคอนเทนต์ (content pillars) ของ KAN และบทเรียนที่สะสมขึ้นเรื่อย ๆ **อ่านไฟล์นี้ก่อน**
- `daily/YYYY-MM-DD.md` — รายงานประจำวัน: สแกนเทรนด์วันนั้น + วิเคราะห์ว่าทำไมคอนเทนต์ตัวอย่างถึงปัง
  + ไอเดีย Reel พร้อมถ่ายของสัปดาห์นั้น

## โฟกัสปัจจุบัน
**Instagram Reels ก่อน** (ตามที่สั่ง) — เพราะเป็นฟอร์แมตที่คนไทยใช้ดูมากที่สุดบน IG
ค่อยขยายไป TikTok / Facebook ทีหลัง

## ข้อจำกัดที่ต้องรู้ (เพื่อให้ตัวเลขแม่นขึ้นในอนาคต)
- ตอนนี้ยังไม่ได้เชื่อม Instagram Insights / คอนเนกเตอร์โซเชียล → ตัวเลข engagement จริงของ KAN
  ยังดูไม่ได้ การวิเคราะห์จึงอิงเทรนด์อุตสาหกรรม + งานวิจัยตลาดไทยเป็นหลัก
- ถ้าเชื่อม IG Insights หรือส่งออกยอดวิว/ยอดไลก์ของโพสต์ KAN มาได้ จะวิเคราะห์ "คอนเทนต์ของเราเอง"
  ตัวไหนปัง-ไม่ปัง ได้แม่นขึ้นมาก
