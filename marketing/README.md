# KAN Autoparts — การตลาด & คอนเทนต์ (Marketing)

โฟลเดอร์นี้เก็บงานของ "นักวิเคราะห์การตลาด" ที่รันทุกวันแบบอัตโนมัติ เพื่อ:
1. ดูเทรนด์ตลาด + คอนเทนต์ที่ประสบความสำเร็จบนโซเชียล (เน้น **Instagram** ก่อน)
2. วิเคราะห์ว่า **ทำไม** คอนเทนต์นั้นถึงปัง (ถอดสูตร ไม่ใช่แค่ลอกเลียน)
3. นำข้อดีมาปรับใช้กับแผนคอนเทนต์ IG ของ KAN แบบลงมือทำได้จริง

## โครงสร้าง
- `playbook.md` — คู่มือ/สกิลของนักวิเคราะห์การตลาด (วิธีทำงานแต่ละวัน + สูตรที่พิสูจน์แล้ว). รันทุกวันให้ยึดไฟล์นี้
- `daily/YYYY-MM-DD-ig-content-analysis.md` — รายงานประจำวัน: เทรนด์ + บทวิเคราะห์ + ไอเดียโพสต์สำหรับ KAN
- `playbook.md` อัปเดตได้เมื่อเจอสูตรใหม่ที่เวิร์ก (เก็บความรู้สะสม)

- ร้านอะไหล่รถยนต์ (ปลีก/ส่ง) — มีราคาส่ง/ราคาเหมา
- ขาย/ปิดการขายผ่าน **LINE OA** (`@617ytnjm`) + เว็บแคตตาล็อกบนมือถือ
- ลูกค้า: เจ้าของรถ, ช่าง/อู่, ร้านอะไหล่รายย่อยที่ซื้อไปขายต่อ
- แบรนด์โทน: น้ำเงินกรมท่า + ทอง (ดูพรีเมียม น่าเชื่อถือ)
