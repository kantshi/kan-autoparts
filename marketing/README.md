# KAN Autoparts — Marketing Analyst (Daily)

เอกสารนี้คือ "คู่มือการทำงาน" ของนักวิเคราะห์การตลาดประจำวันของ KAN
(ใช้แทน/เสริม `skill.md` ของนักวิเคราะห์การตลาดที่พูดถึงในโปรเจกต์ KAN)
ทุกวันระบบจะรันอัตโนมัติเพื่อ **ดูเทรนด์ตลาด + คอนเทนต์ที่ประสบความสำเร็จ → วิเคราะห์ว่าทำไมถึงสำเร็จ → แปลงเป็นแผนคอนเทนต์ IG ของ KAN**

---

## 1. KAN คือใคร (บริบทที่ต้องยึดทุกครั้ง)

| หัวข้อ | รายละเอียด |
|---|---|
| ธุรกิจ | ร้าน/ตัวแทนจำหน่าย **อะไหล่รถยนต์** ในไทย (B2B ช่าง/อู่ + B2C เจ้าของรถ) |
| ช่องทางสั่งซื้อ | แคตตาล็อกมือถือ (เว็บแอป) → ปิดการขายผ่าน **LINE OA** |
| ลูกค้าหลัก | ช่าง / อู่ซ่อม / ร้านอะไหล่รายย่อย / เจ้าของรถสาย DIY |
| จุดขายที่ต้องสื่อ | ของแท้/คุณภาพเชื่อถือได้, ราคาส่ง-ปลีกชัดเจน, หาอะไหล่ง่าย, สั่งผ่าน LINE สะดวก |
| โทนแบรนด์ (จากแอป) | พรีเมียม-น่าเชื่อถือ: กรมท่า (navy `#082B55`), ทอง (`#C99632`), เขียวหัวเป็ด (`#1C6668`), ครีม (`#F6F4ED`) |
| Platform โฟกัส | **Instagram ก่อน** (Reels เป็นหลัก) แล้วค่อยขยายไป TikTok/FB |

> ❗ คอนเทนต์ทุกชิ้นต้องจบที่ **CTA ไป LINE OA** (ทักแชต/เช็กราคา/สั่งของ) เพราะนั่นคือจุดปิดการขายจริงของ KAN

## 2. ทำอะไรทุกวัน (Routine)

1. **สแกนเทรนด์** — คอนเทนต์สายรถ/อะไหล่/ดีเทลลิ่งที่กำลังเวิร์กบน IG Reels (ไทย + เทศ) และเบนช์มาร์กวงการ
2. **วิเคราะห์ "ทำไมถึงสำเร็จ"** — ถอดโครงว่าชิ้นนั้นเวิร์กเพราะ *หลักการ* อะไร (hook, อารมณ์, ความพึงพอใจทางสายตา, social proof ฯลฯ) ไม่ใช่แค่ "คลิปสวย"
3. **แปลงเป็นของ KAN** — เปลี่ยนหลักการนั้นเป็นไอเดีย Reels ที่ KAN ถ่ายเองได้จริงด้วยสินค้า/หน้าร้าน/ช่างที่มี พร้อม hook + แคปชัน + CTA
4. **บันทึก** — เขียนรายงานลง `reports/YYYY-MM-DD-*.md` และอัปเดต playbook เมื่อเจอหลักการใหม่
5. **แจ้งเตือน** — ส่งสรุป + ท็อปไอเดียของวันเข้ามือถือเจ้าของ

## 3. ไฟล์ในโฟลเดอร์นี้

- `README.md` — คู่มือนี้
- `kan-ig-content-playbook.md` — **คลังสูตรคอนเทนต์ที่พิสูจน์แล้ว** ปรับเป็นของ KAN (สะสมเพิ่มทุกวัน)
- `reports/YYYY-MM-DD-*.md` — รายงานวิเคราะห์ + แผนคอนเทนต์รายวัน

## 4. หลักยึดเวลาแปลงเทรนด์เป็นคอนเทนต์ KAN
- **สัดส่วนคอนเทนต์ 40/30/20/10** — สินค้า 40% / ให้ความรู้ 30% / รีวิว-social proof 20% / ความเป็นแบรนด์ 10%
- **ความสม่ำเสมอ > จำนวน** — ตั้งเป้า Reels 4–5 ชิ้น/สัปดาห์ ทำได้จริงดีกว่าถี่แล้วหาย
- **3 วินาทีแรกคือทุกอย่าง** — เปิดด้วยภาพ "after" หรือปัญหาที่เห็นชัด อย่าเปิดด้วย "สวัสดีครับวันนี้..."
- **วัดผลที่ shares & saves + ยอดทัก LINE** ไม่ใช่แค่ยอดไลก์
