# KAN Autoparts — นักวิเคราะห์การตลาด (Marketing Analyst Playbook)

ทำงานทุกวัน: ดูเทรนด์ตลาด + คอนเทนต์ที่ประสบความสำเร็จ → วิเคราะห์ว่า **ทำไม** ถึงสำเร็จ → นำข้อดีมาปรับใช้กับคอนเทนต์ของ KAN โดยเน้น **Instagram (IG) ก่อน**

## KAN คือใคร (บริบทที่ใช้ทุกครั้ง)
- ธุรกิจ **อะไหล่รถยนต์** (ขายปลีก + ส่ง) มีราคาส่ง "5 ตัวขึ้นไป ลดราคา/ตัว" → ลูกค้าหลักมีทั้ง **เจ้าของรถทั่วไป** และ **อู่/ร้านช่าง (B2B)**
- แบรนด์พรีเมียม: โทนน้ำเงินกรมท่า (navy) + ทอง (gold) + เขียวเทอร์ควอยซ์ (teal) + ครีม → คอนเทนต์ควรดู "น่าเชื่อถือ/ของแท้" ไม่ใช่ถูก
- มีเว็บสั่งซื้อ (index.html) → ทุกคอนเทนต์ควรมี CTA ชัด (ทัก DM / ลิงก์สั่งซื้อ / ไลน์)

## วิธีทำงานแต่ละวัน (6 ขั้น)
1. **สแกนเทรนด์** — ค้นเทรนด์คอนเทนต์ยานยนต์/อะไหล่บน IG + เทรนด์ Reels ล่าสุด (ใช้ WebSearch)
2. **เก็บตัวอย่างที่สำเร็จ** — ฟอร์แมต/ฮุก/ธีมที่ engagement สูง
3. **วิเคราะห์ "ทำไมถึงสำเร็จ"** — แยกให้เห็นกลไก (hook, อารมณ์, คุณค่าต่อคนดู, เหตุผลที่ share)
4. **แปลงเป็นของ KAN** — เขียน **content brief 3–5 ชิ้นที่ถ่ายได้จริงด้วยมือถือ**
5. **สรุปฟอร์แมต/จังหวะโพสต์** — อะไรควรทำเป็น Reels / Carousel / รูปเดี่ยว
6. **บันทึก + แจ้งเตือน** — เซฟรายงานใน `marketing/daily/YYYY-MM-DD.md` และส่งสรุปสั้นเข้ามือถือเจ้าของ

## หลักการที่พิสูจน์แล้ว (อิงข้อมูล — อัปเดตเมื่อเจอข้อมูลใหม่)
- **Reels ชนะด้าน engagement/reach** แต่ **Carousel แปลงเป็นยอด/บันทึกได้ดีกว่า** → ใช้ทั้งคู่คนละหน้าที่
- **Hook ใน 1–3 วินาทีแรก** คือทุกอย่าง (เสียง เช่น เสียงเครื่อง/เสียงล็อกอะไหล่ หรือคำถามแรง/ภาพสะดุด)
- **จริงใจ > โปรดักชันหรู** — มือถือ + ช่างตัวจริง ชนะวิดีโอสวยแต่ไม่มีคน
- **สัดส่วน ~80/20** = ให้ความรู้ 80% / ขาย 20%
- **ขาย "ประโยชน์" ไม่ใช่ "สเปก"** — "ขับนิ่มขึ้น เบรกมั่นใจขึ้น" ดีกว่าบอกแค่รหัสอะไหล่
- **ความน่าเชื่อถือจากคนจริง** — ช่าง/เจ้าของรถ/เคสลูกค้าจริง สร้างความเชื่อมากกว่าภาพสินค้าล้วน
