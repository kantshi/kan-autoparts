## วิธีทำงานประจำวัน (กรอบการวิเคราะห์)

ทุกวันทำ 4 ขั้น แล้วบันทึกไฟล์ลง `marketing/daily/YYYY-MM-DD.md`

### 1) สแกนเทรนด์ (Trend Scan)
- เทรนด์ Instagram/Reels ล่าสุด (ฟอร์แมต, ความยาว, ออดิโอ, อัลกอริทึม)
- คอนเทนต์สายรถ/อะไหล่/อู่ ที่กำลังมาหรือเพิ่งไวรัล (ไทย + ต่างประเทศ)
- บริบทตลาด/เศรษฐกิจที่กระทบพฤติกรรมคนซื้ออะไหล่

### 2) วิเคราะห์ว่าทำไมสำเร็จ (Why It Works)
สำหรับคอนเทนต์/เทรนด์ที่เด่น ถอดออกมาเป็น "ปัจจัยความสำเร็จ" ที่หยิบไปใช้ต่อได้ เช่น
- Hook 3 วินาทีแรก, อารมณ์ที่กระตุ้น (อยากรู้/กลัวพลาด/ฮา)
- รูปแบบที่ทำให้คน **เซฟ/แชร์/ทักแชท** (สัญญาณที่อัลกอริทึมชอบ)
- ความจริง/ความน่าเชื่อถือ (คนจริง หน้าร้านจริง ช่างจริง)

### 3) แปลงเป็นแผนคอนเทนต์ KAN (Apply to KAN)
ปัจจัยความสำเร็จ → ไอเดียโพสต์ IG ที่ผูกกับสินค้า/จุดขายจริงของ KAN
พร้อม: ฟอร์แมต (Reel/Carousel/Story), Hook, แคปชัน, CTA (ปิดที่ "ทักไลน์ KAN")

### 4) ส่งมอบ (Deliver)
- บันทึกไฟล์วันนั้น + อัปเดต log ด้านล่าง
- commit + push
- แจ้งเตือนสรุป insight + คอนเทนต์ที่ควรทำวันนี้

## หลักคิดประจำของ KAN (ตกผลึกจากการวิเคราะห์)

หลักเหล่านี้คือ "สูตร" ที่ให้ใช้เป็นค่าตั้งต้นทุกวัน (ปรับตามเทรนด์ใหม่ได้):

1. **ช่วยเหลือ > ไวรัล** — ร้านอะไหล่ชนะด้วยคอนเทนต์ที่ "มีประโยชน์จริง" ไม่ใช่ตลกอย่างเดียว คนเซฟไว้ใช้ = อัลกอริทึมดัน + สร้างความเชื่อถือ
2. **ความน่าเชื่อถือ = จุดตัดสินใจซื้ออะไหล่** — คนไทยกลัวของปลอม/ของเทียบไม่ตรงรุ่น คอนเทนต์ "แท้ vs ปลอม / ดูยังไงให้ตรงรุ่น" ทรงพลังมาก
3. **คอนเทนต์ประหยัดเงิน/เตือนภัยมาแรง** — "อย่าเพิ่งเปลี่ยนทั้งชุด", "เสียงแบบนี้ = ต้องเช็กอะไหล่ตัวไหน", เทียบราคาศูนย์ vs ร้าน
4. **ของจริงหน้าร้านขายได้** — คลังสินค้า, แพ็กของ, ช่าง/พนักงานจริง สร้าง trust มากกว่าภาพสต็อกสวยๆ
5. **ปิดการขายที่แชท** — ทุกโพสต์จบด้วย CTA ทักไลน์ KAN (สัญญาณ DM/แชร์ดันการเข้าถึงคนนอกผู้ติดตาม)
6. **ฟอร์แมต:** Reel 30–60 วิ เพื่อ reach, Carousel เช็กลิสต์/วิธีทำ เพื่อ saves, Story เพื่อโปร/ของเข้าใหม่

## ส่วนผสมคอนเทนต์รายสัปดาห์ (ค่าแนะนำ)
- 40% มีประโยชน์/สอน (วิธีดูอะไหล่, แท้ vs ปลอม, ตรงรุ่นไหม)
- 20% เตือนภัย/ประหยัดเงิน
- 20% ของจริง/เบื้องหลังร้าน + รีวิวลูกค้า
- 20% สินค้า/โปร/ของเข้าใหม่
