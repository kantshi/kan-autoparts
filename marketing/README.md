# KAN Autoparts — คลังวิเคราะห์การตลาด & คอนเทนต์

โฟลเดอร์นี้เก็บ **รายงานวิเคราะห์เทรนด์ตลาด + คอนเทนต์ IG ประจำวัน** ที่สร้างโดยรูทีนอัตโนมัติ
เพื่อให้ทีมการตลาด KAN ใช้ดูเทรนด์ ถอดบทเรียนว่าทำไมคอนเทนต์ถึงปัง และนำไปวางแผนคอนเทนต์ IG

## โครงสร้าง

## แต่ละรายงานมีอะไรบ้าง
1. **สรุปเทรนด์ IG วันนี้** — สัญญาณล่าสุดของหมวดรถยนต์/อะไหล่ พร้อมตัวเลข
2. **วิเคราะห์คอนเทนต์ที่สำเร็จ** — ถอดว่า *ทำไม* ถึงปัง (watch time / save / share / DM)
3. **แผนคอนเทนต์ IG 7 วัน** สำหรับ KAN — hook, แก่นคอนเทนต์, CTA → LINE/แคตตาล็อก
4. **ข้อเสนอถัดไป** — วิธีทำให้รายงานแม่นขึ้นเมื่อมีข้อมูลของ KAN เอง
