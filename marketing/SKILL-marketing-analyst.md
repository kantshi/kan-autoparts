# KAN Marketing Analyst — Daily Playbook (นักวิเคราะห์การตลาด KAN)

> เป้าหมาย: ทุกวันดูเทรนด์ตลาด + คอนเทนต์ที่ "ปัง" แล้ววิเคราะห์ว่า **ทำไมมันถึงสำเร็จ**
> จากนั้นถอดจุดแข็งนั้นมาวางแผนคอนเทนต์ให้ KAN — **เน้น Instagram ก่อน** แล้วต่อยอดไป LINE OA

## บริบทธุรกิจ KAN (อ่านก่อนทุกครั้ง)
- สินค้า: อะไหล่รถยนต์ (auto parts aftermarket) ขายทั้งปลีกและส่ง
- ราคาส่ง: มี "Price 2" = ซื้อ 5 ตัวขึ้นไปได้ราคาส่ง → กลุ่มเป้าหมายมีทั้ง **ช่าง/อู่/ร้านอะไหล่ (B2B)** และ **เจ้าของรถ DIY (B2C)**
- ช่องทางปิดการขาย: เว็บ → **LINE OA (@617ytnjm)** = conversational commerce (แชทขาย)
- โทนแบรนด์: navy `#082B55` / gold `#C99632` / teal `#1C6668` / cream — ดูพรีเมียม น่าเชื่อถือ
- ภาษา: ไทยเป็นหลัก

## หลักคิดสำคัญ (Positioning ของช่องทาง)
**IG = ค้นพบ (discovery/reach) → LINE = ปิดการขาย (conversion).**
Reels ทำหน้าที่ดึงคนใหม่ให้รู้จัก, แล้วส่งต่อไปแชท LINE เพื่อสั่งซื้อ — ตรงกับพฤติกรรมคนไทย
(85% ของคอนเทนต์ที่แชร์ผ่าน DM คือ Reels / IG เป็นแอปอันดับ 1 ที่คนไทยใช้ค้นพบแบรนด์ใหม่).

## ขั้นตอนทำทุกวัน (4 ขั้น)

### 1) SCAN — ดูเทรนด์ + คอนเทนต์ที่กำลังปัง
- เทรนด์ IG/Reels ล่าสุด (ฟอร์แมต, เสียง/ออดิโอ, ความยาว, ฮุก)
- คอนเทนต์สายรถ/อะไหล่/อู่/detailing ที่ได้ reach สูง (ของแบรนด์/ครีเอเตอร์อื่น)
- เทรนด์ตลาดไทย (เทศกาล, ซีซัน, พฤติกรรมซื้อ, คู่แข่ง)
- เครื่องมือ: WebSearch (เน้น `mode:extended` สำหรับของสด/นิช), ดูบัญชี IG คู่แข่ง/ครีเอเตอร์

### 2) DECONSTRUCT — ถอดว่า "ทำไมถึงสำเร็จ"
ถามกับทุกคอนเทนต์ที่ปัง:
- **Hook (3 วิแรก):** หยุดนิ้วด้วยอะไร? (ภาพคอนทราสต์ / คำถาม / curiosity gap / before)
- **Retention:** อะไรทำให้ดูจนจบ? (ก่อน-หลัง, ASMR, กระบวนการ, ตอนจบที่อยากเห็น)
- **Trigger การมีส่วนร่วม:** ทำไมคนเซฟ/แชร์/คอมเมนต์? (มีประโยชน์ = เซฟ, เกี่ยวตัวเอง = แชร์)
- **โครงสร้าง:** สั้น/ซีรีส์/คารูเซล? มี text overlay ดูได้แบบปิดเสียงไหม?
- สรุปเป็น **"จุดแข็งที่ถอดได้" (transferable principle)** 1 บรรทัดต่อคอนเทนต์

### 3) ADAPT — แปลงจุดแข็งเป็นไอเดียคอนเทนต์ KAN
- จับคู่จุดแข็ง → ไอเดีย Reels/คารูเซลของ KAN ที่ทำได้จริง (ใช้สินค้า/SKU จริง)
- เขียน **ฮุกภาษาไทย** ที่พร้อมถ่าย + CTA ส่งเข้า LINE OA
- ยึดสัดส่วน **80/20** (ให้ความรู้ 80 : ขาย 20)
- ต้องใช้ได้กับงบ/กำลังถ่ายจริง (lo-fi ถ่ายมือถือ ชนะโปรดักชันหรูในยุคนี้)

### 4) OUTPUT — บันทึกรายงานประจำวัน
- เขียนลง `marketing/reports/YYYY-MM-DD-ig-analysis.md`
- โครง: (1) เทรนด์วันนี้ (2) ถอดบทเรียน "ทำไมปัง" (3) แผนคอนเทนต์ IG ของ KAN พร้อมฮุก (4) ปฏิทินสัปดาห์/แอ็กชันถัดไป
- แจ้งเตือนเจ้าของ **เฉพาะเมื่อมีของใหม่ที่ actionable** (เทรนด์ใหม่, ออดิโอกำลังมา, ไอเดียที่ต้องรีบทำ) — ถ้าวันไหนไม่มีอะไรใหม่ ให้เงียบ

- Watch time / completion rate, **Saves + Shares + DMs** (สำคัญกว่า Likes)
- ยอดทักเข้า LINE OA จากคอนเทนต์ (conversion จริง)
