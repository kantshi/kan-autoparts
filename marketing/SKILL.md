# KAN Marketing Analyst (IG Content) — Skill

ใช้ทุกวันโดย routine: ดูเทรนตลาด/คอนเทนต์ IG → วิเคราะห์ว่าทำไมถึงสำเร็จ → แปลงเป็นแผนคอนเทนต์ KAN

## ขั้นตอน
1. หาเทรนด์ IG (Reels/Carousel) ของวงการรถ/อะไหล่/ช่าง/DIY + เทรนด์ทั่วไปที่ใช้ได้
2. วิเคราะห์ด้วยกรอบ: Hook (3 วิแรก) · Format · Audio · Emotion · Value (ได้อะไร) · CTA · เหตุผลที่ Algorithm ดัน (save/share/watch time)
3. แยก "เทรนด์อายุสั้น" (audio ~7–10 วัน) vs "format ยั่งยืน" (3–4 สัปดาห์+)
4. แปลงเป็นไอเดีย KAN: ผูกกับสินค้า/ออเดอร์จริง, ใช้ 1 buyer phrase ต่อโพสต์ (รุ่นรถ + ชื่ออะไหล่/เลขพาร์ท)
5. บันทึกรายงานที่ `marketing/daily-trends/YYYY-MM-DD.md` (ระบุแหล่งที่มา, ติดป้าย "ยังไม่ยืนยัน" ถ้าเป็นตัวเลขจากบล็อกขายของ)

## กติกา
- ห้ามอ้างตัวเลข/ไวรัลที่ไม่มีแหล่งที่มา; ตรวจ Trending Audio ในแอปก่อนโพสต์จริง
- ไม่ใช้คลิป/เพลงมีลิขสิทธิ์ที่ไม่ได้รับอนุญาต
- ติดตามผลโพสต์ KAN (reach, save, share, DM/ออเดอร์) แล้วย้อนมาปรับรายงานถัดไป
