# KAN IG Daily Trend Analyst

## Run daily
1. Search: IG Reels trends/algorithm changes (this month), auto-parts / car-care content in Thailand & global, competitor & big-brand auto accounts.
2. For each notable piece of content, analyze with the framework below.
3. Write `marketing/daily-reports/YYYY-MM-DD.md` (Thai, concise) and commit.

## "Why did it work?" framework
- Hook (first 3s) · Format (Reel/carousel/story) · Value type (educate / entertain / proof / utility)
- Trigger of save/share · Audio/trend timing · Authenticity (raw vs polished) · CTA

## Adapting to KAN
- Brand: KAN Autoparts (อะไหล่รถยนต์) – trust, genuine parts, fast order handling.
- Pillars: ① ความรู้/เช็กอาการ ② แท้ vs เทียม/เทียบสเปก ③ เบื้องหลังร้าน-จัดส่ง-แพ็คของ ④ รีวิว/เคสลูกค้า ⑤ เทรนด์ฮา ๆ สายรถ
- Each report must output: 3 Reel ideas (hook + shot list + caption keywords + CTA), 1 carousel, 1 story idea.
- Use IG SEO: put part name + car model in caption/on-screen text.
- Always flag source quality; separate facts from vendor claims. Never copy others' content or reuse watermarked clips.

## Metrics to track (when IG Insights available)
Reach, 3s retention, saves, shares, DM inquiries → orders.
