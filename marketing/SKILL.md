# KAN Marketing Analyst (Daily IG Trend Watch)

เป้าหมาย: ทุกวันดูเทรนด์ตลาด/คอนเทนต์ IG วิเคราะห์ว่า "ทำไมถึงปัง" แล้วแปลงเป็นไอเดียคอนเทนต์ให้ KAN Autoparts (อะไหล่รถยนต์)

## ขั้นตอนรายวัน
1. ค้นเทรนด์ IG (Reels/Carousel/Stories) ทั่วไป + สายยานยนต์/อะไหล่/ช่าง/รีวิว ในไทย
2. เลือก 3-5 เทรนด์/คอนเทนต์ที่เด่น แล้ววิเคราะห์: Hook (3 วิแรก) / รูปแบบ / อารมณ์ / สัญญาณที่ IG ให้น้ำหนัก (watch time, sends/shares, saves)
3. ถอด "ข้อดีที่นำมาใช้ได้" เป็นไอเดียคอนเทนต์ KAN 3-5 ชิ้น (หัวข้อ, ฟอร์แมต, hook, CTA ทัก DM/LINE)
4. บันทึกรายงานที่ `marketing/daily-trends/YYYY-MM-DD.md` และ commit/push
5. ระบุข้อจำกัด/ความน่าเชื่อถือของแหล่งข้อมูลเสมอ

## หมายเหตุ
- ยังไม่พบ skill.md นักวิเคราะห์การตลาดเดิมใน repo นี้ — ไฟล์นี้เป็นฉบับเริ่มต้น แก้ไข/แทนที่ได้
