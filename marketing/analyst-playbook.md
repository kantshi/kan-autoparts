## 2. ขั้นตอนประจำวัน (ทำซ้ำทุกวัน)

1. **สแกนเทรนด์ (Scan)** — ค้นเทรนด์ IG/วิดีโอสั้นล่าสุด + เทรนด์คอนเทนต์สายรถยนต์/อะไหล่ (ไทย+สากล). ใช้ WebSearch. จดเฉพาะสิ่งที่ "เพิ่งเปลี่ยน" หรือ "ยังแรงอยู่"
2. **ถอดรหัสความสำเร็จ (Deconstruct)** — เลือกฟอร์แมต/คอนเทนต์ที่กำลังเวิร์ก 1–3 ชิ้น แล้ววิเคราะห์ **"ทำไมมันถึงปัง"** โดยแยกเป็น: Hook (3 วินาทีแรก) / คุณค่าที่คนได้ / อารมณ์หรือ trigger ที่ทำให้ Save–Share / รูปแบบการนำเสนอ
3. **แปลงเป็นของ KAN (Apply)** — เอา "ข้อดี" นั้นมาออกแบบเป็นโพสต์ IG ของ KAN ที่ทำได้จริงด้วยสินค้าอะไหล่ พร้อม Hook ภาษาไทย + CTA ชี้ไป LINE
4. **ส่งแผน (Deliver)** — เขียนลง `marketing/daily/` + commit ขึ้น branch + แจ้งเตือนเจ้าของด้วยไฮไลต์ที่ลงมือทำได้วันนี้
5. **ต่อยอด (Compound)** — ดูไฟล์ของเมื่อวาน ไม่เสนอซ้ำ; สะสมคลัง Hook/ฟอร์แมตที่เวิร์กไว้ในส่วน "คลังไอเดีย" ข้างล่าง

## 3. หลักการที่พิสูจน์แล้วว่าเวิร์ก (อัปเดตเรื่อย ๆ)

**ฟอร์แมตที่เหมาะกับร้านอะไหล่ที่สุด:**
- **Before/After แบบ Carousel (5–8 สไลด์):** อาการเสีย → อะไหล่ตัวที่พัง → ของใหม่/หลังเปลี่ยน → ได้ Save/Share สูง (อัลกอริทึมชอบ)
- **วิดีโอติดตั้ง/Time-lapse 15–30 วิ:** วิดีโอทำ engagement ~2 เท่าของภาพนิ่ง
- **OEM vs เทียบ (เทียบของแท้/เทียบ):** ช่วยลูกค้าตัดสินใจ = คนเซฟไว้
- **ถาม-ตอบเรื่องความพอดี (Fitment Q&A):** "รุ่นนี้ใส่รถอะไรได้บ้าง" แบบวิดีโอสั้น
- **UGC จากลูกค้า/ช่าง:** ให้ลูกค้าแท็กรูปงานที่ใช้ของ KAN = social proof ที่เงินซื้อไม่ได้ (ฟอร์แมตที่ร้านอะไหล่ "ใช้น้อยที่สุด")
- **ลิสต์ "3 ความผิดพลาด...":** เช่น "3 พลาดตอนซื้ออะไหล่เทียบ"

**สไตล์ที่กำลังมา (2026):** ดิบ/จริง/ไม่ขัดเกลา ชนะงานโปรดักชันเนี้ยบ · ต้องมี **Hook แรงใน 2 วินาทีแรก** · มีซับไตเติล+ข้อความพาดหัว · ฟอร์แมตเกม "this-or-that / ทายราคา" ปั่นคอมเมนต์ · เทรนด์เสียงพีคใน 7–10 วัน (รีบใช้) แต่เทรนด์ "ฟอร์แมต" อยู่ยาวกว่า

**ข้อควรระวัง:** สถิติส่วนใหญ่มาจากบล็อกเอเจนซี/เครื่องมือ = ใช้เป็นทิศทาง ไม่ใช่ตัวเลขตายตัว · ยังขาดดาต้าเฉพาะไทย — ถ้าเจ้าของมี insight จริงของเพจ KAN ให้ยึดของจริงก่อน
