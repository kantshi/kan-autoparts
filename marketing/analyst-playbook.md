# KAN Autoparts — คู่มือนักวิเคราะห์การตลาด (Marketing Analyst Playbook)

> เอกสารนี้คือ "สกิล" ของนักวิเคราะห์การตลาดประจำวันของ KAN
> ทุกวันให้ทำตามขั้นตอนนี้แล้วบันทึกผลลง `marketing/daily/YYYY-MM-DD.md`
> โฟกัสหลัก: **คอนเทนต์ Instagram ก่อน** (Reels + Carousel) แล้วค่อยขยายไป TikTok / LINE / Facebook

---

## เป้าหมายของรูทีนนี้
1. **สแกนเทรนด์** คอนเทนต์และตลาดในแต่ละวัน (ทั้งสายรถยนต์/อะไหล่ และเทรนด์ IG ทั่วไป)
2. **วิเคราะห์ว่าทำไมคอนเทนต์นั้นถึงสำเร็จ** — ถอด "หลักการที่อยู่เบื้องหลัง" ไม่ใช่แค่ลอกไอเดีย
3. **แปลงข้อดีมาเป็นแผนคอนเทนต์ของ KAN** — ไอเดียโพสต์ที่ลงมือทำได้จริงภายในวันนั้น

## บริบทธุรกิจ KAN (ใช้ตั้งต้นทุกครั้ง)
- ธุรกิจ: ร้านอะไหล่รถยนต์ (ขายปลีก + ขายส่ง มีราคาส่งแบบซื้อจำนวนมาก)
- ลูกค้า: เจ้าของรถ, ช่าง/อู่, ร้านอะไหล่รายย่อย (B2B + B2C)
- ช่องทางปิดการขาย: **LINE OA** (CTA เกือบทุกโพสต์ควรดันไป LINE)
- หมวดสินค้าหลัก: เบรก, กรอง (อากาศ/น้ำมันเครื่อง/โซลาร์), น้ำมันเครื่อง, แบตเตอรี่, ช่วงล่าง, ไฟ/หลอดไฟ, สายพาน, หัวเทียน ฯลฯ
- โทนแบรนด์: น้ำเงินกรม + ทองแชมเปญ (ดูน่าเชื่อถือ มืออาชีพ) — คอนเทนต์ควรคุมโทนให้ "น่าเชื่อถือแต่เข้าถึงง่าย"

---

## ขั้นตอนประจำวัน (ทำซ้ำได้)

### ขั้นที่ 1 — สแกนเทรนด์ (Trend Scan)
ค้นหา/ทบทวน 3 แกน:
- **เทรนด์ IG ทั่วไป**: ฟอร์แมตไหนรีชดี, เสียง/trend audio, พฤติกรรม algorithm ล่าสุด
- **สายรถยนต์/อะไหล่**: คอนเทนต์ร้านอะไหล่/ช่าง/คาร์แคร์ที่กำลังมา (ไทย + ต่างประเทศ)
- **จังหวะตามฤดูกาล/เหตุการณ์**: เช่น หน้าฝน (เบรก/ที่ปัดน้ำฝน/ยาง), สงกรานต์/ปีใหม่ (เช็กรถก่อนเดินทางไกล), หน้าร้อน (แบต/แอร์/หม้อน้ำ)

### ขั้นที่ 2 — วิเคราะห์ "ทำไมถึงสำเร็จ"
เลือกคอนเทนต์ที่เวิร์ก 1–3 ชิ้น แล้วถอดด้วยกรอบนี้:
| หัวข้อ | คำถามที่ต้องตอบ |
|---|---|
| **Hook** | 3 วินาที/สไลด์แรกหยุดนิ้วคนดูด้วยอะไร |
| **Format** | Reel / Carousel / Photo — ทำไมฟอร์แมตนี้ถึงเหมาะกับสารนี้ |
| **Emotion/Value** | ให้คุณค่าอะไร (ความรู้ / ตลก / น่าทึ่ง / ประหยัดเงิน / ความไว้ใจ) |
| **ทำไมคนเซฟ/แชร์** | คนเก็บไว้ดูทีหลัง หรือส่งต่อเพราะอะไร |
| **หลักการที่ถอดได้** | 1 ประโยค — กฎที่เอาไปใช้ซ้ำได้ |

> **ตัวชี้วัดที่สำคัญที่สุดของ IG คือ Save และ Share** (ไม่ใช่ยอดไลก์) — Save rate = saves ÷ reach
> Reel เหมาะ "หาคนใหม่" (รีชดีสำหรับบัญชี < 50k) / Carousel เหมาะ "สร้างความน่าเชื่อถือ + เซฟ"

### ขั้นที่ 3 — แปลงเป็นแผนคอนเทนต์ KAN
ออกไอเดียโพสต์ IG ที่ทำได้จริง โดยทุกไอเดียต้องระบุ:
- **ฟอร์แมต** (Reel/Carousel) + **Hook** (ข้อความสไลด์แรก/3 วิแรก)
- **แนวแคปชัน** + **CTA ปิดการขาย** (ทักLINE / ขอเช็กราคาส่ง)
- **แฮชแท็ก** (ผสมแท็กกว้าง + แท็กเฉพาะกลุ่มรถ/อะไหล่)
- **หลักการที่เอามาจากขั้นที่ 2** (โยงให้ชัดว่าทำไมถึงเลือกทำแบบนี้)

## คลังหลักการที่ถอดได้ (สะสมเพิ่มทุกวัน)
> อัปเดตลิสต์นี้เรื่อย ๆ เมื่อเจอหลักการใหม่จากการวิเคราะห์

1. **หน้าคนขายดีกว่าโลโก้** — คอนเทนต์ที่มี "คนจริง" ของร้าน (เช่น ลูกสาวร้านอะไหล่) สร้างความผูกพันและรีชดีกว่าภาพสินค้าเฉย ๆ
2. **ตอบคำถามที่ลูกค้าสงสัยจริง** — "อะไหล่แท้ vs เทียบ vs OEM", "รถมีอาการแบบนี้เกิดจากอะไร" คนเซฟไว้เยอะเพราะเป็นความรู้ที่ใช้ได้จริง
3. **Before/After & ของเก่า vs ของใหม่** — คอนทราสต์ภาพหยุดนิ้วได้เอง และคนชอบเซฟ
4. **ของแท้ต้องชนะด้วย "เหตุผล"** — เทียบชัด ๆ ว่าอะไหล่แท้/ดีกว่าอย่างไร ช่วยปิดการขายให้กลุ่มที่กลัวของปลอม
5. **Hook ต้องมาก่อนทุกอย่าง** — สไลด์แรก/3 วิแรกคือทั้งหมด ถ้า swipe-through ต่ำแปลว่า hook พัง
