# KAN Autoparts – Daily IG Trend & Content Brief (2026-10-02)

## 1. เทรนด์ตลาด IG ตอนนี้
- Reels = ตัวดึง reach/คนใหม่; Carousel = engagement/save สูงกว่า → ใช้คู่กัน (Reel ดึงคน, Carousel ให้ความรู้/ปิดการตัดสินใจ)
- Hook ใน 2 วินาทีแรก + ตัดต่อเร็ว, storytime พูดตรงกล้อง, format แบบเกม/ควิซ
- ความจริงใจชนะงานโปรดักชันแพง: วิดีโอจากมือถือที่คนจริงพูด ชนะวิดีโอโฆษณาเนี๊ยบๆ
- ซีซัน: คอนเทนต์ตามฤดู (ปลายปี/ฝน) และเสียงเทรนด์ตามเทศกาล

## 2. เทรนด์เฉพาะวงการอะไหล่
- วิดีโอสั้นแสดงขั้นตอนติดตั้ง, ก่อน–หลัง, ผลต่อสมรรถนะ แปลงเป็นยอดขายดีกว่ารูปนิ่ง/ข้อความ
- เปรียบเทียบแบรนด์/เกรด และ "อะไรสำคัญจริงตอนเลือกอะไหล่" ชนะคำบรรยายสินค้าทั่วไป
- IG = โชว์รูมภาพของร้าน

## 3. ทำไมแนวนี้ได้ผล (วิเคราะห์)
| ปัจจัย | เหตุผล | ประยุกต์กับ KAN |
|---|---|---|
| Hook เร็ว | คนเลื่อนผ่านใน <2 วิ | เปิดด้วยอาการรถ/ปัญหา เช่น "เบรกมีเสียงนี้ = ผ้าเบรกหมด" |
| Proof ก่อน–หลัง | ลดความเสี่ยงที่รับรู้ของผู้ซื้อ | ของเก่าสึก vs ของใหม่, ถ่ายตอนแพ็ค/ตรวจของ |
| คนจริง | สร้างความเชื่อถือ | ช่างหรือทีมงาน KAN พูดเอง |
| ให้ความรู้ที่ save ได้ | Carousel ได้ save/share | เช็กลิสต์ระยะเปลี่ยนอะไหล่, วิธีดูรหัสรุ่น/ปีรถ |

## 4. ไอเดียคอนเทนต์ 5 ชิ้น (ใช้ได้สัปดาห์นี้)
1. Reel: "3 สัญญาณผ้าเบรกใกล้หมด" (hook 2 วิ, ฟังเสียง, CTA ทัก DM พร้อมรุ่นรถ)
2. Reel: ก่อน–หลังเปลี่ยนอะไหล่ (ของเก่าสึก vs ของใหม่) พร้อมราคา/รับประกัน
3. Carousel: "เช็กรหัสอะไหล่ให้ตรงรุ่นรถ ใน 4 ขั้นตอน" (save-worthy ลดการสั่งผิด)
4. Reel Quiz: "เดาสิ ชิ้นไหนของแท้ / OEM / เกรดเทียบ" เฉลยท้ายคลิป
5. Behind-the-scenes: แพ็คออเดอร์/ตรวจของก่อนส่ง (เชื่อมกับระบบจัดการออเดอร์ของ KAN)

## 5. KPI ที่ควรติดตาม
Reach non-follower, 3-sec hold, save/share ต่อโพสต์, DM ที่ถามรุ่นรถ, ออเดอร์จาก IG
