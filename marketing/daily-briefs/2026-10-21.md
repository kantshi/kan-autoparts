# KAN Autoparts – Daily IG Trend Brief (2026-10-21)

> หมายเหตุ: ใน repo ยังไม่มีไฟล์ skill.md ของนักวิเคราะห์การตลาด/skill อื่นของ KAN จึงใช้กรอบวิเคราะห์พื้นฐานแทน (Hook → Retention → Share → CTA) เมื่อมีไฟล์ skill ให้วางไว้ที่ `marketing/skills/` แล้วรอบถัดไปจะนำมาใช้

## 1. เทรนด์ IG ที่ตรวจพบวันนี้
| เทรนด์ | ทำไมจึงได้ผล | ข้อมูลที่ยืนยันได้ |
|---|---|---|
| Hook ใน 3 วินาทีแรก | watch time คือสัญญาณหลักของ algorithm | Mosseri: watch time, likes per reach, sends per reach |
| คลิป "ส่งต่อ" (DM share) | sends per reach ดันคลิปให้คนที่ไม่ได้ติดตาม | สัญญาณขยายการเข้าถึงที่แรงที่สุดตามแหล่งข้อมูล |
| ความยาว 30–90 วิ | ดูจนจบง่าย / Reels ยาวถึง 3 นาทีมีสิทธิ์ขึ้น Explore | Buffer (ผ่านบทความสรุป) |
| ปัญหา→วิธีแก้, หักล้างความเชื่อผิด, เบื้องหลังงานจริง | ตรงกับสิ่งที่ลูกค้าอะไหล่ค้นหาและเชื่อใจ | แนวทางทั่วไปสำหรับธุรกิจบริการ |
| ข้อความบนจอ + คำบรรยาย | คนดูปิดเสียงจำนวนมาก | |
| Original content, ไม่ repost/มีลายน้ำ | algorithm ลดการแนะนำคอนเทนต์ซ้ำ | แหล่งข้อมูลเชิงผู้ขายเครื่องมือ (ใช้เป็นแนวทาง) |
| Trial Reels | ทดสอบกับคนที่ไม่ใช่ผู้ติดตามก่อนลงเงินโปรโมต | |
| Carousel | บางชุดข้อมูลพบ engagement ดีกว่า Reels สำหรับบางเป้าหมาย | ควรทดสอบ |

ข้อจำกัด: ผลค้นหาไม่มีข้อมูลเฉพาะวงการอะไหล่รถ/ตลาดไทย และไม่พบการเปลี่ยน algorithm ใหม่เดือนนี้ ควรเสริมด้วยการดูคอนเทนต์คู่แข่ง/ร้านอะไหล่ไทยด้วยตนเองหรือผ่านเครื่องมือที่ดึง IG ได้

## 2. ไอเดียคอนเทนต์ IG สำหรับ KAN (นำเทรนด์มาปรับใช้)
1. **"อาการนี้ = อะไหล่ตัวไหน"** (Reel 30–45 วิ): Hook "เสียงดังตอนเบรก? อย่าเพิ่งเปลี่ยนทั้งชุด" → โชว์ชิ้นส่วนจริง → CTA ทักสั่งผ่านไลน์/DM
2. **หักล้างความเชื่อ** : "อะไหล่แท้ vs เทียบ ต่างกันตรงไหน" เปรียบเทียบจับต้องได้ เหมาะให้ส่งต่อในกลุ่มช่าง/เจ้าของรถ
3. **เบื้องหลังออเดอร์** : แพ็คของ/ตรวจเช็กสินค้า/จัดส่ง สร้างความน่าเชื่อถือ (ใช้ภาพจากระบบออเดอร์ได้)
4. **Carousel เช็กลิสต์** : "5 อะไหล่ที่ควรเปลี่ยนตามระยะ" บันทึกและแชร์ง่าย
5. **ทดสอบด้วย Trial Reels** ก่อนโปรโมตคลิปที่ผ่านเกณฑ์

## 3. เกณฑ์วัดผลที่ควรติดตามต่อโพสต์
ดูจนจบ %, sends/reach, saves, คลิกโปรไฟล์/ทักแชท แล้วบันทึกว่า Hook แบบไหนชนะ
