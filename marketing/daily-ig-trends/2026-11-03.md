> ข้อมูลเทรนด์มาจากบทความการตลาดทั่วไป (ไม่ใช่ข้อมูลทางการของ IG และไม่มีข้อมูลเฉพาะไทย/พ.ย. 2026) – ถือเป็นแนวทาง ต้องตรวจซ้ำกับ IG Insights ของ KAN เอง

## 1. สัญญาณเทรนด์ที่พบ
- **Saves / Shares / DM sends** มีน้ำหนักมากกว่าไลก์ (ตัวเลขตัวคูณเป็นการประมาณของบล็อก ไม่ใช่ตัวเลขทางการ)
- **เทรนด์เสียง** อยู่ได้ ~7–10 วัน, **เทรนด์รูปแบบ (format)** อยู่ได้ 3–4 สัปดาห์ → เลือก format ก่อนเสียง
- **สายรถยนต์**: อัลกอริทึมชอบคอนเทนต์ original ที่มีภาพรถ/ชิ้นส่วนจริง ไม่ใช่แค่ลิปซิงก์เสียงฮิต
- **Carousel** ดีสำหรับ save (กลุ่มผู้ติดตามเดิม), **Reels** ดีสำหรับ reach คนใหม่ ช่วง 3 วินาทีแรกสำคัญที่สุด (ความยาวที่ดีที่สุด: แหล่งข้อมูลขัดแย้งกัน 15–30 vs 30–90 วิ → ให้ A/B test)
- สินค้าที่ติดตั้งกับรถ ลูกค้าต้องการ **ความเชื่อใจเรื่องคุณภาพ/ความเข้ากันได้**

## 2. ทำไมคอนเทนต์แบบนี้ถึงสำเร็จ (วิเคราะห์)
| รูปแบบ | กลไก | ปรับใช้กับ KAN |
|---|---|---|
| Before/After transformation | hook เร็ว, ดูจนจบ | เปลี่ยนอะไหล่/ซ่อมจริง ก่อน–หลัง |
| Comparison (A vs B) | ชวนคอมเมนต์/แชร์ | OEM vs เทียบเท่า, ยี่ห้อ A vs B |
| Educational carousel / checklist | คนกด save | "5 อาการที่ต้องเปลี่ยนผ้าเบรก", ตารางระยะเปลี่ยนอะไหล่ |
| Relatable / "ส่งให้เพื่อนที่ขับรถ" | DM sends | มุกช่าง–ลูกค้า, ความผิดพลาดที่เจอบ่อย |

## 3. แผนคอนเทนต์ IG ที่แนะนำ (สัปดาห์นี้)
1. **Reel (15–30 วิ):** "ผ้าเบรกสึกแล้วเป็นยังไง" – hook 3 วิแรกด้วยภาพชิ้นส่วนสึกจริง + CTA "ส่งให้เพื่อนที่ไม่เคยเช็คเบรก"
2. **Carousel 7 สไลด์:** เช็คลิสต์บำรุงรถก่อนช่วงเดินทางปลายปี (save-bait) + หน้าสุดท้ายบอกวิธีสั่ง/ตรวจสอบรุ่นรถผ่าน KAN
3. **Reel เปรียบเทียบ:** อะไหล่แท้ vs เทียบเท่า – พูดตรง โปร่งใส สร้างความน่าเชื่อถือ
4. **Story:** โพลถามรุ่นรถที่ลูกค้าอยากให้ทำเนื้อหา → ใช้วางแผนรอบถัดไป

## 4. Test / KPI
- วัดต่อโพสต์: saves, shares/sends, reach ต่อ non-follower, ค่า 3-sec hold
- ทดสอบความยาว Reel 15–30 vs 30–60 วิ อย่างละ 2 โพสต์
- รายงานรอบถัดไปควรเทียบกับข้อมูล IG Insights จริงของ KAN
