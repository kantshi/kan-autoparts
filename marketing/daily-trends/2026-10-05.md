# KAN Autoparts — Daily IG Trend Brief (2026-10-05)

> หมายเหตุ: ใน repo ยังไม่มี skill.md ของนักวิเคราะห์การตลาด/skill อื่นของ KAN (มีแค่ README.md + index.html ระบบออเดอร์) — brief นี้ใช้กรอบ วิเคราะห์ Hook → Format → Value → CTA แทน เมื่อมี skill.md แล้วให้ชี้ path มาที่นี่

## 1) เทรนด์ตลาด IG (ล่าสุด)
- **Reels = ช่องทางหลักของการเข้าถึง**: ~50% ของเวลาบน IG, reach มากกว่ารูปนิ่ง ~2 เท่า, engagement Reels โต ~24.8% YoY
- **Raw / unpolished ชนะงานโปรดักชันสูง** + hook 1–3 วินาทีแรกต้องแรง
- **Close-up → Wide reveal**: เปิดภาพมือ/ชิ้นส่วนใกล้ๆ แล้วถอยให้เห็นภาพรวม สร้าง micro-mystery ให้คนดูจนจบ
- **Carousel = Save/Share**: ใช้อธิบายขั้นตอน เหตุผล หลักฐาน
- **ไทย**: ~85% ของคอนเทนต์ที่ส่งต่อในแชทคือ Reels ("Digital Pebbling"); ผู้ใช้ไทย ~70% ทัก DM ถามสินค้าก่อนซื้อ → CTA ต้องพา "ทัก DM/LINE"
- **สายรถ**: รถแต่ง (ล้อ, ไฟ LED, ท่อ, bodykit), คอนเทนต์ให้ความรู้, EV, เสียงเล่าเรื่อง

## 2) ทำไมคอนเทนต์เหล่านี้สำเร็จ (วิเคราะห์)
| ปัจจัย | เหตุผล | นำมาใช้กับ KAN |
|---|---|---|
| Hook เร็ว | ตัดสินใจเลื่อนผ่านใน 1–3 วิ | เปิดด้วยอาการเสีย/เสียงผิดปกติ/ราคาเทียบ |
| Reveal ภาพใกล้→กว้าง | คนอยากรู้ผลลัพธ์ | โชว์อะไหล่ใกล้ๆ แล้วถอยเห็นรถทั้งคัน |
| ให้ความรู้สั้นๆ | Save/Share สูง | "อาการนี้ = อะไหล่ตัวนี้" 15 วิ |
| ส่งต่อทางแชท | DM-driven | ปิดท้าย "ส่งให้ช่าง/เพื่อนที่ขับรถรุ่นนี้" |

## 3) ไอเดียคอนเทนต์ IG ที่แนะนำสัปดาห์นี้
1. **Reel – "เสียงนี้ = อะไหล่อะไร"** (ลูกหมาก/ผ้าเบรก/ยางแท่นเครื่อง) hook เสียง + reveal ชิ้นส่วน
2. **Reel – แกะกล่องแท้ vs เทียบ** raw ถ่ายมือถือ ไม่ต้องตัดต่อหนัก
3. **Carousel – เช็กลิสต์ก่อนเดินทางยาว / ช่วงหน้าฝน** (ใบปัด ยาง เบรก แบต) เน้นให้เซฟ
4. **Reel – ของจริงที่แพ็กส่งวันนี้** behind-the-scenes ออเดอร์ (เชื่อมระบบออเดอร์ของ KAN) สร้างความน่าเชื่อถือ
5. **Story/DM CTA** – สติกเกอร์ถามรุ่นรถ → ตอบเป็นรายการอะไหล่ที่ตรงรุ่น

## 4) ข้อจำกัดของ brief นี้
- ข้อมูลเป็นเทรนด์ทั่วไปจากเว็บ ยังไม่มีข้อมูลเฉพาะ "ร้านอะไหล่ไทย" และไม่มีสถิติ IG ของ KAN เอง
- ถ้าต้องการวิเคราะห์คอนเทนต์คู่แข่งรายตัว ต้องมีรายชื่อบัญชี IG อ้างอิง (ยังไม่มีใน repo)
