# เทรนด์ IG & แผนคอนเทนต์ KAN Autoparts — 2026-10-06

> หมายเหตุ: ใน repo ยังไม่มีไฟล์ skill.md (นักวิเคราะห์การตลาด/skill อื่นของ KAN) — รอบนี้ใช้หลักวิเคราะห์ทั่วไป ถ้าเพิ่ม skill.md เข้า repo รอบหน้าจะนำมาใช้อัตโนมัติ

## 1) เทรนด์ตลาด IG ตอนนี้
- **Raw / lo-fi ชนะงานโปรดักชันหรู** — เบื้องหลังหน้าร้าน ช่างทำงานจริง คลิปไม่เกลา ได้ใจกว่า
- **Hook 2 วินาทีแรก + fast-cut** — เปิดด้วยปัญหาหรือภาพช็อต เช่น "อะไหล่เทียบกับของแท้ ต่างกันตรงไหน"
- **Educational Reels = save สูงสุด** (ผู้ใช้ 41% ชอบคอนเทนต์ให้ความรู้) เหมาะกับการสอนเลือกอะไหล่
- **Game format** (this-or-that, blind ranking) และ **episodic series** แทนการตามเทรนด์ครั้งเดียว
- **ไทย: DM คือพลัง** — Reels 85% ที่แชร์ผ่าน DM ("Reelslationship" / Digital Pebbling) → ออกแบบคอนเทนต์ให้ "ส่งต่อให้เพื่อน/ช่าง/พี่ชาย"
- **Reels = 50% ของเวลาบน IG** → Reels ต้องเป็นหลัก, Carousel ไว้ทำยอด save/share
- สายรถ: เสียงโทนมืด/บรรยากาศ + night-drive reveal จังหวะตามบีต

## 2) ทำไมคอนเทนต์เหล่านี้ได้ผล (วิเคราะห์)
| ปัจจัย | เหตุผล | ใช้กับ KAN |
|---|---|---|
| ความจริงใจ | ลดกำแพงความเป็นโฆษณา สร้างความเชื่อใจ (อะไหล่ = ของที่ต้องเชื่อใจ) | คลิปแกะกล่องจริง ตรวจสต๊อกจริง |
| ประโยชน์ใช้ได้ทันที | คนกด save ไว้ใช้ตอนรถมีปัญหา | "5 อาการที่ต้องเปลี่ยน…" |
| ส่งต่อได้ | คนส่งให้คนใกล้ตัวที่ขับรถ | คำถาม/ปัญหาที่ "เพื่อนเราต้องเจอ" |
| ตอนต่อเนื่อง | สร้างนิสัยกลับมาดู | ซีรีส์ประจำสัปดาห์ |

## 3) แผนคอนเทนต์ IG ที่แนะนำ (สัปดาห์นี้)
1. **Reel: "ของแท้ vs เทียบ" (this-or-that)** — hook: "เลือกอันไหน? เฉลยท้ายคลิป" · CTA: ส่งให้เพื่อนที่ขับรถ
2. **Reel: "1 นาทีรู้จักอะไหล่" ซีรีส์ EP.1** — สอนดูอาการ/รหัสอะไหล่ · CTA: Save
3. **Reel เบื้องหลังร้าน** — แพ็คออเดอร์/ตรวจของ ไม่ต้องตัดต่อเนี้ยบ + เสียงบรรยากาศ
4. **Carousel: เช็คลิสต์ "ก่อนซื้ออะไหล่ต้องรู้ 5 ข้อ"** — เน้น save
5. **Story: โพลล์ "อาการรถที่เจอ"** — ดึง DM แล้วต่อยอดเป็นคอนเทนต์

ข้อควรทำ: ใส่ CTA ให้ DM ถามรุ่นรถ/ปีรถ เพื่อปิดการขายผ่านแชต

## 4) ข้อจำกัดของรอบนี้
- ผลค้นหาเป็นเทรนด์ทั่วไปของ IG/ไทย ยังไม่มีข้อมูลเฉพาะอะไหล่รถยนต์ไทย และไม่ได้เข้าดูคอนเทนต์/ยอดวิวของคู่แข่งโดยตรง (ต้องใช้ล็อกอิน IG) → แนะนำให้ทีมเพิ่มลิสต์บัญชีคู่แข่ง/แรงบันดาลใจใน repo เพื่อให้รอบหน้าวิเคราะห์เจาะจงขึ้น
