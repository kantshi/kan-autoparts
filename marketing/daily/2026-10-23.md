# KAN IG Trend Report – 2026-10-23

## Snapshot
- IG rewards **saves, shares, DMs and replies** over likes; Reels = discovery, carousels = trust/proof ([mean.ceo Oct 2026](https://blog.mean.ceo/?p=10941)).
- **Longer Reels** are now eligible for Explore recommendation, which opens room for install/comparison tutorials ([Metricool](https://metricool.com/instagram-reels-guide/)).
- 7-15s clips get the best completion; 15-30s works for tutorials/product content ([aivideocut](https://www.aivideocut.com/blog/best-instagram-reels-making-tools)).
- Many viewers watch muted → on-screen text hook in the first seconds ([SmartSites](https://www.smartsites.com/blog/best-practices-for-high-performing-instagram-reels-ads-in-2026/)).
- Business formats that work: problem-solving, myth-busting, behind-the-scenes, before/after, direct-to-camera UGC ([mean.ceo](https://blog.mean.ceo/?p=8819), [invideo](https://invideo.io/blog/instagram-reels-guide/)).
- Trending audio tagged "automotive" (late Aug/early Sep list, dated): "Timber" for aggressive walk-around reveals ([SocialPilot](https://www.socialpilot.co/blog/instagram-reels-trends)).

## Why these formats work
| Format | Hook | Driver |
|---|---|---|
| Problem → fix | "รถมีเสียงดังตอนเบรก? สาเหตุคือ…" | Solves a real pain → saves |
| Myth-busting | "อะไหล่เทียบ = ห่วย? จริงหรือ" | Curiosity + debate → comments/shares |
| Before/After | ของเก่าพัง vs ของใหม่ | Visual proof → shares |
| BTS / packing | แพ็คออเดอร์ ตรวจสต็อก | Trust → DM to order |

## Lessons for KAN
1. Lead every Reel with a Thai on-screen text hook (muted-friendly).
2. Teach "how to pick the right part" (รุ่นรถ/ปี/เลขอะไหล่) – high save value for ช่าง and owners.
3. Use carousels for fitment guides/checklists (trust), Reels for reach.
4. CTA = "ทัก DM/LINE ส่งรุ่นรถ เช็คอะไหล่ให้" → drives the DM signal.
