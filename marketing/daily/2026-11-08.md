# IG Daily Brief — 2026-11-08 (KAN Autoparts)

## 1) Trend snapshot
- Algorithm: ลำดับสัญญาณหลักของ Reels = watch time/completion → sends ต่อ reach → likes (ไม่พบการเปลี่ยนแปลงเด่นช่วงนี้)
- Instagram ลด reach ของบัญชีที่ repost; ขยายมาตรการถึงภาพ/คารูเซล (เม.ย. 2026) → ต้องทำคอนเทนต์ต้นฉบับ
- Carousel ใส่ได้ถึง 20 สไลด์
- เทรนด์: คอนเทนต์ให้ความรู้ที่ "เซฟได้", Reels ที่ค้นเจอผ่านคีย์เวิร์ด (search-friendly), ตอบเร็วใน DM, ความเป็นธรรมชาติ ไม่ต้องโปรดักชันหนัก
- รถ: ลิปซิงก์ตามเสียงเทรนด์อย่างเดียวไม่พอ ต้องมีภาพรถ/อะไหล่ที่เกี่ยวข้อง; format ที่แนะนำคือเปรียบเทียบ

## 2) Why it works → KAN takeaway
| รูปแบบที่เวิร์ก | ทำไมถึงเวิร์ก | ปรับใช้กับ KAN |
|---|---|---|
| เปรียบเทียบ (A vs B) | ดูจนจบ + ส่งต่อให้เพื่อน | OEM vs ของเทียบ / รุ่นเก่า vs ใหม่ |
| Carousel ให้ความรู้ | คนเซฟไว้กลับมาดู | เช็กลิสต์อาการเสีย/รอบเปลี่ยนอะไหล่ |
| Reels ตอบคำค้นเฉพาะ | ถูกค้นเจอ ตรงความต้องการซื้อ | "ผ้าเบรกรุ่น X ใช้เบอร์ไหน" |
| ดิบ ไม่โปรดักชันเยอะ | ดูน่าเชื่อถือ | ช่างโชว์แกะของ/แพ็กออเดอร์จริง |

## 3) ไอเดียคอนเทนต์วันนี้ (3 ชิ้น)
1. **Reels เปรียบเทียบ "ของแท้ vs ของเทียบ"** — Hook: "ผ้าเบรกสองชิ้นนี้ ราคาต่างกัน 2 เท่า ต่างตรงไหน?" · 20-30 วิ · CTA: ทัก DM ส่งเลขตัวถัง/รุ่นรถ → วัด: sends, watch time
2. **Carousel 8-10 สไลด์ "5 อาการที่บอกว่าต้องเปลี่ยน…"** (สี navy/gold ตามแบรนด์) — CTA: "เซฟไว้เช็กรถ" → วัด: saves
3. **Reels เบื้องหลังแพ็กออเดอร์** — ตอบคำถามลูกค้า ดึงความน่าเชื่อถือ/จัดส่งไว → วัด: DM, profile visits

## 4) แผนสัปดาห์ (ร่าง)
จ. Carousel ความรู้ · พ. Reels เปรียบเทียบ · ศ. Reels เบื้องหลัง · อา. สรุปผล + ปรับแผน

## 5) ข้อควรระวัง
- แหล่งข้อมูลส่วนใหญ่เป็นบล็อกการตลาดทั่วไป ไม่มีข้อมูลเฉพาะอะไหล่รถ/พ.ย. 2026 และตัวเลขหลายตัวไม่ยืนยัน → ใช้เป็นสมมติฐานแล้วทดสอบกับผลจริงของ KAN
- ยังไม่มีข้อมูล Insights ของบัญชี KAN และ skill.md นักวิเคราะห์การตลาดเดิมไม่อยู่ใน repo — โปรดเพิ่มเพื่อให้การวิเคราะห์แม่นขึ้น
