## 🎯 สรุปผู้บริหาร (อ่าน 20 วินาที)
วันนี้ทิศทางคอนเทนต์ยานยนต์บน IG ชัดเจน: **Reels สั้นที่ "ฮุกใน 3 วิแรก" + ดูจริงใจแบบช่างตัวจริง ชนะวิดีโอสวยหรู** ส่วน **Carousel ขายของได้ดีกว่า** (คนบันทึกไว้ก่อนตัดสินใจซื้อ)

## 2) วิเคราะห์: **ทำไมคอนเทนต์เหล่านี้ถึงสำเร็จ** (กลไกเบื้องหลัง)
นี่คือหัวใจของงานวันนี้ — ไม่ใช่แค่ "ทำอะไร" แต่ "เพราะอะไรถึงเวิร์ก" เพื่อนำมาปรับใช้:

1. **ฮุก 3 วิแรก = ด่านตัดสินชี้เป็นชี้ตาย** — อัลกอริทึมดัน Reels ที่คนดูไม่เลื่อนผ่านช่วงต้น
   → *ทำไมเวิร์ก:* คนตัดสินใจ "ดูต่อ/ปัด" เร็วมาก คลิปที่เปิดด้วย **เสียง** (เครื่องยนต์ติด เสียงประแจ เสียงอะไหล่ล็อกเข้าที่) หรือ **คำถามแรง** ("อะไหล่ชิ้นนี้พังเงียบ ๆ จนรถคุณจะดับกลางถนน") หยุดนิ้วได้

2. **ความ "satisfying" + ก่อน/หลัง = คนดูจนจบ** — การเห็นของเก่าพัง → ของใหม่สวม → ผลลัพธ์ดีขึ้น ให้ความพึงพอใจทางสายตา
   → *ทำไมเวิร์ก:* มี payoff ชัด คนดูรอผล = watch-time สูง = ถูกดันต่อ

3. **จริงใจ/ช่างตัวจริง > สวยหรู** — คนเชื่อคนมากกว่าเชื่อโฆษณา
   → *ทำไมเวิร์ก:* ลดกำแพง "นี่มันโฆษณา" สร้าง trust ซึ่งคือสิ่งที่คนซื้ออะไหล่ต้องการที่สุด (กลัวของปลอม/ของไม่ตรงรุ่น)

4. **Carousel ให้คน "บันทึกไว้ก่อนซื้อ"** — เนื้อหาเทียบ/สอน/เช็กลิสต์ ถูก save ไว้ตัดสินใจทีหลัง
   → *ทำไมเวิร์ก:* การซื้ออะไหล่เป็น considered purchase คนไม่ซื้อทันที Carousel = เก็บเป็นคู่มือ = กลับมาซื้อ

5. **ขายประโยชน์ ไม่ใช่สเปก** — "เบรกนิ่ม หยุดมั่นใจ" > "ผ้าเบรกเกรด X รหัส Y"
   → *ทำไมเวิร์ก:* คนซื้อผลลัพธ์ (ความปลอดภัย/ความสบาย) ไม่ได้ซื้อตัวเลข

## 3) นำมาปรับใช้กับ KAN — **5 Content Brief พร้อมถ่าย (IG)**
ถ่ายด้วยมือถือได้ทั้งหมด แต่ละชิ้นระบุ: ฟอร์แมต / ฮุก / โครงคลิป / CTA / ทำไมถึงเหมาะกับ KAN

### Brief 1 — Reels: "เสียง + ก่อน/หลัง" (satisfying install) ⭐ แนะนำเริ่มชิ้นนี้
- **ฟอร์แมต:** Reels 15–20 วิ แนวตั้ง
- **ฮุก (0–3 วิ):** เสียงจริง — ถอดอะไหล่เก่าที่สึก/แตก โชว์ใกล้ ๆ + ข้อความ "อะไหล่ตัวนี้...รถคุณใช้มากี่ปีแล้ว?"
- **โครง:** ของเก่าพัง (3 วิ) → จับของแท้ KAN เทียบ (4 วิ) → ใส่เข้าไป เสียงล็อกเข้าที่ (5 วิ) → ผลลัพธ์/ขับทดสอบนิ่ม ๆ (3 วิ)
- **CTA:** "ของแท้ ตรงรุ่น ทัก DM เช็กราคา — สั่ง 5 ตัวขึ้นไป ราคาส่ง"
- **ทำไมเหมาะ KAN:** รวมฮุกเสียง + ก่อน/หลัง + ความน่าเชื่อถือของแท้ ครบ 3 กลไกแรง

### Brief 2 — Carousel: "ของแท้ vs ของเทียม แยกยังไงใน 5 จุด" ⭐ ตัวแปลงยอด
- **ฟอร์แมต:** Carousel 6 หน้า (ปกฮุก + 5 จุดเทียบ + หน้าปิด CTA)
- **ฮุก (ปก):** "เสียเงินซื้อของเทียมโดยไม่รู้ตัว? เช็ก 5 จุดนี้ก่อนจ่าย"
- **เนื้อ:** แต่ละหน้าเทียบจุดสังเกต (บรรจุภัณฑ์ โลโก้ รอยปั๊ม น้ำหนัก ใบรับประกัน) ภาพจริง KAN
- **CTA หน้าสุดท้าย:** "บันทึกโพสต์นี้ไว้ 📌 + อยากได้ของแท้ชัวร์ ทัก KAN"
- **ทำไมเหมาะ KAN:** จุดแข็ง "ของแท้" = ทำให้ KAN เป็นผู้เชี่ยวชาญที่คนบันทึกไว้ = กลับมาซื้อ

### Brief 3 — Reels: "อาการแบบนี้ = อะไหล่ตัวไหนกำลังจะพัง" (education, ฮุกคำถาม)
- **ฟอร์แมต:** Reels 20–30 วิ ช่างพูดหน้ากล้อง (จริงใจ)
- **ฮุก:** "ได้ยินเสียง...ตอนเลี้ยว? อย่าปล่อย เพราะมันคือ [ลูกหมาก/ลูกปืนล้อ] กำลังจะไป"
- **โครง:** อาการ → อันตรายถ้าปล่อย → อะไหล่ที่ต้องเปลี่ยน → KAN มีของแท้ตรงรุ่น
- **CTA:** "ไม่แน่ใจรุ่นไหน? ส่งทะเบียน/รุ่นรถมาทาง DM เราเช็กให้"
- **ทำไมเหมาะ KAN:** ให้ความรู้ (80%) สร้าง trust + เปิดบทสนทนา DM = ปิดการขาย

### Brief 4 — Reels/รูป: "ราคาส่งสำหรับอู่/ร้านช่าง" (เจาะ B2B)
- **ฟอร์แมต:** Reels สั้น 10–15 วิ หรือ Carousel ตารางราคา
- **ฮุก:** "เปิดอู่อยู่ใช่ไหม? ตัวนี้สั่ง 5 ตัวขึ้นไป ต้นทุนลดเหลือ ฿___/ตัว"
- **โครง:** โชว์สต็อก/ความหลากหลาย → ราคาส่งต่อตัว → ส่งไว/มีของ
- **CTA:** "อู่/ร้านช่าง ทักรับราคาส่ง + รายการสต็อกเต็ม"
- **ทำไมเหมาะ KAN:** ใช้ฟีเจอร์ราคาส่ง (5 ตัว) ที่มีในเว็บอยู่แล้ว เจาะลูกค้า B2B ที่ซื้อซ้ำ-ซื้อเยอะ

### Brief 5 — Reels: "1 วันของร้านอะไหล่ KAN" (behind the scenes, สร้างตัวตน)
- **ฟอร์แมต:** Reels 15–20 วิ ตัดเร็ว มีเพลงเทรนด์
- **ฮุก:** "แพ็กของ 100 กล่องต่อวันหน้าตาเป็นยังไง?" + ภาพสต็อกเรียงสวย
- **โครง:** เช็กของแท้ → แพ็ก → ติดใบรับประกัน → ส่ง
- **CTA:** "สั่งวันนี้ ส่งไว — ทัก DM"
- **ทำไมเหมาะ KAN:** สร้างความจริงใจ/ความน่าเชื่อถือ (มีของจริง สต็อกเยอะ) = กลไก "คนจริง/ของจริง"

## 4) คำแนะนำฟอร์แมต & จังหวะโพสต์
- **อัตราส่วนสัปดาห์แรก (ลอง 5 โพสต์):** Reels 3 : Carousel 1 : รูป/สตอรี่ 1 — Reels หา reach, Carousel ปิดการขาย
- **ความยาว Reels:** 15–30 วิ (สั้นกว่า = ดูจบมากกว่า)
- **ทุกคลิปต้องมี:** ฮุกใน 3 วิ + คำบรรยายบนจอ (คนดูแบบปิดเสียง) + CTA ทัก DM/ไลน์
- **ภาษาแบรนด์:** โทนน้ำเงิน-ทอง, คำว่า "ของแท้ ตรงรุ่น รับประกัน" ย้ำทุกโพสต์
- **เริ่มวันนี้:** Brief 1 (Reels ก่อน/หลัง) — ต้นทุนถ่ายต่ำสุด ผลลัพธ์แรงสุด
