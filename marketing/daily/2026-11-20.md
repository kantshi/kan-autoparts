# รายงานการตลาดประจำวัน — 2026-11-20 (พฤหัสบดี)
**โฟกัส: Instagram Reels** · นักวิเคราะห์: รูทีนอัตโนมัติ KAN

---

## A. สแกนเทรนด์วันนี้ (ดูตลาด + คอนเทนต์)
1. **IG ไทย = ดินแดนของ Reels** — Meta ไทยระบุ Reels + DM คือวิธีหลักที่คนไทยใช้ IG,
   85% ของสิ่งที่แชร์ผ่านแชต IG เป็น Reels, ฐานผู้ใช้โต ~22.2 ล้าน (มี.ค. 2026)
   และ Meta เพิ่งลงแคมเปญ IG แรกเฉพาะไทยเพื่อดัน Reels โดยตรง
2. **สายยานยนต์: Reels ชนะทุกฟอร์แมต** — เบนช์มาร์กดีลเลอร์รถ Q3/2026:
   Reels ~25 interactions/โพสต์ > carousel 22 > ภาพเดี่ยว 9
3. **ฟอร์แมตที่คนในสายอะไหล่/ซ่อมรถแนะนำว่าปัง:** คลิป "เสียงนี้/อาการนี้แปลว่า…",
   คลิปวินิจฉัยอาการ→วิธีแก้, และ **เปรียบเทียบของเก่าสึก vs ของใหม่**
4. **รสนิยมคนไทย:** ชอบ edutainment (สอนไปสนุกไป) + เรื่องจริงใกล้ตัว + เจาะจงท้องถิ่น

## B. วิเคราะห์: ทำไมคอนเทนต์พวกนี้ถึงสำเร็จ (ถอดข้อดีมาใช้)
| คอนเทนต์ที่ปัง | ทำไมมันเวิร์ก | ข้อดีที่ KAN ขโมยมาใช้ |
|---|---|---|
| คลิป "เสียงนี้ = อาการ…" | Hook จากความกลัว/ความสงสัยของเจ้าของรถใน 2 วิแรก → หยุดนิ้ว | เปิดทุกคลิปด้วย "ปัญหา" ไม่ใช่ "สินค้า" |
| ของเก่าสึก vs ของใหม่ | ภาพเปรียบเทียบทำให้ดูจนจบ + อยากแชร์/คอมเมนต์ → อัลกอฯ ดันต่อ | ใช้ P2 (ของแท้ vs โทรม) เป็นตัวเรียก reach |
| คลิปสอน how-to ทีละสเต็ป | ให้คุณค่าฟรี → คน save ไว้ → สัญญาณคุณภาพต่ออัลกอฯ | ทำ how-to สั้นที่คน "เซฟไว้ใช้ภายหลัง" |
| edutainment ของแบรนด์ไทย | สอนของจริง = น่าเชื่อถือ, ไม่ใช่โฆษณาแข็ง → คนไม่เลื่อนหนี | ขายของแค่ 1 ใน 4–5 คลิป ที่เหลือให้คุณค่า |

**บทสรุปเชิงกลยุทธ์:** คนไม่ซื้ออะไหล่เพราะคลิปสวย แต่ซื้อเพราะ **เชื่อว่าร้านรู้จริง + ของถูกกว่า**
→ KAN มีจุดแข็ง "ราคาส่ง" อยู่แล้ว ขาดแค่คอนเทนต์ที่ **พิสูจน์ว่ารู้จริง** มานำหน้า แล้วปิดด้วยราคาส่ง

## C. แผน Reels พร้อมถ่าย — สัปดาห์นี้ (5 คลิป)
> ถ่ายด้วยมือถือแนวตั้งก็พอ เน้นภาพชัด + ข้อความซ้อน + CTA ทักไลน์/สั่งในแอป

### 🎬 Reel 1 — [P1 อาการเสีย] "3 เสียงที่บอกว่ารถคุณกำลังพัง"
- **Hook (0–2 วิ):** ขึ้นจอดำ ตัวอักษรใหญ่ "ได้ยินเสียงนี้ อย่าปล่อยผ่าน ⚠️"
- **เนื้อ:** โชว์ 3 อาการสั้น ๆ (เสียงเบรกเอี๊ยด = ผ้าเบรก, เสียงดังตอนเลี้ยว = ลูกหมาก, เสียงครืดตอนขับ = ลูกปืนล้อ) แต่ละอันขึ้นชื่ออะไหล่ที่ต้องเปลี่ยน
- **CTA:** "มีอาการไหน ทักไลน์ KAN เช็กราคาส่งได้เลย"
- **แฮชแท็ก:** `#อะไหล่รถยนต์ #ผ้าเบรก #ลูกหมาก #อาการรถเสีย #ช่างยนต์`

### 🎬 Reel 2 — [P2 เทียบของ] "ผ้าเบรกแบบนี้ = อันตราย ถึงเวลาเปลี่ยน"
- **Hook:** ถือผ้าเบรกสึกคู่กับของใหม่เข้ากล้อง "อันไหนควรอยู่ในรถคุณ?"
- **เนื้อ:** ชี้จุดสังเกตความหนา/ร่อง + เตือนอันตรายถ้าไม่เปลี่ยน
- **CTA:** "ผ้าเบรกแท้ราคาส่ง มีให้ทุกรุ่น ทักไลน์เลย"
- **แฮชแท็ก:** `#ผ้าเบรก #อะไหล่แท้ #ราคาส่งอะไหล่ #ดูแลรถ`

### 🎬 Reel 3 — [P3 ราคาส่ง ⭐] "ราคาส่งอาทิตย์นี้ที่ KAN"
- **Hook:** "ซื้อเยอะ = ยิ่งถูก 👇 ราคาส่งอาทิตย์นี้"
- **เนื้อ:** โชว์ 3–4 รายการขายดี + ป้ายราคาส่งต่อชิ้น (ดึงจากในแอป) เน้นตัวเลขใหญ่ ชัด
- **CTA:** "กดสั่งในแอป KAN หรือทักไลน์ ส่งไวทั่วประเทศ"
- **แฮชแท็ก:** `#ราคาส่งอะไหล่ #อะไหล่รถยนต์ #อู่ซ่อมรถ #ร้านอะไหล่`

### 🎬 Reel 4 — [P4 how-to] "เลือกอะไหล่ให้ตรงรุ่น ไม่ให้ซื้อผิด"
- **Hook:** "สั่งอะไหล่ผิดรุ่น = เสียเงินฟรี มาดู 3 ข้อนี้ก่อนสั่ง"
- **เนื้อ:** สอนดูรุ่น/ปี/เลขตัวถัง + บอกว่าทักไลน์ส่งทะเบียน/รุ่นมา KAN เช็กให้ได้
- **CTA:** "ไม่แน่ใจรุ่น ส่งรูปมาทางไลน์ เดี๋ยวเช็กให้"
- **แฮชแท็ก:** `#DIYรถยนต์ #อะไหล่รถยนต์ #วิธีเลือกอะไหล่`

### 🎬 Reel 5 — [P5 myth-busting ไวรัล] "เรื่องรถที่คนเข้าใจผิดมากที่สุด"
- **Hook:** "เปลี่ยนน้ำมันเครื่องทุก 5,000 โล = เสียเงินเกินจริงหรือเปล่า?"
- **เนื้อ:** ไขความเชื่อ 1 เรื่องแบบมีเหตุผล (กระตุ้นให้คนมาเถียง/คอมเมนต์ = reach พุ่ง)
- **CTA:** "คิดเห็นยังไง คอมเมนต์เลย · อะไหล่/น้ำมันครบ ราคาส่งที่ KAN"
- **แฮชแท็ก:** `#ความเชื่อผิดๆ #ดูแลรถ #รถยนต์ #ช่างยนต์`

## D. ลำดับความสำคัญสัปดาห์นี้
1. เริ่มถ่าย **Reel 1 + Reel 2** ก่อน (ต้นทุนต่ำ ได้ reach เร็วสุด)
2. **Reel 3 ราคาส่ง** โพสต์กลางสัปดาห์ตอนคน engage แล้ว (ปิดการขาย)
3. ทุกคลิปใช้เช็กลิสต์ใน `playbook.md` §5 ก่อนโพสต์

## E. สิ่งที่จะทำให้รายงานนี้แม่นขึ้น (ข้อเสนอ)
- **เชื่อม Instagram Insights / ส่งออกยอดวิว-ไลก์-เซฟของโพสต์ KAN** → จะได้วิเคราะห์คอนเทนต์
  "ของเราเอง" ว่าตัวไหนปังจริง ไม่ต้องเดาจากเบนช์มาร์กคนอื่น
- ระบุ **คู่แข่งบน IG 2–3 ร้าน** ให้ไว้ → รูทีนจะคอยส่องว่าเขาโพสต์อะไรแล้วปัง เอามาปรับใช้
