## 2. ถอดสูตร: ทำไม 3 คอนเทนต์นี้ถึงปัง

### 🅐 คลิป DIY "เปลี่ยนไส้กรองอากาศเอง" (746k วิว)
- **Hook:** แตะ "ความกังวลค่าซ่อม" ทันที — ช่างไม่มีเวลาบอกคุณ / เปลี่ยนเองประหยัดเป็นพัน
- **คุณค่า:** ผู้ชมได้ "เซฟเงิน + ทำเองได้" รู้สึก empower
- **ทำไมแชร์/เซฟ:** เป็นทิปใช้ได้จริง → คนเซฟไว้ทำตาม (save = สัญญาณดันแรงสุดของ IG)
- **บทเรียนสำหรับ KAN:** สอนของง่ายๆ ที่ลูกค้าทำเองได้ **แล้วปิดท้ายว่า "อะไหล่ตัวนี้สั่งที่ KAN ราคาส่ง"** — ให้ก่อน ขายทีหลัง

### 🅑 Before/After ล้าง-เคลือบเงา (ฟอร์แมตเห็นผลชัด)
- **Hook:** ภาพ "ก่อน" ที่สกปรก/หมองในวินาทีแรก สร้างความอยากเห็น "หลัง"
- **คุณค่า:** หลักฐานภาพ = ว้าว + น่าเชื่อถือ
- **บทเรียนสำหรับ KAN:** before/after ใช้ได้กับทุกอย่าง — อะไหล่เก่า vs ใหม่, ผ้าเบรกสึก vs ใหม่, ไฟหน้าเหลือง vs ใส. ของขัด/เคลือบคือ "ตัวนำ" ราคาถูกที่ทำคอนเทนต์นี้ง่ายสุด

### 🅒 Myth-busting "ทิปดูแลรถที่ทำรถพัง"
- **Hook:** ขัดความเชื่อ — "หยุด! อย่าทำแบบนี้กับรถ"
- **คุณค่า:** ป้องกันความเสียหาย + วางตัวเป็นผู้เชี่ยวชาญ
- **บทเรียนสำหรับ KAN:** เพราะทิปปลอมเกลื่อนโซเชียล KAN เล่นบท "ร้านอะไหล่ที่บอกความจริง" ได้เปรียบเรื่องความน่าเชื่อถือ → นำไปสู่ยอดขายระยะยาว (ร้านที่คนเชื่อ = เจ้าประจำ)

## 4. Quick wins ทำวันนี้ได้
1. **เริ่มที่คลิป #2 (Before/After เคลือบเงา)** — ต้นทุนต่ำ ถ่ายง่าย โอกาสปังสูง (ตรงกับของขายดีอันดับ 1 ตลาดไทย)
2. ทุกคลิป **ติดซับไทยบนจอ** + hook ใน 1–2 วิแรก
3. ใช้ **Trial Reels** ปล่อยให้คนนอก follower เห็น เพื่อหา follower ใหม่
4. ธีมตามฤดู: ใกล้ปีใหม่ → "เช็ก 5 อะไหล่ก่อนขับทางไกลเทศกาล" (เตรียมไว้เป็นคลิปซีรีส์)
