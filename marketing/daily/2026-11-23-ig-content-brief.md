# KAN IG Content Brief — 2026-11-23

> นักวิเคราะห์การตลาด (อัตโนมัติ): ดูเทรนด์ตลาด+คอนเทนต์ → ถอดว่าทำไมถึงปัง → แปลงเป็นแผน IG ให้ KAN
> วันแรกของการรันประจำวัน — ตั้งต้นด้วยการวางรากฐานเทรนด์ + เสนอคอนเทนต์ที่ลงมือได้เลยสัปดาห์นี้

---

## 1) เทรนด์วันนี้ (ภาพรวมตลาด + IG)

- **Reels ครองการเข้าถึง, Carousel ชนะยอดเซฟ** — Reels คือรูปแบบดีที่สุดสำหรับการมองเห็น(reach); Carousel ถูกเซฟมากกว่า ~2–3 เท่า โดยเฉพาะคอนเทนต์ "ให้ความรู้" (how-to) → KAN ควรใช้ทั้งสองคู่กัน: Reel ล่าคนใหม่, Carousel สร้างความไว้ใจ+ยอดเซฟ
- **บริบทไทยสำคัญมาก:** Meta Thailand ระบุ **85% ของคอนเทนต์ที่แชร์ผ่านแชทคือ Reels** และเวลาดู Reels โตกว่า 30% YoY → ออกแบบ Reel ให้ "น่าส่งต่อในแชท" (คนส่งให้เพื่อนที่กำลังหาอะไหล่)
- **ความเชี่ยวชาญ > ยอดฟอลโลเวอร์:** 81% ของผู้บริโภค(อ้างอิง Meta) มองว่า "ความรู้เชิงลึก" คือคุณสมบัติสำคัญที่สุดของครีเอเตอร์ → นี่คือสนามที่ KAN ได้เปรียบ เพราะขายอะไหล่ = มีความรู้ technical จริง
- **คอนเทนต์ดิบชนะคอนเทนต์เนี้ยบ:** พูดกล้องตรง ๆ ไม่ต้องตัดต่อเยอะ + ซับไตเติล กำลังเวิร์ก → ลดต้นทุนการผลิตของ KAN ลงได้มาก
- **อายุเทรนด์:** เสียง/เพลงพีคใน 7–10 วัน (ต้องรีบ), รูปแบบอยู่ได้ 3–4 สัปดาห์ (มีเวลาวางแผน) → KAN โฟกัส "รูปแบบ" ก่อน เพราะทำได้ยั่งยืนกว่าไล่ตามเพลง

## 2) คอนเทนต์ที่วิเคราะห์ + ทำไมถึงสำเร็จ (ถอดจุดเด่น)

วิเคราะห์ **3 รูปแบบ** ที่พิสูจน์แล้วในวงการรถ/อะไหล่ แล้วถอดว่าจุดเด่นคืออะไร:

**A. Before/After อะไหล่ (ของเก่าสึก vs ของใหม่)**
- *ทำไมปัง:* Hook แรงใน 3 วิ (ภาพของพังสะดุดตา) + ให้ผลลัพธ์จับต้องได้ → คนเซฟไว้เยอะ; โครงสร้าง before/after เป็นสูตรโฆษณาคลาสสิกที่หยุดนิ้วได้เสมอ
- *จุดเด่นที่ยืมมา:* "ความคมชัดของความต่าง" — ยิ่งเห็นความต่างชัด ยิ่งหยุดดู

**B. คลิปสั้น 15–30 วิ ชี้อะไหล่ 1 ชิ้น + อธิบายว่ามันทำงานยังไง/เสียแล้วเป็นไง**
- *ทำไมปัง:* สร้างภาพ "ผู้เชี่ยวชาญ" ภายในไม่กี่วินาที → ตรงกับที่คนไทยให้ค่าความรู้สูงสุด; ต้นทุนผลิตต่ำ ทำซ้ำเป็นซีรีส์ได้
- *จุดเด่นที่ยืมมา:* "1 คลิป = 1 ความรู้" ทำให้คนติดตามเพื่อรอดูตอนต่อไป

**C. OEM vs อะไหล่เทียบ (comparison + โพล)**
- *ทำไมปัง:* กระตุ้นให้คน "เลือกข้าง" → คอมเมนต์/ถกเถียง = engagement signal ที่อัลกอริทึมชอบ; โพล 3 ตัวเลือกดึงคนที่ปกติไม่คอมเมนต์ให้มีส่วนร่วม
- *จุดเด่นที่ยืมมา:* "ให้คนตัดสินใจ" ในคอนเทนต์ แทนการพูดฝ่ายเดียว

## 3) แปลงเป็นแผน KAN — เสนอ 3 โพสต์ IG (ลงมือได้สัปดาห์นี้)

### โพสต์ 1 — Reel: "อะไหล่ตัวนี้ ถึงเวลาเปลี่ยนหรือยัง?" (เน้น reach)
- **Hook (0–3 วิ):** ถือของพังขึ้นกล้อง + ข้อความ "เห็นแบบนี้ = อันตราย 🚨"
- **เนื้อ:** ชี้จุดสึก 2–3 จุด อธิบายสั้น ๆ ว่าถ้าปล่อยไว้จะเกิดอะไร (10–20 วิ) พูดกล้องตรง ๆ + ซับไตเติล
- **CTA:** "ไม่แน่ใจรุ่นรถตัวเอง ทัก DM เช็กให้เลย / เซฟไว้ก่อนลืม"
- **ทำไม:** ใช้จุดเด่น A+B, น่าส่งต่อในแชทให้เพื่อน, โชว์ความเชี่ยวชาญ

### โพสต์ 2 — Carousel: "5 สัญญาณว่า [อะไหล่ยอดฮิต] ใกล้พัง" (เน้น saves)
- **สไลด์ 1 (ปก):** หัวข้อใหญ่ + ภาพอะไหล่ ใช้สีแบรนด์ (น้ำเงิน/ทอง)
- **สไลด์ 2–6:** 1 สัญญาณ/สไลด์ ภาพประกอบชัด
- **สไลด์สุดท้าย:** "มีอาการนี้? KAN มีของพร้อมส่ง ราคาส่ง ทัก DM"
- **ทำไม:** Carousel+how-to = ยอดเซฟสูง, สร้างความไว้ใจกับคนที่ตามอยู่แล้ว

### โพสต์ 3 — Reel/Story โพล: "OEM หรืออะไหล่เทียบ? คุณเลือกแบบไหน"
- **รูปแบบ:** เทียบข้อดี-ข้อเสียสั้น ๆ + โพล 2–3 ตัวเลือก
- **CTA:** "คอมเมนต์รุ่นรถ เดี๋ยวแนะนำให้"
- **ทำไม:** ใช้จุดเด่น C ดัน engagement + เก็บ lead (รุ่นรถ) ไปปิดการขายใน DM

> **ปฏิทินแนะนำ:** โพสต์ 1 (Reel) ต้นสัปดาห์เพื่อ reach → โพสต์ 2 (Carousel) กลางสัปดาห์เก็บ saves → โพสต์ 3 (โพล) ปลายสัปดาห์เก็บ engagement
> เริ่มที่ **3 โพสต์/สัปดาห์** คุณภาพ > ปริมาณ (อัลกอริทึม 2026 ให้ค่าความสม่ำเสมอ+การมีส่วนร่วม มากกว่าการโพสต์ถี่)

## 4) ต้องรีบ vs รอข้อมูลจริง

- **ต้องรีบ:** ยังไม่มีเทรนด์เสียงที่อายุสั้นต้องไล่ตามวันนี้ → โฟกัสวาง "รูปแบบ" 3 แบบข้างบนก่อน (ยั่งยืน 3–4 สัปดาห์)
- **รอข้อมูลจริง:** ยังไม่ได้เชื่อม Instagram/Meta Insights ของ KAN ในเซสชันนี้ → ตัวเลขทั้งหมดเป็น "ทิศทางจากเทรนด์รวม" ไม่ใช่ของบัญชี KAN
  - **สิ่งที่ควรทำต่อ:** เชื่อม IG Insights เพื่อดู 3-sec retention / avg watch time / saves จริง แล้วค่อยทดสอบ hook แบบ A/B (เปลี่ยนแค่ 2–3 วิแรก ใช้ฟุตเทจเดียวกัน)
