# KAN Autoparts — Playbook นักวิเคราะห์การตลาด (Instagram)

> คู่มือนี้คือ "skill" ของนักวิเคราะห์การตลาดที่รันอัตโนมัติทุกวัน
> เป้าหมาย: ดูเทรนด์ตลาด + ถอดบทเรียนคอนเทนต์ที่ประสบความสำเร็จ → นำข้อดีมาวางแผนคอนเทนต์ IG ให้ KAN
> โฟกัส: **Instagram ก่อน** (ค่อยขยายไป TikTok/Facebook ภายหลัง)

---

## 1. KAN คือใคร (บริบทที่ต้องยึดทุกครั้ง)

- ธุรกิจ: ร้าน/ผู้จำหน่าย **อะไหล่รถยนต์** ขายทั้งปลีกและส่ง (มีราคาขายส่ง/bulk)
- ลูกค้าหลัก: ช่างยนต์/ร้านซ่อม + ผู้ใช้รถทั่วไปที่ซื้ออะไหล่
- แบรนด์: โทนสุภาพ-พรีเมียม — กรมท่า (navy #082B55), ทอง (#C99632), เขียวน้ำเงิน (teal #1C6668), ครีม (#F6F4ED), ฟอนต์ Sarabun
- ภาษา: ไทยเป็นหลัก
- จุดแข็งที่ขายได้: แคตตาล็อก SKU กว้าง, ราคาส่ง, สั่งออนไลน์ส่งทั่วไทย, ให้คำปรึกษาเรื่องรถ

## 2. รูทีนประจำวัน (ทำซ้ำทุกเช้า)

1. **สแกนเทรนด์** — ค้นเทรนด์ IG/Reels ของวันนั้น + เทรนด์คอนเทนต์สายยานยนต์ (ใช้ WebSearch)
2. **เลือกคอนเทนต์ตัวอย่าง 1–3 ชิ้นที่ปังจริง** แล้ว **ถอดบทเรียน (teardown)** ว่า *ทำไมถึงสำเร็จ* ด้วยเช็กลิสต์ข้อ 3
3. **แปลงเป็นแผนของ KAN** — ไอเดียโพสต์ IG ที่ลงมือทำได้จริงในสัปดาห์นั้น (ข้อ 4)
4. **บันทึกรายงานลง** `marketing/instagram/reports/YYYY-MM-DD.md` แล้ว commit (ห้ามเก็บแค่ใน session เพราะหาย)
5. **แจ้งเจ้าของ** เฉพาะ insight/แผนที่นำไปใช้ได้ — ไม่ใช่ "วันนี้รันแล้วปกติดี"

## 3. เช็กลิสต์ถอดบทเรียน "ทำไมคอนเทนต์นี้ถึงปัง"

ให้ตอบทุกข้อ แล้วดึง *หลักการ* ที่ KAN ลอกได้ (ไม่ใช่ลอกคลิป):

1. **Hook 1–2 วินาทีแรก** คืออะไร? (ปัญหา/อาการเสีย/ภาพ before ที่สะดุดตา)
2. **ความกระชับ** — จบใน <60 วิไหม? ตัดส่วนเกินออกหมดหรือยัง?
3. **Payoff ที่เห็นชัดแบบ binary** — มี before/after ที่ตาเห็นผลทันทีไหม? (= ดูจบ + แชร์)
4. **เสียง/ASMR/เพลงเทรนด์** — ใช้เสียงที่กำลังมา หรือเสียงลงชิ้นส่วนที่ฟังแล้วฟิน?
5. **ขายแบบไม่ขาย** — ตัวคอนเทนต์ = การสาธิตสินค้าแก้ปัญหาจริง มีลิงก์/โค้ด/ช่องทางสั่งแนบไหม?
6. **Social proof** — มีงานลูกค้าจริง/แฮชแท็กแบรนด์/รีวิวไหม? (รีวิว/คำแนะนำมีน้ำหนักตัดสินใจซื้อสูงสุดในไทย)
7. **ฟอร์แมต** — Reel (เน้น reach) หรือ Carousel (เน้น save/share, เหมาะคอนเทนต์ให้ความรู้)?

## 4. คลังฟอร์แมตที่เวิร์กสำหรับร้านอะไหล่ (หยิบไปปรับ)

| ฟอร์แมต | ทำไมเวิร์ก | ตัวอย่างของ KAN |
|---|---|---|
| Before/After ลงอะไหล่ | payoff เห็นชัด, แชร์ง่าย | อะไหล่เก่าสึก vs ใหม่ KAN + ลงจริง <30 วิ |
| ASMR แกะกล่อง/ลงชิ้นส่วน | ดูจบ, ฟิน | unbox SKU ยอดฮิต เสียงคลิกลงล็อก |
| Carousel "รถรุ่นไหนใช้ตัวไหน" | save สูง, ให้ความรู้ | ตารางอะไหล่ตามรุ่นรถ/เครื่อง |
| โชว์ทีม/หน้าร้าน/แพ็กของ | สร้างความไว้ใจ (เห็นหน้า = เชื่อใจ) | เบื้องหลังแพ็กออเดอร์ส่งทั่วไทย |
| โพล/ทายอะไหล่ (Story) | engagement | "ทายซิชิ้นนี้คืออะไร" |
| ฟีเจอร์งานลูกค้า + แฮชแท็ก | social proof | #KANautoparts งานช่างที่ใช้ของเรา |
| ดีล/ "คุ้มไม่คุ้ม" (ตามฤดู) | ตรงจังหวะซื้อ | ราคาส่งปลายปี/Black Friday สำหรับช่าง |

## 5. คำแนะนำช่องทาง/จังหวะ (baseline)

- **เริ่มที่ IG ให้สม่ำเสมอก่อน** — ฟีด 3–4 โพสต์/สัปดาห์, Story 2–3 ครั้ง/สัปดาห์
- ถ่ายด้วยมือถือแบบ raw ที่หน้าร้าน/ตอนลงอะไหล่ (ของจริงชนะของเนียนตอนนี้)
- ตั้ง **แฮชแท็กแบรนด์** ให้ลูกค้า/ช่างแท็กงาน
- ใส่ลิงก์สั่งซื้อ/LINE OA ใน bio (คนไทยมักดูคลิปสั้นเป็นด่านคัดกรองแรกแล้วค่อยซื้อ)

## 6. ข้อมูลที่ยังขาด (ทำให้วิเคราะห์แม่นขึ้น)

ตอนนี้ยัง **ไม่ได้เชื่อม analytics ของบัญชี IG ของ KAN** ดังนั้นรายงานจึงอิง "เทรนด์ภายนอก" เป็นหลัก
เพื่อให้วิเคราะห์ว่า *คอนเทนต์ของ KAN เอง* อันไหนปัง/ไม่ปัง ควรให้เจ้าของ:
- เชื่อม/ส่งออก Instagram Insights (reach, saves, shares, watch time รายโพสต์)
- หรือแปะสถิติโพสต์ย้อนหลัง 10–20 โพสต์ให้วิเคราะห์

> หมายเหตุความน่าเชื่อถือ: benchmark ตัวเลข engagement ส่วนใหญ่เป็นข้อมูลตลาดสหรัฐ/บทความการตลาด ใช้เป็นแนวทาง ไม่ใช่ตัวเลขยืนยันของตลาดไทย
