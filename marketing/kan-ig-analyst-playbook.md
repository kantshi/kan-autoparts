# KAN Autoparts — คู่มือนักวิเคราะห์การตลาด (IG Content Analyst Playbook)

> ไฟล์นี้คือ "skill.md" ของนักวิเคราะห์การตลาดประจำโปรเจกต์ KAN
> ใช้เป็นแนวทางให้งานวิเคราะห์เทรนด์รายวันทำซ้ำได้ สม่ำเสมอ และสะสมความรู้ไปเรื่อยๆ
> โฟกัสหลัก: **คอนเทนต์ Instagram** (Reels เป็นหัวใจ) ก่อนขยายไปแพลตฟอร์มอื่น

---

## 1. บริบทธุรกิจ KAN (ต้องท่องให้ขึ้นใจก่อนวิเคราะห์ทุกครั้ง)

- **ธุรกิจ:** ร้านอะไหล่รถยนต์ (auto parts) ขายทั้ง **ปลีกและส่ง** (มีราคา Price 2 = ราคาส่ง/ยกแพ็ก)
- **ช่องทางขาย/ปิดการขาย:** LINE OA (`@617ytnjm`) + เว็บแคตตาล็อกสินค้า
- **ลูกค้า 2 กลุ่ม:**
  1. **เจ้าของรถทั่วไป (ปลีก)** — อยากได้ของแท้ ราคาคุ้ม ติดตั้งง่าย รู้ว่าต้องเปลี่ยนเมื่อไหร่
  2. **อู่/ช่าง/ร้านค้า (ส่ง)** — เน้นราคาต้นทุน ความชัวร์ของ fitment สต็อกครบ ส่งไว
- **แบรนด์:** พรีเมียม — navy (#082B55) + ทอง champagne (#C99632) + teal + cream
  น้ำเสียง: น่าเชื่อถือ มืออาชีพ จริงใจ ไม่ตลาดจัด
- **บทบาทของ IG:** = **ต้นน้ำ (reach + สร้างความน่าเชื่อถือ)** → ทุกคอนเทนต์ต้องจบด้วย CTA ให้ทักเข้า **LINE OA** (ที่ที่ปิดการขายจริง)

## 2. กระบวนการทำงานรายวัน (Daily Routine)

ทุกวันทำ 4 ขั้น แล้วบันทึกผลลง `marketing/daily/YYYY-MM-DD.md`:

1. **ดูเทรนด์ (Scan)** — ส่องเทรนด์คอนเทนต์รถ/อะไหล่/สายซ่อม-แต่งรถบน IG & TikTok วันนี้
   (ฟอร์แมตที่กำลังมา, เสียง/เพลงที่ฮิต, มุมถ่าย, ฮุคที่เห็นซ้ำๆ)
2. **วิเคราะห์ว่าทำไมสำเร็จ (Why)** — คอนเทนต์ที่ปังเพราะอะไร แยกเป็น 3 เลเยอร์:
   - **จิตวิทยาผู้ชม** (อยากดูต่อเพราะอะไร — อยากรู้/พอใจ/ได้ประโยชน์/อิน)
   - **อัลกอริทึม** (ส่งสัญญาณอะไรให้ IG ดัน — retention, saves, shares, rewatch)
   - **ความเกี่ยวข้องกับการขาย** (นำไปสู่การซื้อ/ทักแชทได้จริงไหม)
3. **ถอดจุดแข็ง → ปรับใช้กับ KAN (Apply)** — แปลงจุดแข็งเป็นไอเดียคอนเทนต์ที่ KAN ถ่ายได้จริงด้วยของจริงในร้าน
4. **วางแผน + วัดผล (Plan & Measure)** — เสนอ 3–5 ชิ้นพร้อมฮุค/แคปชัน/CTA และระบุ KPI ที่ต้องเช็ก

> ไอเดียที่ยังไม่ได้ผลิต ให้ดองไว้ใน `marketing/content-backlog.md`

## 3. หลักการคอนเทนต์ IG ที่ยึดเป็นมาตรฐาน (อัปเดตจากงานวิจัยเทรนด์)

### ฟอร์แมตที่เวิร์กกับสายอะไหล่/รถ
| ฟอร์แมต | ทำไมเวิร์ก | KAN ถ่ายยังไง |
|---|---|---|
| **Before/After ของอะไหล่** | การเปลี่ยนที่เห็นชัด = "สะใจ" ดูจบทั้งคลิป (retention สูง) | ผ้าเบรก/ไส้กรอง/ลูกหมาก เก่าพังเทียบของใหม่ KAN |
| **Satisfying / ASMR ติดตั้ง** | เสียง+การลงล็อกพอดีกระตุ้นความพอใจ รีวอตช์ซ้ำ | เสียง "คลิก" ตอนประกอบ, เสียงเครื่องก่อน/หลังเปลี่ยน |
| **Education / Trivia สั้น** | ให้คุณค่าทันที → คน save & share, วางตัวเป็นผู้เชี่ยวชาญ | "ของแท้ vs ของเทียม ดูยังไง", "สัญญาณต้องเปลี่ยน X" |
| **Demo / How-to เลือก-ติดตั้ง** | ดูนาน + ตรงกับ intent คนกำลังจะซื้อ | วิธีเช็ก fitment ให้ตรงรุ่น, ติดตั้งเองได้ใน 3 ขั้น |
| **Collab ช่าง/อู่/เจ้าของรถ** | ยืมความน่าเชื่อถือของชุมชนรถ + ขยาย reach | อู่พาร์ทเนอร์รีวิวของจาก KAN |

### กฎทอง (ยึดทุกคลิป)
- **3 วินาทีแรกคือทุกอย่าง** — Skip Rate / retention คือสัญญาณอันดับ 1 ที่ IG ใช้ตัดสินว่าจะดันไหม
- **ฮุคต้องมีข้อความ overlay ตัวใหญ่ชัด** — คนส่วนใหญ่ดูแบบปิดเสียง ต้องเข้าใจทันทีว่าคลิปนี้เกี่ยวกับอะไร
- **ใช้ฟุตเทจจริงของตัวเอง** — อัลกอริทึมปี 2026 ดันคลิปต้นฉบับคุณภาพดี มากกว่าเพลงเทรนด์แปะบนภาพมั่วๆ (KAN ได้เปรียบเพราะมีของจริง/คลังจริง)
- **เสียงเนทีฟ** — เสียงเครื่อง/เสียงประกอบจริง มีพลังกว่าเพลงประกอบทั่วไปในสายรถ
- **CTA เดียวชัดเจน** — ทุกคลิปจบด้วย "ทักไลน์ @617ytnjm เช็กของ/ราคาส่ง"

### สูตรฮุค (เลือกใช้ตามคอนเทนต์)
- **Curiosity gap:** "90% ของคนเปลี่ยน [ชิ้นส่วน] นี้ช้าไป…"
- **Problem–solution:** "รถมีเสียงนี้ = [ชิ้นส่วน] ใกล้พัง"
- **Bold claim:** "ผ้าเบรกถูกที่สุดไม่ได้แปลว่าคุ้มที่สุด"
- **Question:** "รู้ไหมของแท้กับของเทียมต่างกันตรงไหน?"

## 4. KPI ที่ต้องติดตาม (ลำดับความสำคัญ)

1. **Retention 3 วินาทีแรก / % ดูจบ** — สุขภาพของฮุค (สำคัญสุด)
2. **Saves + Shares** — สัญญาณว่าคอนเทนต์ "มีคุณค่า" (ดันการเข้าถึงมากสุด)
3. **Reach / Views จาก non-followers** — การเติบโต (ใช้ฟีเจอร์ Trial Reels ทดสอบกับคนนอก)
4. **คลิก/ทักเข้า LINE OA หรือ DM** — ตัวชี้วัดปลายทางที่ผูกกับยอดขายจริง
5. **Follower growth** — ผลสะสม

> กลยุทธ์โต: ใช้ **Trial Reels** ทดสอบคอนเทนต์กับคนนอกก่อน แล้ว **รีโพสต์คลิปที่เคยปัง** ซ้ำในรูปแบบใหม่ (เคสจริงต่างประเทศโตได้หลักพันฟอลโลว์ต่อคลิป)

## 5. ข้อจำกัด/หมายเหตุของสภาพแวดล้อม

- เซสชันนี้ **WebFetch เข้าได้เฉพาะโดเมนที่อนุญาต** — ดึงหน้าเว็บบางเว็บไม่ได้ (เช่น fluxnote.io, carvertical.com) แต่ **WebSearch ใช้ได้ปกติ** จึงอิงสรุปจากผลค้นหา
- ยังไม่มีคอนเนกเตอร์ข้อมูลยอดขาย/โซเชียลของ KAN ต่อเข้ามา (HubSpot/QuickBooks ฯลฯ เชื่อมไม่ติดในเซสชันนี้) — การวิเคราะห์จึงอิงเทรนด์ตลาด + บริบทธุรกิจ หากต่อ Insight จริงของ IG/ยอดขายได้จะแม่นขึ้นมาก
- ตัวเลข engagement จากบล็อกการตลาดเป็นค่าโดยประมาณ (directional) ใช้ชี้ทิศ ไม่ใช่ตัวเลขชี้ขาด
