# KAN IG Content Playbook — สูตรคอนเทนต์ที่พิสูจน์แล้ว (ปรับเป็นของ KAN)

คลังสูตรที่ถอดมาจากคอนเทนต์สายรถ/อะไหล่/ดีเทลลิ่งที่เวิร์กจริง แล้วแปลงเป็นสิ่งที่ KAN ถ่ายเองได้
ทุกสูตรมี: **หลักการที่ทำให้สำเร็จ → วิธีทำแบบ KAN → hook → CTA**
(อัปเดตเพิ่มทุกวันเมื่อเจอหลักการใหม่ — last update: 2026-11-24)

---

## สูตร 1 — Before / After (การเปลี่ยนที่เห็นชัด)
- **ทำไมเวิร์ก:** สมองคนชอบ "ผลลัพธ์การเปลี่ยนแปลง" การเห็นก่อน-หลังในคลิปเดียวให้ความพึงพอใจทันทีและกระตุ้นการ *แชร์/เซฟ*
- **แบบ KAN:** ผ้าเบรกสึก/จานเบรกเป็นสนิม → ใส่ของ KAN → เบรกใหม่เอี่ยม | ไฟหน้าขุ่นเหลือง → เปลี่ยนหลอด/เจียรไฟ → ใสกิ๊ง | โช้คเก่าน้ำมันไหล → โช้คใหม่
- **Hook (3 วิ แรก):** โชว์ภาพ "after" ที่สวยที่สุดก่อน แล้วค่อยตัดกลับไป "before" + ข้อความทับ *"ชิ้นนี้พังจนเกือบทิ้ง...จนเจอตัวนี้"*
- **CTA:** "อะไหล่ตัวนี้ทักมาที่ LINE เช็กของ+ราคาได้เลย"

## สูตร 2 — ติดตั้ง/เปลี่ยนใน 60 วินาที (How-to สั้น)
- **ทำไมเวิร์ก:** คลิปสอนสั้นแบบจบใน 60 วิ เข้าถึงคนได้หลักพัน+ เพราะมี "คุณค่าใช้ได้จริง" คน *เซฟไว้ทำตาม* และแท็กเพื่อน
- **แบบ KAN:** เปลี่ยนกรองอากาศ / เปลี่ยนหลอดไฟหน้า / เช็ก-เปลี่ยนใบปัดน้ำฝน / เปลี่ยนไส้กรองแอร์ ทีละสเต็ปเร็วๆ
- **Hook:** *"เปลี่ยนเองได้ ไม่ต้องเข้าอู่ — ใช้เวลา 60 วิ"* + โชว์อะไหล่ในมือ
- **CTA:** "อะไหล่รุ่นรถคุณมีครบ สั่งผ่าน LINE ส่งถึงบ้าน"

## สูตร 3 — ASMR แกะกล่อง / เสียงน่าฟัง
- **ทำไมเวิร์ก:** กระแส ASMR ยังแรง — เสียงแกะซีล, เสียงประกบชิ้นส่วน, เสียงไขน็อต ทำให้คนดูจนจบ (watch time สูง = อัลกอริทึมดัน)
- **แบบ KAN:** แกะกล่องอะไหล่แท้ซีลโรงงาน โคลสอัพโลโก้แบรนด์/ซีล โชว์ความเนียบของงาน
- **Hook:** โคลสอัพมือกำลังแกะซีล + เสียงจริง ไม่มีเพลงพากย์ทับช่วงแรก
- **CTA:** "ของแท้ทุกชิ้น มีรับประกัน — ทัก LINE ดูสต็อก"

## สูตร 4 — ของแท้ vs ของเทียม (ให้ความรู้ + สร้างความเชื่อใจ)
- **ทำไมเวิร์ก:** ตลาดอะไหล่ไทยกลัวของปลอม/ของตาย มาก คอนเทนต์ที่ *สอนให้ดูออก* สร้าง authority และความไว้ใจ → คนตามเพจเพื่อ "ความรู้"
- **แบบ KAN:** วางของแท้ KAN เทียบของก๊อป ชี้จุดต่าง 3 จุด (ซีล/เนื้องาน/โค้ด) "เปลี่ยนของถูกแต่พังเร็ว = แพงกว่า"
- **Hook:** *"ของถูกกว่า 200 บาท แต่พังใน 2 เดือน — ดูตรงนี้ก่อนซื้อ"*
- **CTA:** "อยากได้ของแท้ชัวร์ ทัก LINE KAN"

## สูตร 5 — รีวิวลูกค้า/ช่างจริง (Social Proof)
- **ทำไมเวิร์ก:** สำหรับธุรกิจอะไหล่ "เสียงช่าง/ลูกค้าจริง" น่าเชื่อกว่าโฆษณาหลายเท่า เป็น proof ที่ปิดการขาย
- **แบบ KAN:** คลิปสั้นช่างอู่พูด "สั่งกับ KAN ของตรงรุ่น ส่งไว" / แคปแชต LINE ลูกค้าชม(เบลอข้อมูลส่วนตัว)
- **Hook:** หน้าช่าง/รถจริงในอู่ + คำพูดเด็ดประโยคเดียว
- **CTA:** "อู่ไหนอยากได้ราคาส่ง ทัก LINE มาเปิดบิลได้เลย"

## สูตร 6 — "อาการรถแบบนี้ ต้องเปลี่ยนอะไร" (Problem → Solution)
- **ทำไมเวิร์ก:** ตรงกับสิ่งที่คนค้นหา/กังวล ("รถมีเสียง", "เบรกสั่น") → ตอบปัญหา = ได้ทั้ง reach และคนทักถามรุ่น
- **แบบ KAN:** "เบรกมีเสียงเอี๊ยด = ผ้าเบรกหมด" / "พวงมาลัยสั่นตอนเบรก = จานเบรกคด" พร้อมอะไหล่ที่ต้องใช้
- **Hook:** เล่นเสียง/อาการจริง + ข้อความ *"รถคุณเป็นแบบนี้ไหม?"*
- **CTA:** "บอกรุ่นรถทาง LINE เดี๋ยวจัดให้ครบ"
