# KAN — Marketing Analyst Skill (นักวิเคราะห์การตลาด)

> Playbook สำหรับงานประจำวัน: ดูเทรนด์ตลาด + คอนเทนต์ → วิเคราะห์ว่าทำไมคอนเทนต์นั้นถึงสำเร็จ → ถอดจุดเด่นมาวางแผนคอนเทนต์ให้ KAN (เน้น Instagram ก่อน)
> ไฟล์นี้คือ "skill.md ของนักวิเคราะห์การตลาด" ที่ใช้ซ้ำได้ทุกวัน ปรับปรุงได้เรื่อย ๆ เมื่อมีข้อมูลจริงจาก Insights

---

## 1. KAN คือใคร (บริบทแบรนด์)

- **ธุรกิจ:** KAN Autoparts — ขายอะไหล่ยนต์ มีระบบจัดการออเดอร์ (ดูได้จาก `index.html`)
- **ลูกค้า:** มีทั้งร้าน/อู่/ช่าง (B2B — เห็นได้จากราคาส่ง/bulk pricing และ SKU) และผู้ใช้รถทั่วไป (B2C)
- **โทนแบรนด์ (จาก index.html):** น้ำเงินเข้ม `#082B55` / ทอง `#C99632` / เขียวเทอร์ควอยซ์ `#1C6668` / ครีม `#F6F4ED` — ดูพรีเมียม น่าเชื่อถือ สะอาด ฟอนต์ Sarabun
- **จุดขายที่ควรสื่อสาร:** ความเชี่ยวชาญเรื่องอะไหล่ (fitment/ของแท้-เทียบ), ราคาส่ง, ความไว, ความน่าเชื่อถือ

## 2. ทำอะไรทุกวัน (ขั้นตอน)

1. **สแกนเทรนด์ (15 นาที)** — เทรนด์ IG รายสัปดาห์/เดือน + เทรนด์วงการรถ/อะไหล่ + กระแสในไทย
   - แหล่งอ้างอิง: Metricool, Hootsuite, ContentStudio, New Engen (IG trends รายสัปดาห์), Meta Thailand / marketingoops / contentshifu (บริบทไทย)
   - ของจริงที่สุด: **Instagram Insights ของ KAN เอง** (ถ้าเชื่อม IG/Meta ได้) — ตัวเลข vendor blog เป็นแค่ทิศทาง ไม่ใช่ความจริงของบัญชีเรา
2. **หาคอนเทนต์ที่ "ปัง" 2–3 ชิ้น** — ในวงการรถ/อะไหล่/ช่าง หรือรูปแบบที่ยืมมาใช้ได้ (before/after, อธิบายของพัง, unbox)
3. **วิเคราะห์ว่าทำไมถึงสำเร็จ** — ใช้เฟรมเวิร์กข้อ 3
4. **แปลงเป็นแผนให้ KAN** — เสนอ 2–3 คอนเทนต์ IG ที่ทำได้จริงภายในสัปดาห์ พร้อม hook / รูปแบบ / CTA
5. **บันทึก** ลง `marketing/daily/YYYY-MM-DD-ig-content-brief.md`
6. **แจ้งเตือน** เฉพาะเมื่อมีเทรนด์ที่ควรรีบทำ (อายุเทรนด์สั้น) หรือข้อเสนอที่ควรลงมือ ถ้าเป็นวันธรรมดา ๆ ไม่มีอะไรใหม่ → บันทึกเฉย ๆ ไม่ต้องรบกวน

## 3. เฟรมเวิร์ก "ทำไมคอนเทนต์ถึงสำเร็จ" (ถอดจุดเด่น)

ดูทุกชิ้นด้วย 5 แกนนี้ แล้วสรุปว่า "จุดเด่นที่ยืมมาใช้กับ KAN ได้คืออะไร":

| แกน | คำถาม | ใช้กับ KAN ยังไง |
|---|---|---|
| **Hook (3 วิแรก)** | หยุดนิ้วคนดูด้วยอะไร? ภาพ/คำถาม/ตัวเลข/ของพัง? | เปิดด้วยภาพอะไหล่พังชัด ๆ หรือคำถาม "อะไหล่ตัวนี้ถึงเวลาเปลี่ยนหรือยัง?" |
| **รูปแบบ (Format)** | Reel / Carousel / Story? before-after, comparison, how-to, storytime? | Reel = การเข้าถึง(reach) / Carousel = ยอดเซฟ(saves) + ความรู้ |
| **คุณค่า (Value)** | ให้ความรู้ / ความบันเทิง / ความอยากได้ / ความไว้ใจ? | KAN ชนะด้วย "ความเชี่ยวชาญ" (ไทย: 81% ของผู้บริโภคให้ค่าความรู้ของครีเอเตอร์มากที่สุด) |
| **อารมณ์/การมีส่วนร่วม** | ทำไมคนคอมเมนต์/เซฟ/แชร์? โพล? เดา? เถียงกัน OEM vs เทียบ? | ใส่โพล/คำถามปลายเปิด/ของ-เทียบ ให้คนคอมเมนต์ |
| **CTA** | ปิดท้ายให้ทำอะไร? ทัก DM? เซฟไว้? | นำไปสู่การสั่งซื้อ/ทัก DM เช็คสต็อก/ราคาส่ง |

**หลักที่ยืนยันซ้ำจากข้อมูล (ใช้เป็นเข็มทิศ):**
- Reels ครองการเข้าถึง; Carousel ชนะเรื่องยอดเซฟ โดยเฉพาะคอนเทนต์ให้ความรู้ (how-to/fitment)
- Hook ต้องชนะใน 1–3 วินาทีแรก เป้า 3-second retention > 60% ถือว่าโอเค, > 80% ดีมาก
- คอนเทนต์ดิบ ๆ พูดกล้องตรง ๆ (ไม่ต้องตัดต่อเยอะ) + ซับไตเติล ทำงานได้ดี
- **บริบทไทย:** 85% ของคอนเทนต์ที่แชร์ผ่านแชทคือ Reels → ออกแบบ Reel ให้ "ส่งต่อในแชทง่าย" (มีประโยชน์/น่าส่งให้เพื่อนที่กำลังหาอะไหล่)
- อายุเทรนด์: เทรนด์เสียง/เพลงพีคใน 7–10 วัน, เทรนด์รูปแบบอยู่ได้ 3–4 สัปดาห์ → เสียงต้องรีบ, รูปแบบมีเวลาวางแผน

## 4. คลังรูปแบบคอนเทนต์ที่เหมาะกับ KAN (เลือกหมุนใช้)

1. **Before/After อะไหล่** (Reel) — ของเก่าสึก vs ของใหม่ เคียงกัน เปิดด้วยภาพพังชัด ๆ
2. **"อะไหล่ตัวนี้คืออะไร / เสียแล้วเป็นยังไง" 15–30 วิ** (Reel) — ชี้อะไหล่ 1 ชิ้น อธิบายสั้น → สร้างภาพผู้เชี่ยวชาญ
3. **OEM vs อะไหล่เทียบ** (Carousel/โพล) — เทียบข้อดี-ข้อเสีย ชวนคนเลือกในคอมเมนต์
4. **How-to / วิธีเช็กว่าอะไหล่ถึงเวลาเปลี่ยน** (Carousel) — คนเซฟไว้เยอะ
5. **เบื้องหลังคลัง/การแพ็ก (ASMR)** (Reel) — สร้างความน่าเชื่อถือ + ความเร็วในการส่ง
6. **Unbox / รีวิวจากลูกค้า-ช่าง** (Reel/Story) — social proof
7. **ซีรีส์ต่อเนื่อง** เช่น "อะไหล่ประจำสัปดาห์" — ใช้ serialized/linked Reels สร้างคนติดตาม

## 5. รูปแบบผลลัพธ์รายวัน (เขียนลง daily/)

```
# KAN IG Content Brief — YYYY-MM-DD
## 1) เทรนด์วันนี้ (3–5 bullet, พร้อมที่มา)
## 2) คอนเทนต์ที่วิเคราะห์ + ทำไมถึงสำเร็จ (ถอดด้วยเฟรมเวิร์กข้อ 3)
## 3) แปลงเป็นแผน KAN — เสนอ 2–3 โพสต์ IG (hook / format / สคริปต์ย่อ / CTA / วันลง)
## 4) สิ่งที่ต้องรีบ (ถ้ามีเทรนด์อายุสั้น) + สิ่งที่รอข้อมูลจริงจาก Insights
```

## 6. ข้อควรระวัง (ความซื่อสัตย์ของข้อมูล)

- ตัวเลขจาก marketing/vendor blog = **ทิศทาง ไม่ใช่ข้อเท็จจริง** ของบัญชี KAN; อย่านำเสนอเป็นของตาย
- ยังไม่มีการเชื่อม Instagram/Meta Insights ของ KAN ในเซสชันนี้ → ข้อเสนอเป็นสมมติฐานที่ต้องเอาไปทดสอบจริง (A/B hook, วัด 3-sec retention + avg watch time + saves)
- ถ้าภายหลังเชื่อม IG ได้ ให้เปลี่ยนจาก "สมมติฐานจาก trend" → "ข้อเสนอจากตัวเลขจริงของ KAN"

## 7. skill อื่นของ KAN/ระบบที่หยิบมาเสริมได้

- `small-business:content-strategy` — ทำแผนคอนเทนต์ 30 วันจากข้อมูลยอดขาย (ต้องเชื่อม PayPal/QuickBooks)
- `small-business:social-content-engine` / `canva-creator` — ทำปฏิทินโพสต์ + สร้างชิ้นงาน Canva (ต้องเชื่อม Canva/HubSpot)
- `small-business:growth-pulse` — เช็กว่าการตลาด/ช่องทางไหนได้ผล
- `dataviz` / `artifact-design` — ถ้าจะทำสรุปเทรนด์เป็นหน้าเว็บ/กราฟให้ดูง่าย

> หมายเหตุ: คอนเนกเตอร์หลายตัว (Canva, HubSpot, QuickBooks ฯลฯ) ยังเชื่อมไม่ได้ในสภาพแวดล้อมนี้ จึงใช้การวิเคราะห์จากการค้นเว็บเป็นหลักไปก่อน
