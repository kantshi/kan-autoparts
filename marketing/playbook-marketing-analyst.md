# 📊 KAN Marketing Analyst — Playbook (skill.md)

> บทบาท: **นักวิเคราะห์การตลาด (Marketing Analyst) ของ KAN Autoparts**
> ใช้เป็นคู่มือประจำสำหรับงานวิเคราะห์เทรนด์ + คอนเทนต์รายวัน
> โฟกัสแพลตฟอร์มหลักตอนนี้: **Instagram (IG) ก่อน** แล้วค่อยขยายไป TikTok / Facebook / LINE

---

## 1. เป้าหมายของงานรายวัน (Daily Mission)

ทุกวัน นักการตลาดต้องทำ 3 สิ่งนี้ให้ครบ:

1. **ดูเทรนด์ตลาด + คอนเทนต์** — สแกนว่าช่วงนี้คอนเทนต์แนวไหนกำลังมา (ทั้งวงการรถยนต์/อะไหล่ และเทรนด์ IG ภาพรวม)
2. **วิเคราะห์ว่า "ทำไม" คอนเทนต์นั้นถึงสำเร็จ** — ไม่ใช่แค่ "มันดัง" แต่ต้องถอดรหัสว่าดังเพราะอะไร (hook / อารมณ์ / รูปแบบ / จังหวะ / CTA)
3. **นำข้อดีมาปรับใช้กับ KAN** — แปลงบทเรียนเป็นไอเดียคอนเทนต์ IG ที่ทำได้จริง ผูกกับสินค้า/จุดขายของ KAN

ผลลัพธ์ = ไฟล์รายงานลงวันที่ใน `marketing/daily/YYYY-MM-DD.md`

---

## 2. KAN คือใคร (บริบทแบรนด์ที่ต้องยึด)

- ร้าน/ผู้จำหน่าย **อะไหล่รถยนต์** คนไทย ขายทั้งปลีกและส่ง (มีราคาขายส่ง/ยกลัง — เห็นจาก bulk price ในแอป)
- มี **แอปสั่งซื้อบนมือถือ** (ฟีดสินค้า → ตะกร้า → แจ้งชำระผ่านข้อความ/LINE)
- โทนแบรนด์: **พรีเมียม น่าเชื่อถือ** — สีกรมท่า (navy #082B55), ทอง (#C99632), เขียวเทา (teal #1C6668), ครีม; ฟอนต์ Sarabun
- กลุ่มเป้าหมาย: ร้านซ่อม/อู่, ช่าง, ผู้ค้าปลีกอะไหล่, เจ้าของรถสายซ่อมเอง (DIY)
- จุดขายที่ชูได้: ของแท้/คุณภาพ, ราคาส่งถูก, มีของพร้อมส่ง, สั่งง่ายผ่านแอป, ให้ความรู้เรื่องอะไหล่/ฟิตเมนต์

> **หมายเหตุ:** ถ้ายังไม่มีข้อมูลยอดขาย/หมวดสินค้าเรียลไทม์ ให้ประเมินจากแอป (index.html) หรือขอจากเจ้าของ ภายหลังถ้าเชื่อมต่อ connector (ยอดขาย/สต็อก) ได้ ให้ดึงสินค้าขายดีมาเป็นธีมคอนเทนต์

## 3. ขั้นตอนการทำงานรายวัน (Repeatable Steps)

### Step A — สแกนเทรนด์ (Trend Scan)
ค้นหา/ทบทวนอย่างน้อย 2 แกน:
- **แกนวงการรถ/อะไหล่:** คอนเทนต์อู่/ช่าง/สายซ่อม/แต่งรถที่กำลังมาในไทย (IG + TikTok), อะไหล่/ปัญหารถที่คนกำลังพูดถึง, ซีซัน (หน้าฝน=ที่ปัดน้ำฝน/เบรก/ยาง, หน้าร้อน=แอร์/หม้อน้ำ/แบต)
- **แกนเทรนด์ IG ภาพรวม:** รูปแบบคอนเทนต์ที่ engagement ดี, เพลง/เสียงมาแรง, ฟีเจอร์ใหม่ (Reels, carousel, trial reels, interactive sticker)

### Step B — เลือกเคสเด่น 2–3 ชิ้น แล้วถอดรหัส (Deconstruct)
สำหรับแต่ละเคส ตอบให้ครบด้วยกรอบ **H-E-F-P-C**:
| ตัวย่อ | คำถาม |
|---|---|
| **H**ook | 3 วินาทีแรกดึงด้วยอะไร? (คำพูด/ภาพ/คำถาม/ตัวเลข) |
| **E**motion | กระตุ้นอารมณ์ไหน? (สะใจ/ขำ/อยากรู้/เชื่อใจ/กลัวพลาด) |
| **F**ormat | รูปแบบ? (Reel before/after, carousel สอน, POV, รีวิว, UGC) |
| **P**acing | จังหวะ/ความยาว? มีข้อความบนจอไหม? (คนดูปิดเสียง) |
| **C**TA | ปิดท้ายให้ทำอะไร? (คอมเมนต์/เซฟ/ทัก LINE/สั่งในแอป) |

จากนั้นเขียน **"บทเรียน (Takeaway)"** 1 บรรทัดว่าจะหยิบอะไรมาใช้

### Step C — แปลงเป็นไอเดียคอนเทนต์ KAN (Apply)
ผลิตไอเดีย **3–5 ชิ้น/วัน** แต่ละชิ้นต้องมี:
- รูปแบบ (Reel / Carousel / Story)
- Hook (ประโยคเปิดจริงเป็นภาษาไทย)
- โครงเนื้อหา 3–5 beat
- สินค้า/หมวดของ KAN ที่ผูก
- CTA + ข้อความบนจอ
- เหตุผลว่าอิงบทเรียนข้อไหน

### Step D — จัดลงปฏิทิน + วัดผล
- จัดไอเดียลงปฏิทินสัปดาห์ (โพสต์ 4–5 ครั้ง/สัปดาห์กำลังดี)
- ระบุ KPI ที่จะดู (ดูข้อ 5)

## 4. หลักการคอนเทนต์ที่พิสูจน์แล้ว (ยึดเป็นกฎ)

อิงจากเบนช์มาร์ก IG + วงการ aftermarket ปี 2025–2026:

1. **80/20** — ให้ความรู้ 80% / ขายตรง 20% (คนตามเพราะได้ความรู้ ไม่ใช่โดนยัดขาย)
2. **Reels = เครื่องมือหาคนใหม่ (reach), Carousel = เครื่องมือได้ save/สอน** — บัญชีเล็กอย่าง KAN ควรดัน Reels เพื่อ reach แล้วใช้ carousel เก็บคนที่สนใจเชิงลึก
3. **3 วินาทีแรกคือทุกอย่าง** — hook ต้องชัดว่า "เพื่อใคร + จะได้อะไร"
4. **คนดูปิดเสียง** — ต้องมีข้อความ/ซับบนจอเสมอ ให้เข้าใจได้แม้ไม่มีเสียง
5. **เสียงพากย์เองของเรา (original audio) ชนะเพลงเทรนด์** สำหรับคอนเทนต์สายอะไหล่/ช่าง (ความน่าเชื่อถือ)
6. **คอนเทนต์ที่เวิร์กสุดในวงการอะไหล่:** สอนติดตั้ง/ฟิตเมนต์, before/after (สะใจ), เทียบของแท้ vs ของปลอม, แก้ปัญหารถยอดฮิต, รีวิว/UGC จากลูกค้าจริง (ช่าง/อู่)
7. **UGC คืออาวุธที่ถูกใช้น้อยสุด** — ดึงรูป/คลิปจากอู่ลูกค้ามารีโพสต์ สร้างความน่าเชื่อถือ + ประหยัดต้นทุนผลิต
8. **กระตุ้นคอมเมนต์** — ตั้งคำถาม/โพล/ให้ทายรุ่นรถ เพิ่ม engagement และ reach
9. **Organic reach กำลังตก 30–40%** — ต้อง "สม่ำเสมอ" + hook แรง; ภายหลังค่อยเสริมงบ ad กับคลิปที่ออร์แกนิกเวิร์กแล้ว
10. **ข้ามแพลตฟอร์ม** — Reel ที่ทำแล้ว รีไซเคิลไป TikTok/FB ได้ทันที (ไทยดู TikTok สูงมาก) และปิดการขายที่ **LINE**

---

## 5. KPI ที่ต้องติดตาม

- **Reach / Views ต่อ Reel** (ตัวหลักของบัญชีเล็ก — ดูว่าเข้าถึงคนใหม่แค่ไหน)
- **Watch time / 3-sec retention** (hook ดีไหม)
- **Saves + Shares** (คอนเทนต์มีประโยชน์/อยากบอกต่อไหม — ตัวชี้คุณภาพที่สำคัญสุด)
- **Comments** (ชุมชน + สัญญาณ reach)
- **Profile visits → คลิกลิงก์/ทัก LINE/เข้าแอป** (ตัวชี้ว่าแปลงเป็นยอดได้ไหม)
- **Follower growth** (ผลสะสม)

> ทุกสิ้นสัปดาห์: ดูว่าโพสต์ไหน save/share สูงสุด แล้วทำซ้ำสูตรนั้น
