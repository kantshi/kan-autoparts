# KAN Autoparts — IG Content Playbook (Living Document)

> คู่มือหลักที่สะสมบทเรียนขึ้นเรื่อย ๆ อัปเดตโดยรูทีนวิเคราะห์การตลาดรายวัน
> อัปเดตล่าสุด: 2026-11-20

---

## 1. KAN เป็นใคร (บริบทที่ใช้วางคอนเทนต์)
- ร้านอะไหล่รถยนต์ ลูกค้าคนไทย ขายทั้ง **ปลีกและส่ง** (จุดเด่น: มี "ราคาส่ง" ต่อชิ้น)
- สั่งซื้อผ่านเว็บแอปบนมือถือ + ติดต่อผ่าน **LINE** และ **IG**
- กลุ่มเป้าหมายหลักที่น่าจะอยู่บน IG:
  1. **อู่/ช่างรายย่อย + ร้านอะไหล่ที่ซื้อไปขายต่อ** → สนใจราคาส่ง, ของมีสต็อก, ส่งไว
  2. **เจ้าของรถสาย DIY / คนรักรถ** → สนใจวิธีเลือกของแท้, อาการเสีย, เปรียบเทียบของ
  3. **เจ้าของรถทั่วไป** → สนใจ "รถมีอาการนี้ต้องเปลี่ยนอะไร ราคาเท่าไร"

## 2. เทรนด์ที่ยืนยันแล้ว (ใช้เป็นฐานตัดสินใจ)
| เทรนด์ | ข้อมูลสนับสนุน | แปลว่า KAN ต้องทำอะไร |
|---|---|---|
| **Reels ครอง IG ในไทย** | 85% ของคอนเทนต์ที่แชร์ผ่านแชต IG เป็น Reels; ผู้ใช้ IG ไทย ~22.2 ล้าน (มี.ค. 2026) | เททรัพยากรไปที่ **วิดีโอสั้นแนวตั้ง** ไม่ใช่ภาพนิ่ง |
| **Reels = engagement สูงสุดในสายยานยนต์** | Reels ~25 interactions/โพสต์ > carousel 22 > ภาพเดี่ยว 9 (เบนช์มาร์กดีลเลอร์รถ Q3/2026) | โพสต์หลักควรเป็น Reel, carousel เป็นตัวรอง, ภาพเดี่ยวน้อยที่สุด |
| **คนไทยชอบ edutainment + เรื่องจริงใกล้ตัว** | งานวิจัยตลาดไทย 2026: "authentic, local, relatable + สอนไปขำไป" ชนะ | เนื้อหาต้อง **สอนของจริง + ดูสนุก** ไม่ใช่โฆษณาแข็ง ๆ |
| **เพลงมาแรง + แฮชแท็กตรงกลุ่ม ช่วยการเข้าถึง** | คำแนะนำซ้ำกันหลายแหล่ง; เลี่ยง #fyp #viral แบบเหวี่ยงแห | ใช้เสียงเทรนด์ + แฮชแท็กเฉพาะรุ่นรถ/อะไหล่ |
| **TikTok engagement (4.2%) > IG (1.45%) ในสายยานยนต์** | เบนช์มาร์ก 2026 | ทำ IG ให้นิ่งก่อน แล้วรีไซเคิลคลิปเดิมลง TikTok ทีหลังได้คุ้มมาก |

## 3. ทำไมคอนเทนต์สายอะไหล่/ซ่อมรถถึง "ปัง" (สูตรที่ถอดออกมา)
สิ่งที่คลิปยอดสูงในสายนี้ทำเหมือนกัน — **เอามาปรับใช้กับทุกคลิปของ KAN**:
1. **Hook ใน 2 วินาทีแรก** — ขึ้นด้วยปัญหา/คำถามที่คนมีรถต้องหยุดดู
   เช่น "เสียงนี้ = เบรกกำลังจะพัง", "อย่าเพิ่งเปลี่ยนทั้งชุด ถ้ายังไม่ดูอันนี้"
2. **ให้ของมีค่าฟรีก่อน (edutainment)** — สอนให้คนดู "วินิจฉัยเองได้" เขาถึงจะเชื่อและซื้อ
3. **เปรียบเทียบเห็นภาพ** — ของเก่าสึก vs ของใหม่ / ของแท้ vs ของเทียบ / ก่อน-หลัง
   ภาพ before-after ทำให้คนดูจนจบและคอมเมนต์
4. **เจาะจงรุ่นรถ** — "สำหรับ Vigo / D-Max / Triton" ทำให้ตรงกลุ่มและอัลกอฯ ส่งถูกคน
5. **CTA เดียว ชัด ๆ ตอนจบ** — "ทักไลน์เช็กราคาส่ง" หรือ "กดสั่งในแอป" อย่าใส่หลาย CTA
6. **ข้อความซ้อนบนคลิป (text overlay)** — คนไทยดูแบบปิดเสียงเยอะ ต้องอ่านรู้เรื่องแม้ไม่มีเสียง

> หัวใจ: **สอนของจริง → สร้างความเชื่อถือ → ปิดด้วยราคาส่งที่เป็นจุดแข็งของ KAN**
> คนไม่ได้ซื้ออะไหล่เพราะคลิปสวย แต่ซื้อเพราะ "ร้านนี้รู้จริงและของถูกกว่า"

## 4. เสาหลักคอนเทนต์ของ KAN (Content Pillars)
หมุนเวียน 5 เสานี้ ให้ feed ไม่น่าเบื่อและครบทุกกลุ่มเป้าหมาย:

| # | เสา | เป้าหมาย | ตัวอย่างฟอร์แมต Reel |
|---|---|---|---|
| P1 | **อาการเสีย → อะไหล่ที่ต้องเปลี่ยน** | ดึงเจ้าของรถทั่วไป | "เสียงนี้/ไฟนี้ขึ้น = ต้องเปลี่ยน…" |
| P2 | **ของแท้/ของดี vs ของโทรม-ของปลอม** | สร้างความน่าเชื่อถือ | วางเทียบ + ชี้จุดสังเกต |
| P3 | **ราคาส่ง / ดีลประจำสัปดาห์** ⭐ | จุดขายหลัก ปิดการขาย | "ราคาส่งอาทิตย์นี้" + วิธีสั่ง |
| P4 | **วิธีเลือก/ติดตั้ง/ดูแล** (how-to) | ให้คุณค่า + SEO คำค้น | สอนทีละสเต็ปสั้น ๆ |
| P5 | **ความเชื่อผิด ๆ เรื่องรถ (myth-busting)** | ไวรัล + คอมเมนต์เยอะ | "เรื่องนี้คนเข้าใจผิดกันเยอะ" |

**สัดส่วนแนะนำต่อสัปดาห์ (โพสต์ 4–5 ชิ้น):** P1 และ P2/P4 อย่างละ 1, P3 ราคาส่ง 1, P5 ไวรัล 1
→ ให้คุณค่า/ความน่าเชื่อถือ 3–4 ชิ้น ต่อขายตรง 1 ชิ้น (กันคนเบื่อโฆษณา)

## 5. เช็กลิสต์ก่อนโพสต์ทุกคลิป
- [ ] Hook ชัดใน 2 วิแรก (ขึ้นปัญหา/ตัวเลข/คำถาม)
- [ ] มี text overlay อ่านรู้เรื่องแม้ปิดเสียง
- [ ] ระบุรุ่นรถ/ยี่ห้ออะไหล่ให้เจาะจง
- [ ] ใช้เสียง/เพลงที่กำลังเทรนด์ (เช็กแท็บ Reels ก่อนถ่าย)
- [ ] CTA เดียว → LINE หรือสั่งในแอป
- [ ] แฮชแท็กตรงกลุ่ม (รุ่นรถ + ประเภทอะไหล่) ไม่ใช่ #fyp เหวี่ยงแห
- [ ] ความยาว 15–30 วิ กำลังดี

## 6. ชุดแฮชแท็กตั้งต้น (ปรับตามคลิป)
`#อะไหล่รถยนต์ #อะไหล่แท้ #ราคาส่งอะไหล่ #อู่ซ่อมรถ #ช่างยนต์ #DIYรถยนต์`
\+ แท็กเฉพาะรุ่น เช่น `#Vigo #Dmax #Triton #Fortuner #อีโค่คาร์` ตามสินค้าในคลิป

## 7. ไอเดียวัดผล (เมื่อมีข้อมูลจริง)
ถ้าเชื่อม IG Insights ได้ ให้ดู: **Reach ของผู้ไม่ติดตาม** (คลิปไหนอัลกอฯ ดันออกไปไกล),
**Watch time / ดูจนจบ** (hook ดีไหม), **Saves + Shares** (คอนเทนต์มีค่าไหม), **คลิก LINE/ลิงก์สั่ง** (ปิดการขายได้ไหม)
— จำนวนไลก์สำคัญน้อยสุดในสายนี้
