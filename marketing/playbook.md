# Playbook — นักวิเคราะห์การตลาดคอนเทนต์ KAN (IG-first)

คู่มือการทำงานประจำวัน. เป้าหมาย: ไม่ใช่แค่ "หาเทรนด์" แต่ **ถอดสูตรว่าทำไมมันปัง แล้วแปลงเป็นโพสต์ของ KAN ที่ลงมือทำได้วันนี้**

## ขั้นตอนประจำวัน (ทำซ้ำทุกเช้า)
1. **สแกนเทรนด์** — คอนเทนต์รถยนต์/อะไหล่/ดูแลรถที่กำลังปังบน IG & TikTok (ไทย + สากล), รูปแบบ/เสียง/แฮชแท็กที่มาแรง
2. **เลือก 1–3 ชิ้นที่ปังจริง** แล้ววิเคราะห์ด้วย 4 คำถาม:
   - Hook: 1–2 วินาทีแรกดึงคนยังไง? พูดกับใคร?
   - คุณค่า: ให้ "ประโยชน์/อารมณ์" อะไร (ประหยัดเงิน, กลัวพลาด, ว้าว, ขำ, เชื่อถือได้)?
   - รูปแบบ: ความยาว, ตัดต่อ, before/after, มีซับ/ข้อความบนจอไหม?
   - ทำไมคนแชร์/เซฟ/คอมเมนต์? (share & save = สัญญาณที่อัลกอริทึม IG ดันแรงสุด)
3. **แปลงเป็นของ KAN** — เอาสูตรมาใส่สินค้า/บริการจริงของ KAN (อะไหล่, ราคาส่ง, สั่งผ่าน LINE)
4. **ส่งแผน** — ไอเดียโพสต์พร้อม Hook + CTA + สินค้าที่เกี่ยวข้อง, จัดลำดับความสำคัญ
5. **วัดผลย้อนหลัง** (เมื่อมีข้อมูล) — ดูโพสต์ KAN ที่ผ่านมา อันไหนเวิร์ก เก็บเข้า playbook

## สูตรที่พิสูจน์แล้ว (อัปเดตจากการวิเคราะห์ 2026-11-22)

### รูปแบบ
- **Reels/วิดีโอสั้นแนวตั้ง 9:16 ชนะขาด** — ดู ~3 เท่า, reach ~2 เท่าของภาพนิ่ง. หมวดยานยนต์ engagement บน Reels ~3.2%
- **ติดซับ/ข้อความบนจอเสมอ** — คนดูแบบปิดเสียงเยอะมาก
- **ตัดต่อกระชับ จังหวะไว** รักษาความสนใจ
- ภาพนิ่ง/carousel ใช้ได้กับ "สเปค/เทียบรุ่น/โปรราคาส่ง" แต่ตัวดันยอด reach คือ Reels

### Hook (1–2 วินาทีแรกคือทุกอย่าง)
- **Hook แบบระบุตัวตน**: "ถ้าคุณขับ [รุ่นรถ]..." / "เจ้าของอู่ฟังทางนี้" — คนรู้สึกว่าพูดกับเขา
- **"วิธีที่ผม/เรา..." > "วิธีการ..."** — ให้ความรู้สึกแชร์ประสบการณ์ ไม่ใช่สอน
- **แตะความกลัว/ความอยากประหยัด**: "อย่าเพิ่งจ่ายค่าอู่ ถ้ายังไม่ดูคลิปนี้" / "อะไหล่ตัวนี้เปลี่ยนเองได้ ประหยัดเป็นพัน"

### เนื้อหาที่ปังในหมวดนี้ (เรียงตามแรง)
1. **DIY/ทิปดูแลรถง่ายๆ ที่ประหยัดเงิน** — เช่น เปลี่ยนไส้กรองอากาศเอง (เคสจริง 746k วิว). ขับเคลื่อนด้วย "ความกังวลค่าซ่อม"
2. **Before/After เห็นผลชัด** — ก่อน/หลังล้าง-เคลือบ, อะไหล่เก่า vs ใหม่, คราบ vs สะอาด. "หลักฐานภาพ" = เซฟ+แชร์
3. **แก้ความเชื่อผิดๆ (myth-busting)** — คอนเทนต์ดูแลรถบนโซเชียล ~59–80% เป็นคำแนะนำที่ทำรถพังได้. **KAN ชนะด้วยการเป็นผู้เชี่ยวชาญที่เชื่อถือได้** คอยเตือน/แก้
4. **"อะไหล่ตัวนี้มีไว้ทำอะไร + อาการที่บอกว่าต้องเปลี่ยน"** — เน้น "ปัญหาที่อะไหล่แก้" ไม่ใช่สเปคล้วนๆ
5. **เบื้องหลังร้าน/ช่าง (founder-led)** — สร้างความน่าเชื่อถือ + ตัวตน. ร้านที่ไวรัลมักกลายเป็น "เจ้าประจำ" ของพื้นที่

### สัดส่วนคอนเทนต์: 80/20
~80% ให้ความรู้/บันเทิง, ~20% ขายตรง. โพสต์ขายให้เล่าจาก "ปัญหาที่อะไหล่แก้" ไม่ใช่ลิสต์สเปค

### เทคนิคเพิ่ม reach
- **Trial Reels** (ปล่อยให้คนที่ยังไม่ฟอลโลว์เห็นก่อน) — รีโพสต์คลิปเก่าที่เคยปัง ได้ follower เพิ่มจริง
- **รีไซเคิลคอนเทนต์ที่เคยปัง** ซ้ำได้
- **คอนเทนต์ตามฤดู/เทศกาล** (สงกรานต์เดินทางไกล, หน้าฝน, ปีใหม่) ดันยอดง่าย
- **จับมือร้าน/เพจท้องถิ่นที่เสริมกัน** (อู่, คาร์แคร์, ร้านยาง)

### บริบทไทย (ตัวเลขอ้างอิง)
- 89% ของผู้ใช้ TikTok ไทยสนใจเรื่องรถ, #Car ยอดวิว +25% YoY
- สินค้ายานยนต์ขายดีอันดับ 1 บน TikTok Shop ไทย = **น้ำยาขัด/เคลือบเงารถ** (~200 บาท) → ของชิ้นเล็ก ราคาเข้าถึงง่าย เป็น "ตัวนำ" ที่ทำคอนเทนต์ง่าย
- ช่องทางออนไลน์กลายเป็นหัวใจการขายอะไหล่ในไทย

## ข้อควรระวัง
- อย่าลอกทิปจากคลิปไวรัลโดยไม่เช็ก — หลายอันทำรถพัง. KAN ต้องถูกต้องเสมอ (นี่คือจุดแข็ง)
- ตัวเลข engagement จากบล็อกเครื่องมือการตลาดเป็น "ทิศทาง" ไม่ใช่สัจธรรม — ยึดข้อมูล Insights จริงของ KAN เป็นหลักเมื่อเริ่มมีโพสต์
