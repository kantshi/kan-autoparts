## 1) เทรนด์ตลาด + คอนเทนต์ที่กำลังปัง (SCAN)

**ภาพรวม IG / Reels ตอนนี้**
- **Reels = เครื่องมือ reach อันดับ 1** engagement โตราว +25% ปีที่ผ่านมา และ **85% ของสิ่งที่คนแชร์ผ่าน DM คือ Reels** → คอนเทนต์ที่คน "อยากส่งให้เพื่อน" คือตัวขยายฟรี
- **Carousel = ตัวเก็บ engagement/save** ถูกเซฟมากกว่า Reels ~9 เท่า → เหมาะคอนเทนต์ให้ความรู้ที่คน "เก็บไว้ใช้"
- **Lo-fi ชนะโปรดักชันหรู** คลิปถ่ายมือถือดิบ ๆ ทำผลงานได้ดีกว่าคลิปตัดต่อจัดเต็ม — คนไทยเริ่มเบื่อโฆษณาขัดเงา เชื่อครีเอเตอร์ที่เหมือนคนจริงมากกว่า
- **ฮุก 3 วิแรกคือทุกอย่าง** IG มี metric "Skip rate" วัดคนออกใน 3 วิ — เป้าหมาย 3-sec retention >60% (ใช้ได้) / >80% (แข็งแรง) และเพราะ Reels เล่นอัตโนมัติแบบ **ปิดเสียง** → เฟรมแรก + text overlay คือฮุกตัวจริง
- **ไทยโดยเฉพาะ:** IG เป็นแอปอันดับ 1 ที่คนไทยใช้ **ค้นพบแบรนด์/สินค้าใหม่**, short video ให้ engagement สูงสุด, และ **conversational commerce (แชทขาย)** คือวิธีปิดการขายหลักใน SEA/ไทย → โครง **IG→LINE ของ KAN มาถูกทางแล้ว**

**คอนเทนต์สายรถ/อะไหล่ที่ได้ reach**
- กระบวนการ + ก่อน/หลัง (teardown, ประกอบ, ติดตั้ง, ทำความสะอาด) = ไปได้ไกลสุดบน Reels
- How-to สั้น ๆ (เช่น เปลี่ยนหลอดไฟ/ไส้กรอง) เข้าถึงคนหลักพัน-หมื่นได้
- คอนเทนต์ชวนคอมเมนต์: "ทายรุ่นรถ / นี่คืออะไหล่อะไร" + ให้ลูกค้าอัดคลิปติดตั้งเอง (social proof)

## 2) ถอดบทเรียน — "ทำไมถึงปัง" (DECONSTRUCT)

| คอนเทนต์ที่ปัง | ทำไมถึงสำเร็จ | จุดแข็งที่ถอดมาใช้ได้ |
|---|---|---|
| Before/After งานบูรณะ–ติดตั้ง | "before" สร้าง **ช่องว่างที่สมองอยากเห็นถูกเติมเต็ม** คนดูค้างเพื่อรอผลลัพธ์ | เปิดด้วยปัญหา/ของเก่าพัง → ปิดด้วยของใหม่ที่ KAN |
| Satisfying / ASMR งานช่าง | เสียง + ความลื่นไหลของกระบวนการ = ดูวนซ้ำ (watch time สูง) | ถ่ายเสียงจริงตอนประกอบ/ขันน็อต ไม่ต้องใส่เพลงทับ |
| คลิป how-to สั้น มีประโยชน์ | "มีประโยชน์" = คน **เซฟ + ส่งต่อให้เพื่อนที่รถมีปัญหาเดียวกัน** | ทำเป็น tip สั้น 1 คลิป 1 ปัญหา |
| ฮุกแบบ curiosity gap / คำถาม | ค้างคาใจใน 3 วิแรก ดึง retention ~68% | เปิดด้วยคำถามตรงกับ pain เจ้าของรถ |
| lo-fi ถ่ายมือถือ | ดู "จริง" น่าเชื่อถือกว่าโฆษณา → คนไทยเชื่อ | ถ่ายหน้าร้าน/โต๊ะช่างจริง ไม่ต้องสตูดิโอ |

**หลักร่วม 3 ข้อ:** (1) เปิดด้วย **คอนทราสต์/คำถาม** ใน 3 วิ (2) ให้ **คุณค่าที่คนอยากเซฟ/ส่งต่อ** ไม่ใช่แค่ขาย (3) **ของจริง ดิบ เชื่อถือได้** ชนะของปัง ๆ ขัดเงา

## 3) แผนคอนเทนต์ IG ของ KAN (ADAPT) — 5 คอนเซ็ปต์พร้อมถ่าย

> ยึดสัดส่วน **80 ให้ความรู้/บันเทิง : 20 ขาย** — ทุกคลิปจบด้วย CTA ส่งเข้า **LINE OA**
> ทุกคลิปต้องมี **text overlay เฟรมแรก** (คนดูแบบปิดเสียง)

**① [Reel · Before/After] "ของเดิมพังแบบนี้... เปลี่ยนเสร็จคือคนละคัน"**
- ฮุกเฟรมแรก (text): *"อะไหล่ตัวนี้พังแบบนี้ อันตรายกว่าที่คิด ⚠️"*
- โชว์ของเก่าสึก/แตก 2 วิ → ตัดไปติดตั้งของใหม่ KAN → ผลลัพธ์
- CTA: *"รุ่นรถคุณมีของ ทักไลน์เช็กได้เลย 👉"*

**② [Reel · How-to 30 วิ] "เปลี่ยน [ไส้กรอง/หลอดไฟ/ผ้าเบรก] เองได้ ไม่ต้องเข้าอู่"**
- ฮุก: *"อย่าเพิ่งจ่ายค่าแรงอู่ จนกว่าจะดูคลิปนี้"* (curiosity + ประหยัดเงิน = คนเซฟ)
- 3-4 สเต็ปสั้น ถ่ายมือถือ เสียงจริง
- CTA: *"อะไหล่ชุดนี้สั่งที่ KAN ส่งทั่วไทย"*

**③ [Reel · เกมชวนคอมเมนต์] "ทายซิ...นี่คืออะไหล่อะไร? 🔧"**
- โคลสอัพอะไหล่ปริศนา → เฉลยตอนจบ
- ดันคอมเมนต์ (algorithm ชอบ) + สร้างคอมมูนิตี้ช่าง/คนรักรถ
- ทำเป็น **ซีรีส์** ทุกสัปดาห์ (series โตยั่งยืนกว่าไวรัลครั้งเดียว)

**④ [Carousel · เก็บ save] "เช็กลิสต์ 5 อะไหล่ที่ควรเปลี่ยนก่อนเดินทางไกล"**
- คารูเซลถูกเซฟมากกว่า Reels ~9 เท่า → คอนเทนต์ให้ความรู้ที่คน "เก็บไว้"
- ผูกกับ **ซีซันเดินทาง/ปีใหม่** (พ.ย.–ธ.ค. คนเริ่มเตรียมรถทริปยาว)
- CTA: *"เซฟไว้เลย ครบชุดสั่งที่ KAN ราคาส่ง 5 ตัวขึ้นไปถูกกว่า"*

**⑤ [Reel · B2B ราคาส่ง] "ร้านอะไหล่/อู่ สั่ง 5 ตัวขึ้นไป ราคาต่อตัวลดทันที"**
- เจาะกลุ่มช่าง/ร้าน (จุดแข็ง Price 2 ของ KAN)
- โชว์ส่วนต่างราคาปลีก vs ส่งชัด ๆ
- CTA: *"เปิดบิลร้าน? แอดไลน์รับเรตส่ง"*
