# SKILL — นักวิเคราะห์การตลาด KAN Autoparts (Daily IG Content Analyst)

> สคิลนี้เป็น "กรอบการทำงาน" ให้รอบงานอัตโนมัติรายวันใช้ซ้ำได้ทุกวัน
> เป้าหมาย: ทุกวันดูเทรนด์ตลาด + คอนเทนต์ที่ประสบความสำเร็จ → วิเคราะห์ว่า "ทำไมถึงสำเร็จ" → ถอดจุดเด่นมาปรับใช้กับแผนคอนเทนต์ IG ของ KAN

---

## 1. บริบทธุรกิจ KAN (ใช้ตั้งต้นทุกครั้ง)

- **ธุรกิจ:** ร้านอะไหล่รถยนต์ (auto parts) ขายผ่านแค็ตตาล็อกมือถือ + สั่งผ่าน **LINE OA**
- **โมเดลราคา:** มีราคาปลีก + **ราคาส่ง/ซื้อยกจำนวน ("Price 2")** → แปลว่ามีลูกค้ากลุ่มช่าง/อู่/ร้านรับซื้อยกล็อตด้วย
- **แบรนด์ (จาก index.html):** โทน Navy `#082B55` + Gold `#C99632` + Teal `#1C6668` บนพื้นครีม `#F6F4ED` — ภาพลักษณ์พรีเมียม/น่าเชื่อถือ ฟอนต์ Sarabun
- **ภาษา:** ไทยเป็นหลัก

### กลุ่มเป้าหมาย (2 กลุ่ม — คอนเทนต์ต้องแยกจับ)
- **A. เจ้าของรถทั่วไป** — อยากรู้ว่าต้องใช้อะไหล่ตัวไหน, ของแท้ไหม, ราคาเท่าไหร่, เชื่อถือได้ไหม
- **B. ช่าง / อู่ / ร้านรับซื้อยกล็อต (B2B)** — สนใจ "มีของพร้อมส่ง", ความเร็ว, ของแท้, ราคาส่ง

---

## 2. ขั้นตอนทำงานรายวัน (ทำซ้ำทุกวัน)

1. **ดูเทรนด์แพลตฟอร์ม** — อัปเดตอัลกอริทึม/ฟอร์แมต IG ล่าสุด (Reels, carousel, สัญญาณจัดอันดับ)
2. **ดูคอนเทนต์ที่ประสบความสำเร็จ** — เน้นสายยานยนต์/อะไหล่/ช่าง ทั้งไทยและต่างประเทศ หาเคสที่ยอดดี
3. **วิเคราะห์ "ทำไมถึงสำเร็จ"** — ถอด hook, ฟอร์แมต, อารมณ์, ความยาว, สัญญาณที่อัลกอทึมชอบ
4. **ถอดจุดเด่น → ปรับใช้กับ KAN** — เขียนไอเดียโพสต์ IG ที่ทำได้จริง (hook + ฟอร์แมต + CTA ไป LINE)
5. **บันทึก** ไฟล์ลงวันที่ใน `marketing/daily/YYYY-MM-DD-ig-trend-analysis.md`
6. **แจ้งเตือน (PushNotification)** เฉพาะเมื่อมีเทรนด์/ไอเดียที่ควรลงมือทันที — ถ้าวันไหนไม่มีอะไรใหม่ ให้เงียบ

---

## 3. หลักการตัดสินคอนเทนต์ IG (อัปเดตล่าสุด)

- **Reels ครองรีช** (~11% ของคอนเทนต์ แต่ ~37% ของรีช) → เน้น Reels เพื่อเข้าถึงคนนอกผู้ติดตาม
- **สัญญาณจัดอันดับ = watch time, rewatch, การแชร์ใน DM, การเซฟ** — ไม่ใช่ยอดไลก์ (ไลก์น้ำหนักต่ำสุด)
- **3 วินาทีแรกตัดสินทุกอย่าง** — hook ยิ่งเฉพาะเจาะจงยิ่งดูจบ
- **ฟอร์แมตที่ทำซ้ำได้ชนะ** — talking-head แบบ UGC, listicle สอนความรู้, before/after
- **Originality บังคับ (เม.ย. 2026)** — คอนเทนต์รีโพสต์/ไม่ใช่ของตัวเองถูกตัดจาก recommendation → **ต้องถ่ายเองในร้าน/คลัง**
- **Niche ชนะ Broad** — เสิร์ฟกลุ่มคนรักรถ/ช่างไทยให้ลึก ดีกว่าทำกว้างๆ
- **Carousel เด่นเรื่อง save/share** — เหมาะคอนเทนต์สอน/เช็กลิสต์
- **Local discovery** — ติด location + แฮชแท็กเฉพาะกลุ่ม (เช่น ชื่ออะไหล่/รุ่นรถ)

## 4. สคิลอื่นของโปรเจกต์ KAN / ปลั๊กอินที่เรียกใช้เสริมได้

- `small-business:social-content-engine` — ปฏิทินโพสต์ประจำ
- `small-business:canva-creator` — เปลี่ยนบรีฟเป็นดีไซน์ Canva + แคปชัน (เมื่อเชื่อม Canva/HubSpot)
- `small-business:content-strategy` / `product-management:competitive-brief` — กลยุทธ์/วิเคราะห์คู่แข่ง
- `dataviz`, `artifact-design` — ทำสรุปเชิงภาพ
- หมายเหตุ: ปัจจุบันหลาย connector (Canva/HubSpot ฯลฯ) ยัง "ต่อไม่ติด (403)" — ใช้เป็นบรีฟ/ข้อความให้เจ้าของไปลงมือเองก่อนได้
