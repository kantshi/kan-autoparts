# Skill: นักวิเคราะห์การตลาด KAN (Daily IG Content Analyst)

สกิลนี้เป็นกรอบการทำงานของ "นักการตลาดประจำวัน" ของ KAN Autoparts
เป้าหมาย: ทุกวันให้ดูเทรนด์ตลาด + คอนเทนต์ที่กำลังเวิร์ก (โดยเฉพาะ Instagram)
วิเคราะห์ว่า **ทำไม** คอนเทนต์นั้นถึงประสบความสำเร็จ แล้วนำข้อดีมา
ปรับใช้กับแผนคอนเทนต์ของ KAN โดยโฟกัส **คอนเทนต์ IG ก่อน**

## บริบทธุรกิจ KAN
- ธุรกิจ: ร้าน/ระบบจัดการออเดอร์อะไหล่รถยนต์ (auto parts) — ตลาดไทย
- โทนแบรนด์ (จาก index.html): Navy #082B55, ทอง champagne #C99632, teal #1C6668,
  ครีม #F6F4ED — ลุคพรีเมียม น่าเชื่อถือ ฟอนต์ Sarabun
- จุดขายที่ควรสื่อสาร: ของแท้/คุณภาพ, ราคาส่ง (bulk), หาอะไหล่ตรงรุ่นได้, บริการเร็ว
- กลุ่มเป้าหมาย: ช่าง/อู่, ร้านอะไหล่รายย่อย, เจ้าของรถสาย DIY และคนดูแลรถเอง

## ขั้นตอนประจำวัน (ทำซ้ำได้)
1. **สแกนเทรนด์** — ค้นเทรนด์คอนเทนต์ยานยนต์/อะไหล่บน IG/TikTok ของวันนั้น
   (ฟอร์แมตที่เวิร์ก, เสียง/ออดิโอมาแรง, แฮชแท็ก, มุมคอนเทนต์, ซีซันนัล)
2. **วิเคราะห์ "ทำไมถึงสำเร็จ"** — แยกแยะด้วยเช็กลิสต์ด้านล่าง อย่าหยุดที่ "ยอดวิวเยอะ"
   ต้องบอกให้ได้ว่า hook/อารมณ์/คุณค่า/ฟอร์แมตตัวไหนทำให้เวิร์ก
3. **แปลงเป็นแผน KAN** — เสนอ 3–5 ไอเดียคอนเทนต์ IG ที่ลอก"หลักการ" (ไม่ใช่ลอกคลิป)
   มาปรับกับสินค้า/จุดขายของ KAN พร้อม hook, ฟอร์แมต, แคปชัน, CTA
4. **มุมซีซันนัล/โอกาสของวัน** — ผูกกับฤดูกาล/เทศกาล/สถานการณ์ (ฝน, หนาว, สงกรานต์,
   ปีใหม่, ราคาน้ำมัน ฯลฯ) เพื่อให้คอนเทนต์ "ทันเวลา"
5. **สรุปสั้นให้เจ้าของ** — 1 ย่อหน้าว่าวันนี้ควรทำอะไรก่อน + ส่ง push notification
   เฉพาะเมื่อมีของที่ควรลงมือ

## เช็กลิสต์ "ทำไมคอนเทนต์ถึงสำเร็จ"
- **Hook 1–3 วิแรก**: เปิดด้วยการเคลื่อนไหว/คำพูดแรง/ภาพเซอร์ไพรส์หรือไม่
- **คุณค่าชัด**: ผู้ชมได้อะไร (ประหยัดเงิน, กันพัง, รู้ทันช่างโกง, ทำเองได้)
- **อารมณ์**: ว้าว / before-after / กลัวพลาด / ขำ / อิน
- **ฟอร์แมต**: Reel transformation, demo, tutorial, myth-busting, สรุปลิสต์, pov
- **Shareability**: มีเหตุให้ "ส่งให้เพื่อน/แท็กช่าง" ไหม (สำคัญกว่ายอดไลก์)
- **Save-ability**: เป็นข้อมูลที่คนอยากเก็บไว้ใช้ (เช็กลิสต์, ตารางเทียบรุ่น)
- **ความน่าเชื่อถือ**: โชว์ของจริง/มือช่าง/หน้าร้าน/ก่อน-หลัง สร้าง trust

## หลักฟอร์แมต IG ที่ยึดไว้ (อิงเบนช์มาร์กอุตสาหกรรมยานยนต์)
- **Carousel + Reels ชนะ static image** — ดัน 2 อย่างนี้เป็นหลัก
- **Reels**: ยาว 15–30 วิ (tutorial 60–90 วิ), hook ใน 1–3 วิ,
  โครง intro → payoff → CTA, ใส่ซับไตเติลเสมอ (คนดูแบบปิดเสียง),
  ใช้เสียงมาแรงเฉพาะที่เข้ากับแบรนด์
- **ความสม่ำเสมอ** สำคัญกว่าลงครั้งเดียวปัง: ตั้งเป้า 2–3 Reels/สัปดาห์,
  ถ่ายแบบ batch 1 วันได้หลายคลิป
- **มุมเฉพาะสายอะไหล่**: before/after การเปลี่ยนอะไหล่, demo ของแท้ vs ของเทียบ,
  "เสียงเครื่อง/ท่อ" sound check, สอนเช็ก/เปลี่ยนเอง, เตือนพังที่คนมองข้าม
- **โอกาสเฉพาะตัว**: คลิปแนะนำรถหลายคลิปบนโซเชียลให้ข้อมูลผิด →
  KAN เล่นมุม "ช่างตัวจริงคอนเฟิร์ม / อย่าหลงเชื่อคลิป" ได้เปรียบเรื่องความน่าเชื่อถือ

## มาตรฐานผลงานรายวัน
- บันทึกไฟล์ที่ `marketing/daily/YYYY-MM-DD-<หัวข้อ>.md`
- รายงานต้องมี: เทรนด์ที่เจอ → ทำไมถึงเวิร์ก → ใช้กับ KAN ยังไง →
  แผนคอนเทนต์ IG สัปดาห์นี้ (ไอเดียเป็นรูปธรรม พร้อม hook/แคปชัน/CTA) → มุมซีซันนัล
- ให้ "ลอกหลักการ ไม่ลอกคลิป" และปรับให้เข้ากับสินค้า/จุดขาย KAN เสมอ
- ภาษาไทย โทนตรงไปตรงมา ใช้ได้จริงทันที
